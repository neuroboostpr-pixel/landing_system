# ru-trust-04-principles-grid

## Когда применять

Для компаний с чёткими принципами и ценностями — юристы, врачи, строители, консультанты. Когда нужно передать характер компании через конкретные тезисы, не абстрактные.

## Источник

Извлечено из `/tmp/open-design/skills/editorial-burgundy-principles-template/example.html` (Apache-2.0).
Адаптировано: нейтральные цвета вместо бургундских, добавлены data-slot, русская копия.

## Slots

- `headline` (text, ≤60 char) — заголовок блока.
- `p1-p6-title` (text, ≤40 char) — заголовки принципов.
- `p1-p6-text` (text, ≤160 char) — описания.

## Conversion notes

- Принципы снимают возражения через демонстрацию ценностей.
- Сетка 4×2 создаёт ощущение системности.
