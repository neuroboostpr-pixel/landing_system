# ru-trust-06-labs-showcase

## Когда применять

Trust-блок для компаний с портфолио кейсов или конкретных проектов. 5 карточек с нумерацией создают ощущение системной работы.

## Slots

- `kicker`, `headline` — заголовок секции.
- `tag-{1..4}` — теги-фильтры (декоративные, без JS).
- `lab-{1..5}-{type,title,desc,year}` — каждая карточка: тип, название, описание, год.

## Mobile considerations

Сетка 2×2 (4 карточки), пятая скрывается. Ширина 375px.
