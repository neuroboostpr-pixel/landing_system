# ru-trust-01-guarantees-docs

## Когда применять

Секция доверия для услуг и локального бизнеса — снимает страхи и возражения перед покупкой.

## Slots

- `headline` (text, ≤60 char) — заголовок секции.
- `trust-1-icon` (icon) — иконка "Договор".
- `trust-1-title` (text, ≤20 char) — "Договор".
- `trust-1-text` (text, ≤80 char) — краткое пояснение.
- `trust-2-icon` (icon) — иконка "Лицензия".
- `trust-2-title` (text, ≤20 char) — "Лицензия".
- `trust-2-text` (text, ≤80 char) — краткое пояснение.
- `trust-3-icon` (icon) — иконка "Гарантия".
- `trust-3-title` (text, ≤20 char) — "Гарантия".
- `trust-3-text` (text, ≤80 char) — краткое пояснение.
- `trust-4-icon` (icon) — иконка "Возврат".
- `trust-4-title` (text, ≤20 char) — "Возврат".
- `trust-4-text` (text, ≤80 char) — краткое пояснение.

## Conversion notes

- 4 элемента доверия — оптимально: не перегружает, но убедительно.
- Договор + лицензия — юридическая защита клиента.
- Гарантия + возврат — финансовая защита клиента.

## Mobile considerations

На mobile плашки складываются в 2x2 сетку.
