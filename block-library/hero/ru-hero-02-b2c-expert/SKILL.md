# ru-hero-02-b2c-expert

## Когда применять

Hero-блок для B2C-проектов, где личный бренд эксперта — главный аргумент доверия (психологи, коучи, врачи, консультанты).

## Slots

- `expert-photo` (photo, square) — фото эксперта, обрезается в круг. Обязательный.
- `expert-name` (text, ≤30 char) — имя эксперта.
- `expert-credentials` (text, ≤80 char) — регалии, специализация, стаж.
- `headline` (text, ≤60 char) — оффер/результат для клиента.
- `subhead` (text, ≤120 char) — детализация предложения.
- `primary-cta` (cta, default "Подобрать программу") — обязательная.

## Conversion notes

- Фото в круге создаёт доверие и личное ощущение.
- Регалии под именем — социальное доказательство.
- CTA ведёт на квиз подбора программы.

## Mobile considerations

На mobile эксперт сверху (круг меньше), текст снизу, CTA полной ширины.
