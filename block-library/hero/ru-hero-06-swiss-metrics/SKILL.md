# ru-hero-06-swiss-metrics

## Когда применять

Для B2B-ниш где доверие строится через цифры: строительство, юристы, финтех, консалтинг, IT-агентства. Когда есть 2-3 сильных числовых KPI (клиентов, проектов, лет работы).

## Источник

Извлечено из `/tmp/open-design/skills/digits-fintech-swiss-template/example.html` (Apache-2.0).
Адаптировано: убраны слайды-презентации, оставлен первый слайд как лендинг-hero, добавлены data-slot.

## Slots

- `headline` (text, ≤60 char) — крупный заголовок UPPERCASE. Обязательный.
- `subhead` (text, ≤180 char) — описание что делаем и для кого.
- `metric-1/2/3-value` (text, ≤12 char) — числовые значения KPI.
- `metric-1/2/3-label` (text, ≤40 char) — подписи под числами.
- `primary-cta` (cta) — кнопка действия.

## Conversion notes

- Цифры = немедленное доверие.
- Швейцарская сетка = восприятие надёжности и точности.
- Акцентная карточка выделяет главный KPI.
