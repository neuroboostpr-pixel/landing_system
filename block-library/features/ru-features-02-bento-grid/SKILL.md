# ru-features-02-bento-grid

## Когда применять

Альтернатива 3col-icons — более современный визуальный формат для ниш с сильным визуальным продуктом.

## Slots

- `headline` (text, ≤60 char) — заголовок секции.
- `feature-photo` (photo, 1:1) — фото в большой ячейке (span 2 rows).
- `bento-1-icon` (icon) — иконка 1-й маленькой ячейки.
- `bento-1-title` (text, ≤30 char) — заголовок 1-й ячейки.
- `bento-1-text` (text, ≤80 char) — текст 1-й ячейки.
- `bento-2-icon` (icon) — иконка 2-й маленькой ячейки.
- `bento-2-title` (text, ≤30 char) — заголовок 2-й ячейки.
- `bento-2-text` (text, ≤80 char) — текст 2-й ячейки.
- `bento-3-icon` (icon) — иконка 3-й маленькой ячейки.
- `bento-3-title` (text, ≤30 char) — заголовок 3-й ячейки.
- `bento-3-text` (text, ≤80 char) — текст 3-й ячейки.

## Conversion notes

- Большое фото привлекает внимание и якорит секцию.
- Мелкие ячейки лаконично перечисляют выгоды.
- Bento-формат современен и вызывает доверие у молодой аудитории.

## Mobile considerations

На mobile все ячейки становятся однорядными карточками в вертикальном стеке.
