# ru-features-03-swiss-cards

## Когда применять

Для отображения 4 ключевых преимуществ, шагов процесса или принципов работы. Подходит ниши с B2B-аудиторией или когда нужен нестандартный, запоминающийся визуал.

## Источник

Извлечено из `/tmp/open-design/skills/swiss-creative-mode-template/example.html` (Apache-2.0).
Адаптировано: добавлены data-slot, CSS-переменные, русская копия.

## Slots

- `headline` (text, ≤60 char) — заголовок секции.
- `card-1/2/3/4-title` (text, ≤40 char) — заголовки карточек.
- `card-1/2/3/4-text` (text, ≤160 char) — описания.

## Conversion notes

- Нумерация = системность, клиент понимает что вы умеете планировать.
- Разные цвета = каждый этап равно важен.
