# ru-features-06-cards-2x2

## Когда применять

Блок для **4 равноважных услуг или возможностей**. Хорошо для агентств, студий, многопрофильных компаний, где каждая карточка — отдельный продукт.

## Slots

- `kicker`, `headline`, `subhead` — заголовочная часть слева.
- `card-{1,2,3,4}-tag` (text, ≤20 char) — маленький тег в правом верхнем углу карточки.
- `card-{1,2,3,4}-title` (text, ≤40 char) — название услуги.
- `card-{1,2,3,4}-desc` (text, ≤140 char) — описание.

## Conversion notes

- Четыре карточки — оптимум для показа всей линейки без перегруза.
- Тег карточки помогает категоризации (например "Веб", "SEO", "Дизайн").
- Hover (translateY) работает чисто на CSS без JS.

## Mobile considerations

Заголовок сверху, сетка 2×2 снизу. Карточки немного уменьшаются. Ширина 375px.
