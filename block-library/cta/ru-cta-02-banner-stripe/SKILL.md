# ru-cta-02-banner-stripe

## Когда применять

CTA-блок для размещения **в конце лендинга** как финальный призыв. Подходит для любой ниши (услуги, b2c, local). Работает лучше `ru-cta-01-callback-tg-max` там, где нужен один канал связи, а не выбор из трёх.

Хорошо сочетается после блоков отзывов или раздела «О компании» — аудитория уже разогрета, нужен один чёткий следующий шаг.

## Slots

- `headline` (text, ≤70 char) — главный призыв, жирный крупный. Обязательный.
- `subhead` (text, ≤120 char) — уточнение оффера или снятие возражения. Опциональный.
- `primary-cta` (cta, default "Оставить заявку") — единственная кнопка. Обязательный.

## Conversion notes

- Белая кнопка на акцентном фоне — контраст цвета максимальный, CTA невозможно не заметить.
- Диагональный stripe-паттерн (pure CSS `repeating-linear-gradient`) создаёт визуальное движение без JS и изображений.
- Полноширинный блок без max-width — создаёт «момент» на странице, визуально останавливает скролл.
- Subhead используйте для снятия возражений: «Без предоплаты» / «Ответим за 5 минут» / «Бесплатная консультация».

## Mobile considerations

`template-mobile.html`: headline 30px, CTA полноширинная (display: block; width: 100%). Паттерн stripe сохраняется. Ширина 375px.
