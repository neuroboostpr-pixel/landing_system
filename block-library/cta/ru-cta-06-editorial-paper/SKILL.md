# ru-cta-06-editorial-paper

## Когда применять

Финальный CTA-блок для страниц в редакционном стиле. Нумерация разделов и roman-цифры создают ощущение завершённости. Хорошо сочетается с hero-07, hero-09, hero-10.

## Slots

- `section-num` (text) — roman-цифра раздела (например "VIII.").
- `kicker`, `headline`, `subhead` — заголовочная часть.
- `primary-cta` — главная кнопка. Только email/форма, НЕ WhatsApp.
- `secondary-cta` — ссылка на кейсы.
- `footer-note` (text, ≤60 char) — сноска с пульсирующей точкой.
- `cta-image` (photo, 1:1) — скрывается на mobile.

## Mobile considerations

Изображение скрыто, стек. Ширина 375px.
