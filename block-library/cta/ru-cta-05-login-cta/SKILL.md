# ru-cta-05-login-cta

## Когда применять

Финальный CTA-блок для онлайн-сервисов, записи к специалистам, SaaS. Идеален когда пользователь уже прогрет и нужно минимальное трение для конверсии.

## Источник

Извлечено из `/tmp/open-design/skills/login-flow/example.html` (Apache-2.0).
Адаптировано: убран телефонный статус-бар, добавлены data-slot, изменена копия на русский.

## Slots

- `brand-icon` (icon) — SVG-иконка или лого бренда. Опциональный.
- `headline` (text, ≤50 char) — заголовок карточки.
- `subhead` (text, ≤120 char) — подзаголовок с оффером.
- `input-placeholder` (text, ≤40 char) — placeholder для поля ввода.
- `primary-cta` (cta) — кнопка действия.
- `trust-note` (text, ≤80 char) — строка доверия под кнопкой.

## Conversion notes

- Одно поле — минимальное трение.
- Trust note снимает страх спама.
- Цвет accent применяется к иконке и кнопке для единого акцента.
