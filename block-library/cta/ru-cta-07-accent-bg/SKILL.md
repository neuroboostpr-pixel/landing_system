# ru-cta-07-accent-bg

## Когда применять

Финальный CTA перед footer. Максимально простой — один заголовок, одна кнопка. Акцентный фон (терракотовый) выделяет на фоне белых секций.

## Slots

- `headline` (text, ≤70 char) — ударный призыв к действию.
- `subhead` (text, ≤180 char) — один бенефит кратко.
- `primary-cta` — единственная кнопка. НЕ WhatsApp.
- `footnote` (text, ≤100 char) — снятие страхов ("без обязательств").

## Mobile considerations

Идентична desktop, кнопка на full-width. Ширина 375px.
