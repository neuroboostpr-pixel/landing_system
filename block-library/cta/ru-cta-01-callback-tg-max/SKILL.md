# ru-cta-01-callback-tg-max

## Когда применять

Финальный призыв к действию на странице — после всех секций, перед футером. Универсален для всех ниш.

## Slots

- `headline` (text, ≤80 char) — большой заголовок призыва.
- `subhead` (text, ≤140 char) — дополнительный текст.
- `tg-cta` (cta, default "Написать в Telegram") — обязательная.
- `max-cta` (cta, default "Написать в Max") — обязательная.
- `callback-cta` (cta, default "Перезвоните мне") — обязательная.

## Conversion notes

- **WhatsApp убран** — запрещён в РФ.
- Max Messenger обязателен — растущая платформа в России.
- 3 варианта связи = больше вариантов = выше конверсия.
- Большой padding создаёт ощущение важности блока.

## Mobile considerations

На mobile 3 кнопки складываются в вертикальный стек полной ширины.
