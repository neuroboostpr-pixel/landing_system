# ru-testimonials-01-video-circles

## Когда применять

Секция отзывов для всех ниш — особенно эффективна для B2C и локального бизнеса, где видео-доверие важно.

## Slots

- `headline` (text, ≤60 char) — заголовок секции.
- `testimonial-1-photo` (photo, 1:1) — фото клиента 1 (круглый).
- `testimonial-1-name` (text, ≤30 char) — имя клиента 1.
- `testimonial-1-quote` (text, ≤100 char) — цитата клиента 1.
- `testimonial-2-photo` (photo, 1:1) — фото клиента 2.
- `testimonial-2-name` (text, ≤30 char) — имя клиента 2.
- `testimonial-2-quote` (text, ≤100 char) — цитата клиента 2.
- `testimonial-3-photo` (photo, 1:1) — фото клиента 3.
- `testimonial-3-name` (text, ≤30 char) — имя клиента 3.
- `testimonial-3-quote` (text, ≤100 char) — цитата клиента 3.
- `testimonial-4-photo` (photo, 1:1) — фото клиента 4.
- `testimonial-4-name` (text, ≤30 char) — имя клиента 4.
- `testimonial-4-quote` (text, ≤100 char) — цитата клиента 4.
- `testimonial-5-photo` (photo, 1:1) — фото клиента 5.
- `testimonial-5-name` (text, ≤30 char) — имя клиента 5.
- `testimonial-5-quote` (text, ≤100 char) — цитата клиента 5.

## Conversion notes

- Круглые фото напоминают Stories/Reels — высокое доверие у молодой аудитории.
- Реальные лица повышают конверсию на 20-35%.
- Краткие цитаты читаются быстрее.

## Mobile considerations

На mobile кружки прокручиваются горизонтально (overflow-x: auto).
