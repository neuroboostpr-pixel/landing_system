# ru-quiz-05-thankyou

## Когда применять

Последний экран после отправки формы — подтверждает получение заявки и устанавливает ожидания по срокам связи.

## Slots

- `success-icon` (text) — unicode символ ✓ или другой индикатор успеха.
- `success-headline` (text, ≤80 char) — заголовок "Спасибо!".
- `success-subhead` (text, ≤140 char) — "Свяжемся через 5 минут в Telegram/Max".
- `back-cta` (cta, default "На главную") — кнопка возврата.

## Conversion notes

- Финальный экран закрепляет положительное впечатление.
- Конкретный срок связи ("5 минут") снижает тревожность.
- Упоминание канала (TG/Max) управляет ожиданиями.

## Mobile considerations

Полноэкранный центрированный layout — одинаков на desktop и mobile.
