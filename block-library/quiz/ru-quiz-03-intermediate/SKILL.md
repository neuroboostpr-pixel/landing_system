# ru-quiz-03-intermediate

## Когда применять

Вставляется после 2-3 вопросов квиза для снижения отказов — мотивирует пользователя продолжить.

## Slots

- `emoji-icon` (text) — unicode эмодзи, например "💪" или "🎯".
- `motivation-text` (text, ≤100 char) — поощрительный текст.
- `continue-cta` (cta, default "Продолжить") — обязательная.

## Conversion notes

- Промежуточный экран снижает abandon rate на 15-25%.
- Большое эмодзи создаёт эмоциональный момент.
- Текст должен подчёркивать прогресс ("осталось 2 шага").

## Mobile considerations

Полноэкранный центрированный layout — одинаков на desktop и mobile.
