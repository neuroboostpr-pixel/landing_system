# ru-quiz-13-comparison-question

## Когда применять

Использовать для выявления ключевого приоритета клиента: цена vs качество, скорость vs надёжность, эстетика vs практичность. Даёт менеджеру чёткий ориентир для продажи.

## Slots

- `question-text` (text, ≤120 char) — вопрос «что важнее». Обязательный.
- `option-a-title` (text, ≤50 char) — заголовок варианта А. Обязательный.
- `option-a-description` (text, ≤100 char) — пояснение варианта А.
- `option-b-title` (text, ≤50 char) — заголовок варианта Б. Обязательный.
- `option-b-description` (text, ≤100 char) — пояснение варианта Б.
- `question-comment` (text, ≤80 char) — «Нет правильного ответа — это поможет нам подобрать предложение».
- `progress-label` (text, ≤60 char) — «Вопрос N из M».

## Conversion notes

- Бинарный выбор без когнитивной перегрузки — проще radio из 4 вариантов.
- question-comment снимает тревожность «я отвечаю неправильно».
- CSS radio :checked без JS. На десктопе — side-by-side, на мобильном — стопка.
- Источник: Marquiz (подбор по параметрам для дифференциации предложения).

## Mobile considerations

На мобильном (375px) варианты А и Б выстраиваются вертикально (flex-column), иконка и текст — в ряд для компактности.
