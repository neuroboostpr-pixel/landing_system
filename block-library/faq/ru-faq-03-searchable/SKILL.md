# ru-faq-03-searchable

## Когда применять

FAQ-блок с интерактивным поиском для ниш с широкой вариацией вопросов (медицина, юристы, финтех, сложные услуги). Особенно полезен когда вопросов >6 и их можно сгруппировать по темам.

## Источник

Извлечено из `/tmp/open-design/skills/faq-page/example.html` (Apache-2.0).
Адаптировано под схему block-library: добавлены data-slot атрибуты, CSS-переменные :root, mobile 375px layout.

## Slots

- `headline` (text, ≤60 char) — заголовок секции FAQ. Обязательный.
- `subhead` (text, ≤120 char) — подзаголовок.
- `faq-cat-1/2/3` (text, ≤30 char) — метки категорий.
- `faq-1-q` / `faq-1-a` … `faq-3-q` / `faq-3-a` — вопросы и ответы.
- `footer-cta` (cta) — кнопка «Задать вопрос» в конце.

## Conversion notes

- Поиск снижает отказы: пользователь не листает, а ищет.
- Footer-CTA ловит тех, кто не нашёл ответ.
- Категории ускоряют навигацию по длинным FAQ.

## Mobile considerations

Компактные кнопки-категории, поиск без иконки, CTA полной шириной.
