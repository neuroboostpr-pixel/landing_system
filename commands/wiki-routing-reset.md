# /wiki-routing-reset

Очищает логи работы вики-графа и пересобирает пустой отчёт.
Учитывает что `flush.py` может дописывать события в фоне после завершения сессии —
поэтому очищает дважды с паузой 15 секунд между ними.

## Что делает

1. Первая очистка `logs/wiki-usage.jsonl`.
2. Ждёт 15 секунд — даёт flush.py от предыдущей сессии завершиться.
3. Вторая очистка — убирает всё что flush.py успел дописать.
4. Пересобирает пустой `wiki/routing-report.md`.

## Steps

```bash
# 1. Первая очистка
python -c "open('logs/wiki-usage.jsonl', 'w').close()" && echo "Первая очистка — готово. Жду 15 сек пока flush.py завершится..."

# 2. Пауза
sleep 15

# 3. Вторая очистка
python -c "open('logs/wiki-usage.jsonl', 'w').close()" && echo "Вторая очистка — готово."

# 4. Пересобрать пустой отчёт
python -m scripts.wiki.stats --report
```

Сообщи пользователю: «Логи и отчёт вики-графа очищены.»
