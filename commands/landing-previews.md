# /landing-previews

После того как composed.html готов — генерирует 3 файла:
- `composed-desktop-preview.html` — 1280×800
- `composed-mobile-preview.html` — 375×812
- `composed-previews-index.html` — все устройства с переключателем

Открой `composed-previews-index.html` в браузере — увидишь как лендинг выглядит на mobile, tablet, desktop, wide.

## Использование

```
/landing-previews <project>
```
