# ru-features-07-2col-split

## Когда применять

Блок "О нас" или "Наш подход" для страниц, где важно рассказать историю бренда или объяснить философию работы. Хорошо стоит между hero и features.

## Slots

- `kicker`, `headline`, `subhead` — заголовочная часть.
- `art-image` (photo, 1:1) — изображение справа.
- `cta` (cta, ghost-стиль) — вспомогательная кнопка.
- `footnote` (text, ≤80 char) — нижняя строка (процессы компании).

## Mobile considerations

Изображение сверху, текст снизу. Ширина 375px.
