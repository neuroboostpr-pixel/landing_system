# ru-features-01-3col-icons

## Когда применять

Секция "Почему мы" / "Наши преимущества" — универсальная для всех ниш после hero-блока.

## Slots

- `headline` (text, ≤60 char) — заголовок секции.
- `feature-1-icon` (icon) — SVG-иконка для 1-й колонки.
- `feature-1-title` (text, ≤30 char) — заголовок 1-го преимущества.
- `feature-1-text` (text, ≤80 char) — описание 1-го преимущества.
- `feature-2-icon` (icon) — SVG-иконка для 2-й колонки.
- `feature-2-title` (text, ≤30 char) — заголовок 2-го преимущества.
- `feature-2-text` (text, ≤80 char) — описание 2-го преимущества.
- `feature-3-icon` (icon) — SVG-иконка для 3-й колонки.
- `feature-3-title` (text, ≤30 char) — заголовок 3-го преимущества.
- `feature-3-text` (text, ≤80 char) — описание 3-го преимущества.

## Conversion notes

- 3 преимущества — оптимальное число для восприятия.
- Иконки визуально якорят каждый блок.
- Заголовки должны быть конкретными (цифры, факты).

## Mobile considerations

На mobile колонки складываются в вертикальный список.
