# ru-features-04-numbered-list

## Когда применять

Блок преимуществ для **SaaS-продуктов**, **tech-услуг** и **B2B**. Чистый белый фон с тонкими границами хорошо разделяет секции и не перегружает страницу.

## Slots

- `section-label` (text, ≤50 char) — верхний лейбл раздела (опциональный).
- `feat-{1,2,3}-num` (text, ≤4 char) — номер (по умолчанию 01, 02, 03).
- `feat-{1,2,3}-title` (text, ≤45 char) — заголовок преимущества.
- `feat-{1,2,3}-desc` (text, ≤180 char) — описание. Используйте измеримые результаты.

## Conversion notes

- Монопространственные числа создают технический, надёжный вид.
- Лучше писать описания с конкретными результатами: "Ответ за 2 часа" вместо "Быстрая поддержка".
- Хорошо сочетается с hero-07 и hero-09 (бежевый и пергаментный стили).

## Mobile considerations

`template-mobile.html` — вертикальный стек с горизонтальными разделителями. Ширина body 375px.
