# ru-features-05-method-steps

## Когда применять

Блок для описания **метода работы** или **процесса** в нишах с многоэтапными услугами — консалтинг, строительство, IT, дизайн. Четыре шага с линией-соединителем создают ощущение чёткости и профессионализма.

## Slots

- `kicker`, `headline`, `subhead` — заголовочная часть слева.
- `step-{1,2,3,4}-title` (text, ≤40 char) — название шага.
- `step-{1,2,3,4}-desc` (text, ≤160 char) — описание шага.

## Conversion notes

- Используйте глаголы действия: "Выявляем проблему", "Разрабатываем решение", "Запускаем", "Оцениваем результат".
- Четыре шага — психологически комфортное число: не слишком просто, не слишком сложно.

## Mobile considerations

Вертикальный стек с разделителями. Ширина 375px.
