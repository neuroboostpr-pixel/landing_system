# ru-trust-02-numbers-row

## Когда применять

Блок доверия для **любой ниши**, где есть конкретные цифры: лет на рынке, клиентов, проектов, гарантии, скорости ответа. Работает после hero или перед отзывами.

Альтернатива `ru-trust-01-guarantees-docs` (icon + text plaques): числа создают другой тип доверия — конкретику и масштаб, а не юридические гарантии.

## Slots

- `headline` (text, ≤60 char) — необязательный заголовок секции, uppercase-стиль (напр. «Наши результаты в цифрах»). Опциональный.
- `stat-1-number` (text, ≤10 char) — большое число (напр. «12 лет», «500+», «24/7»). Обязательный.
- `stat-1-label` (text, ≤20 char) — подпись к числу, uppercase. Обязательный.
- `stat-2-number`, `stat-2-label` — аналогично. Обязательные.
- `stat-3-number`, `stat-3-label` — аналогично. Обязательные.
- `stat-4-number`, `stat-4-label` — аналогично. Обязательные.

## Conversion notes

- 4 числа = ровно столько, сколько пользователь сканирует за 2-3 секунды.
- Числа в шрифте 56px становятся якорями взгляда без иконок и иллюстраций.
- Вертикальные разделители между ячейками создают «таблицу», но без тяжести таблицы.
- Секция лёгкая и быстрая — подходит как separator между контентными секциями.

## Mobile considerations

`template-mobile.html`: stats перегруппированы в 2×2 сетку, размер числа 36px, ячейки с border-bottom + border-right (последний столбец без border-right). Ширина 375px.
