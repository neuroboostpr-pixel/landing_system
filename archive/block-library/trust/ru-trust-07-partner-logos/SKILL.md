# ru-trust-07-partner-logos

## Когда применять

Быстрый trust-сигнал сразу после hero. Занимает мало места. Показывает известные бренды среди клиентов.

## Slots

- `section-label` (text, ≤60 char) — лейбл "Нам доверяют" / "Среди клиентов".
- `logo-{1..5}` (text, ≤40 char) — названия компаний.

## Conversion notes

- Используйте реальные узнаваемые бренды.
- Текстовые лого проще SVG для landing-системы — не нужны файлы.
- Opacity 55% убирает ощущение "рекламного каталога".

## Mobile considerations

Flex-wrap, лого переносятся на несколько строк. Ширина 375px.
