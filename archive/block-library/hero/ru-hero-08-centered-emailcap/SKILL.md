# ru-hero-08-centered-emailcap

## Когда применять

Hero для **лид-магнитов**, **пресейлов** и **запуска новых продуктов**, где основная цель — собрать email. Терракотово-оранжевая палитра создаёт ощущение эксклюзивности и срочности.

## Slots

- `kicker` (text, ≤50 char) — верхний лейбл (например "Скоро открытие · Запись открыта").
- `headline` (text, ≤60 char) — главный заголовок, крупно и ударно.
- `subhead` (text, ≤160 char) — одно-два предложения о ценности.
- `email-placeholder` (text, ≤30 char) — плейсхолдер в поле email, default "Ваш email".
- `primary-cta` (cta) — текст кнопки отправки, default "Получить доступ".
- `ticker-text` (text, ≤60 char) — текст для бегущей строки в нижней ленте.

## Conversion notes

- Inline email-форма прямо в hero → лучший CR для лид-магнитов (меньше шагов до конверсии).
- Бегущая строка создаёт ощущение активности и ажиотажа без отвлечения от CTA.
- НЕ использовать WhatsApp/Telegram кнопки — только email или нейтральный CTA.
- Добавить микрокопи "Мы не спамим" рядом с формой для повышения доверия.

## Mobile considerations

`template-mobile.html` — форма вертикальная (input + button стеком), всё по центру. Ширина body 375px.
