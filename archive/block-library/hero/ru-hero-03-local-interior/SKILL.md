# ru-hero-03-local-interior

## Когда применять

Hero-блок для локального бизнеса (кафе, салон красоты, студия, клиника), где атмосфера интерьера — ключевой фактор выбора.

## Slots

- `interior-bg` (photo, 16:9) — фото интерьера. Обязательный.
- `headline` (text, ≤60 char) — название + локация. Обязательный.
- `hours-tag` (text, ≤20 char) — часы работы, например "Пн-Вс 10-22".
- `primary-cta` (cta, default "Записаться") — обязательная.

## Conversion notes

- Full-width фото с тёмным оверлеем создаёт атмосферу.
- Часы работы в плашке — снижают барьер входа (знают, когда прийти).
- CTA "Записаться" ведёт на форму или квиз.

## Mobile considerations

На mobile overlay сохраняется, текст центрирован, CTA полной ширины снизу.
