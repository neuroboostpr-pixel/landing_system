# ru-hero-09-kami-serif

## Когда применять

Hero для **профессиональных и экспертных услуг** — юридические фирмы, финансовые консультанты, архитектурные бюро, образовательные учреждения. Засечный шрифт и пергаментная палитра создают ощущение надёжности.

## Slots

- `eyebrow-left` (text, ≤40 char) — левый метатекст (название компании / бренд).
- `eyebrow-right` (text, ≤40 char) — правый метатекст (год основания / специализация).
- `headline` (text, ≤80 char) — засечный заголовок; слово в `<span class="accent">` окрашивается синим.
- `subhead` (text, ≤220 char) — tagline или описание в serif-стиле.
- `metric-1-value` ... `metric-3-*` — карточки с ключевыми цифрами справа (опциональные).
- `primary-cta`, `secondary-cta` — две кнопки (заполненная и контурная).

## Conversion notes

- Засечный шрифт = доверие + профессионализм. Хорошо для B2B и сложных услуг.
- Карточки-метрики (N клиентов / N лет / N проектов) заменяют отдельный блок с числами.
- Синий акцент #1B365D нейтрален и профессионален — не создаёт риска ассоциации с конкурентами.

## Mobile considerations

`template-mobile.html` — вертикальный стек: eyebrow → h1 → tagline → карточки горизонтально → CTA. Ширина body 375px.
