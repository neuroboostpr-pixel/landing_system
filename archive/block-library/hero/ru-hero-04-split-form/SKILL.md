# ru-hero-04-split-form

## Когда применять

Hero-блок для **услуг** и **b2c** проектов, где нет сильного продуктового фото. Форма на первом экране без скролла. Подходит для ниш: юридические услуги, финансы, образование, консалтинг, ремонт (когда нет портфолио).

Альтернатива `ru-hero-01-services-calc` (фото) — когда проект стартует без фотобанка или фото не добавляет доверия.

## Slots

- `headline` (text, ≤60 char) — главный оффер. Обязательный.
- `bullet-1-text` (text, ≤80 char) — первое ключевое преимущество. Обязательный.
- `bullet-2-text` (text, ≤80 char) — второе ключевое преимущество. Обязательный.
- `bullet-3-text` (text, ≤80 char) — третье преимущество. Опциональный.
- `primary-cta` (cta, default "Узнать стоимость") — ссылка на форму / якорь. Обязательный.
- `lead-phone-input` (input, type=tel) — поле телефона в форме. Обязательный.
- `lead-submit-cta` (cta, default "Отправить заявку") — кнопка отправки формы. Обязательный.

## Conversion notes

- Форма и CTA одновременно видны без скролла — двойная точка конверсии.
- Радио-группа Telegram / Max / Позвоните мне охватывает все предпочтения РФ-пользователей (без запрещённых мессенджеров).
- Буллеты с ✓ строят доверие перед заполнением — не убирать.
- Подпись под кнопкой ("соглашение с политикой") снижает bounce на шаге отправки.

## Mobile considerations

`template-mobile.html` использует вертикальный stack: headline → bullets → hero-cta → форма. Ширина 375px. Форма полноширинная внизу экрана.
