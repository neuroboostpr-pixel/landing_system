# ru-hero-07-editorial-serif

## Когда применять

Hero-блок для **экспертных** и **premium-услуг** — консалтинг, дизайн, юридические и финансовые сервисы, архитектура. Тёплый бежевый фон и курсивный акцент создают доверие и элегантность без пафоса.

## Slots

- `kicker` (text, ≤40 char) — маленький верхний лейбл с нишей/специализацией.
- `headline` (text, ≤70 char) — заголовок; слово в `<em>` получит курсив засечного шрифта.
- `subhead` (text, ≤180 char) — подзаголовок с главной ценностью.
- `stat-1-value`, `stat-1-label` ... `stat-3-*` — три кольца с цифрами (лет / проектов / клиентов).
- `hero-image` (photo, 4:3) — иллюстрация или фото справа. Опциональный.
- `primary-cta` (cta, default "Начать работу") — обязательная.
- `secondary-cta` (cta, default "Узнать подробнее") — опциональная.

## Conversion notes

- Кольца с метриками (N лет / N проектов) — социальное доказательство без отдельного блока.
- На mobile фото идёт сверху (выше заголовка), затем текст, затем кнопки.
- CTA оранжевого цвета (#ed6f5c) имеет достаточный контраст на бежевом фоне.

## Mobile considerations

`template-mobile.html` — вертикальный стек: фото → kicker → h1 → subhead → статистика → кнопки. Ширина body 375px. Обе кнопки на full-width.
