# ru-testimonials-02-text-photo

## Когда применять

Секция отзывов для всех ниш — особенно для услуг и B2B, где важны конкретные результаты и детальные отзывы.

## Slots

- `headline` (text, ≤60 char) — заголовок секции.
- `testimonial-1-photo` (photo, 1:1) — фото клиента 1.
- `testimonial-1-quote` (text, ≤200 char) — цитата клиента 1.
- `testimonial-1-name` (text, ≤30 char) — имя клиента 1.
- `testimonial-1-role` (text, ≤50 char) — регалии/роль клиента 1.
- `testimonial-2-photo` (photo, 1:1) — фото клиента 2.
- `testimonial-2-quote` (text, ≤200 char) — цитата клиента 2.
- `testimonial-2-name` (text, ≤30 char) — имя клиента 2.
- `testimonial-2-role` (text, ≤50 char) — регалии/роль клиента 2.
- `testimonial-3-photo` (photo, 1:1) — фото клиента 3.
- `testimonial-3-quote` (text, ≤200 char) — цитата клиента 3.
- `testimonial-3-name` (text, ≤30 char) — имя клиента 3.
- `testimonial-3-role` (text, ≤50 char) — регалии/роль клиента 3.
- `testimonial-4-photo` (photo, 1:1) — фото клиента 4.
- `testimonial-4-quote` (text, ≤200 char) — цитата клиента 4.
- `testimonial-4-name` (text, ≤30 char) — имя клиента 4.
- `testimonial-4-role` (text, ≤50 char) — регалии/роль клиента 4.

## Conversion notes

- Конкретные результаты в цитатах ("сэкономил 150 000 ₽") работают лучше общих слов.
- Фото слева задаёт личное доверие.
- Роль/профессия клиента добавляет релевантность.

## Mobile considerations

На mobile фото и цитата в колонку, не в строку.
