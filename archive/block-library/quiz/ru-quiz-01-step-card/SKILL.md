# ru-quiz-01-step-card

## Когда применять

Основной шаблон шага квиза — используется для каждого вопроса с вариантами ответа.

## Slots

- `question-text` (text, ≤120 char) — вопрос шага. Обязательный.
- `answer-1-text` (text, ≤50 char) — вариант ответа 1.
- `answer-2-text` (text, ≤50 char) — вариант ответа 2.
- `answer-3-text` (text, ≤50 char) — вариант ответа 3.
- `answer-4-text` (text, ≤50 char) — вариант ответа 4.
- `question-comment` (text, ≤100 char) — мелкий серый текст "зачем спрашиваем".

## Conversion notes

- Карточка по центру фокусирует внимание.
- 4 варианта — баланс между выбором и перегрузкой.
- Комментарий снимает тревожность ("зачем вы это спрашиваете").

## Mobile considerations

Полная ширина для карточки и кнопок, комментарий снизу.
