# ru-quiz-12-mini-calculator

## Когда применять

Использовать для ниш с переменной стоимостью: ремонт, отделка, остекление, мебель. Заменяет абстрактный вопрос «какой бюджет» на конкретную цифру. Мотивирует уточнить у менеджера.

## Slots

- `headline` (text, ≤100 char) — «Рассчитайте стоимость покрытия». Обязательный.
- `param-1-label` (text, ≤60 char) — название первого параметра. Обязательный.
- `param-1-opt-1`, `param-1-opt-2` (text, ≤50 char) — варианты первого параметра.
- `param-2-label` (text, ≤60 char) — название второго параметра.
- `param-2-opt-1`, `param-2-opt-2` (text, ≤50 char) — варианты второго параметра.
- `result-prefix` (text, ≤40 char) — «Ориентировочная стоимость:». Обязательный.
- `cta-button` (text, ≤50 char) — «Уточнить точную цену →». Обязательный.

## Conversion notes

- Показ ориентировочной цены создаёт «крючок»: клиент хочет уточнить точную цифру → оставляет контакт.
- Расчёт статичный (диапазон по выбору), без реального JS-вычисления.
- Источники: Marquiz ("калькулятор как отдельный продукт"), Skillbox (calculator quiz type).

## Mobile considerations

На мобильном (375px) radio-кнопки обёрнуты flex-wrap, параметры в колонку, результат-box с жирным шрифтом.
