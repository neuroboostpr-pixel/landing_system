# ru-quiz-09-multi-select

## Когда применять

Использовать для вопросов, где допустимо несколько ответов: «Что важно при выборе?», «Какие проблемы хотите решить?», «Для каких помещений?». Собирает больше данных для сегментации.

## Slots

- `question-text` (text, ≤120 char) — вопрос. Обязательный.
- `option-1` ... `option-6` (text, ≤60 char) — варианты чекбоксов. option-1, option-2 обязательные.
- `next-button` (text, ≤30 char) — текст кнопки «Далее →». Обязательный.
- `progress-label` (text, ≤60 char) — «Вопрос N из M».

## Conversion notes

- Множественный выбор собирает больше сигналов о клиенте, делает ответ более персональным.
- CSS :checked + скрытые checkbox — никакого JS. Кнопка «Далее» видна сразу, не зависит от выбора.
- Источники: Tilda Education (multi-select question), Marquiz (для детализации потребностей).

## Mobile considerations

На мобильном (375px) варианты в колонку, шрифт 14px, кнопка «Далее» на всю ширину. Чекбокс-box 20×20px — достаточно для нажатия пальцем.
