# ru-quiz-08-slider-range

## Когда применять

Использовать для вопросов, где ответ — число в диапазоне: «Какой бюджет?», «Сколько квадратных метров?», «На сколько лет?». Устраняет проблему пустого поля ввода.

## Slots

- `question-text` (text, ≤120 char) — вопрос. Обязательный.
- `unit-label` (text, ≤20 char) — единица измерения: «₽», «м²», «лет». Обязательный.
- `min-label` (text, ≤30 char) — подпись левого края: «от 10 000 ₽».
- `max-label` (text, ≤30 char) — подпись правого края: «от 300 000 ₽».
- `question-comment` (text, ≤100 char) — подсказка мелким шрифтом.
- `progress-label` (text, ≤60 char) — «Вопрос N из M».

## Conversion notes

- Нативный `<input type="range">` без JS. Текущее значение показывается статично — для живого обновления потребуется JS при интеграции в форму.
- Слайдер сегментирует аудиторию по бюджету: менеджер сразу видит диапазон клиента.
- Источники: Tilda Education (slider question type), Skillbox (calculator quiz).

## Mobile considerations

На мобильном (375px) thumb слайдера 28px для удобного касания пальцем. Кнопка «Далее» на всю ширину.
