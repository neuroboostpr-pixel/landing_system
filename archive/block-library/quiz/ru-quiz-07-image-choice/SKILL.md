# ru-quiz-07-image-choice

## Когда применять

Использовать, когда варианты ответа можно показать визуально: стили интерьера, типы покрытий, цвета, материалы. Идеален для ниш ремонта, дизайна, одежды, мебели.

## Slots

- `question-text` (text, ≤120 char) — вопрос шага. Обязательный.
- `image-1` ... `image-4` (image) — фото варианта. image-1 и image-2 обязательные.
- `label-1` ... `label-4` (text, ≤40 char) — подпись под картинкой.
- `progress-label` (text, ≤60 char) — «Вопрос N из M · осталось ~Y мин».

## Conversion notes

- Визуальный выбор снижает когнитивную нагрузку: люди быстрее реагируют на картинку, чем читают текст (Tilda Education).
- CSS :checked + скрытый radio — никакого JS.
- Источник: tilda.education/how-to-create-marketing-quiz ("Ответы могут быть в форме фото").

## Mobile considerations

На мобильном (375px) сетка 2 колонки сохраняется, изображения высотой 100px вместо 140px. Кнопка «Далее» на всю ширину.
