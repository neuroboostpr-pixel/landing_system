# ru-pricing-02-comparison-table

## Когда применять

Блок ценообразования для **услуг и SaaS/сервисов**, где тарифы отличаются конкретными функциями, а не только ценой. Работает там, где клиент хочет сравнить «что входит»: IT-услуги, юридические пакеты, маркетинговое сопровождение, техобслуживание.

Альтернатива `ru-pricing-01-rub-from` (card-style): таблица подходит для ≥3 значимых отличий между тарифами.

## Slots

- `headline` (text, ≤60 char) — заголовок секции. Обязательный.
- `tier-1-name` (text, ≤20 char) — название 1-го тарифа (напр. «Базовый»). Обязательный.
- `tier-1-price` (text, ≤20 char) — цена (напр. «от 9 900 ₽»). Обязательный.
- `tier-1-cta` (cta, default "Выбрать") — CTA в нижней строке. Обязательный.
- `tier-2-name`, `tier-2-price`, `tier-2-cta` — средний тариф (выделен акцентом). Обязательные.
- `tier-3-name`, `tier-3-price`, `tier-3-cta` — старший тариф. Обязательные.
- `feature-row-1..6` (text, ≤60 char) — названия строк функций. Обязательные. (✓/✗ матрица — hardcoded, кастомизируется под проект.)

## Conversion notes

- Средний тариф выделен цветовым фоном (`#eff6ff`) + акцентной рамкой — якорный эффект; большинство выбирает его.
- ✓ (зелёные) / ✗ (серые) в ячейках визуально быстро показывают разницу — клиент не читает, он сканирует.
- CTA-строка снизу — у каждого тарифа своя кнопка. Accent-кнопка у среднего тарифа.
- feature-row-6 намеренно оставлен как текст («Базовая / Расширенная / Приоритетная») — для градуированных характеристик (напр. поддержка).

## Mobile considerations

`template-mobile.html`: таблица горизонтально прокручивается (overflow-x: auto), JS не нужен. min-width таблицы 480px обеспечивает читаемость. Шрифт headline уменьшен до 26px, цены — до 20px. Ширина контейнера 375px.
