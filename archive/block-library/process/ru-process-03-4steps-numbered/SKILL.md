# ru-process-03-4steps-numbered

## Когда применять

Process-блок для B2B услуг с ячеистым, структурированным видом. Иллюстрации в ячейках дают место для визуала.

## Slots

- `kicker`, `headline`, `subhead` — заголовочная часть.
- `step-{1..4}-title` (text, ≤40 char), `step-{1..4}-desc` (text, ≤160 char) — шаги.

## Mobile considerations

Сетка 2×2. Иллюстрации скрыты для компактности. Ширина 375px.
