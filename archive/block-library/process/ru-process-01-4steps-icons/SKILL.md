# ru-process-01-4steps-icons

## Когда применять

Секция "Как мы работаем" для услуг и локального бизнеса — снижает страх неопределённости.

## Slots

- `headline` (text, ≤60 char) — заголовок секции.
- `step-1-icon` (icon) — иконка 1-го шага.
- `step-1-title` (text, ≤30 char) — заголовок 1-го шага.
- `step-1-text` (text, ≤100 char) — описание 1-го шага.
- `step-2-icon` (icon) — иконка 2-го шага.
- `step-2-title` (text, ≤30 char) — заголовок 2-го шага.
- `step-2-text` (text, ≤100 char) — описание 2-го шага.
- `step-3-icon` (icon) — иконка 3-го шага.
- `step-3-title` (text, ≤30 char) — заголовок 3-го шага.
- `step-3-text` (text, ≤100 char) — описание 3-го шага.
- `step-4-icon` (icon) — иконка 4-го шага.
- `step-4-title` (text, ≤30 char) — заголовок 4-го шага.
- `step-4-text` (text, ≤100 char) — описание 4-го шага.

## Conversion notes

- Большие цифры 1-2-3-4 снижают тревожность — клиент знает, что ждёт.
- Процесс из 4 шагов — оптимальная длина (не пугает, не кажется пустым).
- Иконки якорят каждый шаг визуально.

## Mobile considerations

На mobile шаги складываются в вертикальный список с иконкой и цифрой слева.
