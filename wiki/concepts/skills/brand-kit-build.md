# Сборка бренд-кита

## Что делает

Скилл читает все YAML-файлы из папки `04_БРЕНД/extracted/`, синтезирует итоговый `brand-kit.md` с полной провенанцией (каждый дизайн-токен ссылается на исходный скриншот или URL), а затем рендерит HTML-превью (`brand-kit.html`) с образцами палитры, шрифтов и иконок. Перед извлечением токенов предлагает клиенту выбрать палитры из глобальной библиотеки (`presets/palettes.yaml`) — точечно (1–3), несколько (4–6) или весь каталог. Отобранные палитры снэпшотятся в `04_БРЕНД/palettes.yaml` скриптом `snapshot-palettes-to-project.py`. Если библиотека пуста, шаг выбора пропускается, а палитра создаётся с нуля на этапе 05.

## Когда вызывается

Вызывается агентом `brand-architect` в ходе выполнения команды `/landing-brand` (этап 04), после того как стиль-экстрактор выгрузил артефакты в `extracted/*.yaml`. Выполняется однократно per-проект; при повторном прогоне перезаписывает `brand-kit.md` и `brand-kit.html`.

## Вход → выход

**Вход:** YAML-артефакты из `04_БРЕНД/extracted/`; артефакты анализа ниши из `01a_АНАЛИЗ_НИШИ`; глобальная библиотека палитр `presets/palettes.yaml`; подтверждённый список ID палитр от пользователя (для режимов 1–2).

**Выход:** `04_БРЕНД/brand-kit.md` — полный бренд-кит с провенанцией; `04_БРЕНД/brand-kit.html` — визуальный превью с образцами; `04_БРЕНД/palettes.yaml` — снэпшот выбранных палитр для дальнейшего использования на этапе 05.

## Failure modes

- **Пустой `extracted/`** — скрипт `build.py` завершается без вывода, `brand-kit.md` не создаётся; нужно сначала запустить стиль-экстрактор.
- **Отсутствует `presets/palettes.yaml`** — режим 3 («весь каталог») падает с ошибкой; нужно создать файл или сообщить пользователю о пустой библиотеке.
- **Неверные ID палитр** — `snapshot-palettes-to-project.py` молча пропускает несуществующий ID, `palettes.yaml` окажется неполным.
- **Нет HTML-рендерера** — если `render-html.py` не находит шрифтов или изображений превью, HTML создаётся, но с пустыми образцами.
- **Отсутствует провенанция** — если исходные YAML не содержат поля `source`, `brand-kit.md` не пройдёт ручной ревью на корректность происхождения токенов.
