# brand-kit-build — Сборка бренд-кита

## Что делает

Читает все YAML-файлы с извлечёнными стилями из папки `04_БРЕНД/extracted/`, синтезирует итоговый файл `brand-kit.md` с полной прослеживаемостью каждого токена до источника (фото или URL), и рендерит HTML-превью `brand-kit.html` с палитрой, шрифтовыми образцами и иконками.

## Когда вызывать / в каком этапе

Этап **04 — БРЕНД**. Вызывается агентом `brand-architect` после того, как стили извлечены и сохранены в `04_БРЕНД/extracted/`. Точка входа для пользователя — команда `/landing-brand`.

Перед запуском синтеза скилл предлагает выбрать режим подбора палитры:
- **1–3 палитры** — клиент знает направление.
- **4–6 палитр** — есть ориентир (рекомендуется).
- **Весь каталог** — клиент в свободном поиске.

Кандидаты берутся из библиотеки `presets/palettes.yaml` (анализ ниши из `01a_АНАЛИЗ_НИШИ`). Если библиотека пуста — шаг выбора пропускается, палитра создаётся с нуля на этапе `/landing-design`.

## Что на вход / на выход

**Вход:**
- `04_БРЕНД/extracted/*.yaml` — YAML-файлы с токенами стиля (цвета, шрифты, иконки).
- `presets/palettes.yaml` — глобальная библиотека палитр (опционально).
- Артефакты анализа ниши из `01a_АНАЛИЗ_НИШИ` (для подбора палитры).

**Выход:**
- `04_БРЕНД/brand-kit.md` — полный бренд-кит с провенансом каждого токена.
- `04_БРЕНД/brand-kit.html` — визуальное превью для согласования с клиентом.
- `04_БРЕНД/palettes.yaml` — снапшот выбранных палитр из глобальной библиотеки.

**Скрипты:**
- `scripts/build.py` — синтез `brand-kit.md`.
- `scripts/render-html.py` — рендер `brand-kit.html`.
- `scripts/snapshot-palettes-to-project.py` — копирование палитр из глобальной библиотеки в проект.
