# Style Decomposition — Извлечение стиля из референсов

## Что делает

Автоматически вытаскивает из изображений и URL-адресов сайтов палитру цветов, шрифты и иконки, а затем упаковывает всё это в пять структурированных файлов, готовых для работы бренд-архитектора.

## Когда вызывать / в каком этапе

Используется на **этапе 04 (Бренд-кит)** агентом `style-extractor`. Запускается после того, как собраны референсы (этап 03), и до финального утверждения бренд-кита. Вызывается автоматически оркестратором — вручную не нужен.

## Что на вход / на выход

**Вход:**
- Изображения референсов (скриншоты, лого, фото с сайта клиента)
- URL-адреса сайтов-референсов для DOM-инспекции

**Выход** (папка `04_БРЕНД/extracted/`):
- `palette.yaml` — доминантные цвета, извлечённые через colorthief + Pillow
- `fonts.yaml` — шрифты, определённые через CSS-инспекцию Playwright
- `icons.yaml` — семантические имена иконок, подобранные из Iconify
- `grid.md` — сеточные параметры
- `motion.md` — параметры анимации / motion-стиля

**Скрипты:**
- `scripts/extract-palette.py` — извлечение цветов из изображений
- `scripts/identify-fonts.py` — определение шрифтов по URL
- `scripts/match-icons.py` — подбор иконок через Iconify API
- `scripts/download-fonts.py` — скачивание WOFF2 для офлайн-использования
- `scripts/orchestrate.py` — главная точка входа, запускает все скрипты по порядку
