# Style Decomposition — извлечение стиля из референсов

## Что делает

Автоматически вытаскивает визуальный стиль из картинок и сайтов-референсов: определяет цветовую палитру, шрифты, иконки и создаёт пять готовых файлов для бренд-кита проекта.

## Когда вызывать / в каком этапе

Вызывается агентом `style-extractor` на этапе **04 — Бренд-кит**, после того как пользователь предоставил референсные изображения или URL-адреса конкурентов/вдохновений. Не вызывается напрямую пользователем — только через агента или оркестратор.

## Что на вход / на выход

**Вход:**
- Референсные изображения (PNG/JPG) — для извлечения палитры
- URL-адреса сайтов-референсов — для определения шрифтов через DOM-инспекцию

**Выход** (папка `04_БРЕНД/extracted/`):
- `palette.yaml` — доминантные цвета с HEX-кодами
- `fonts.yaml` — идентифицированные шрифты
- `icons.yaml` — семантически подобранные иконки из Iconify
- `grid.md` — описание сеточной системы
- `motion.md` — параметры анимации/переходов
- WOFF2-файлы шрифтов — кэшированные локально для офлайн-сборки

**Внутренние скрипты:**
- `extract-palette.py` — colorthief + Pillow для работы с изображениями
- `identify-fonts.py` — Playwright для CSS-инспекции по URL
- `match-icons.py` — сопоставление имён иконок с библиотекой Iconify
- `download-fonts.py` — скачивание WOFF2
- `orchestrate.py` — главная точка входа, запускает все вышеперечисленные
