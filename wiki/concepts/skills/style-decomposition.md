# Декомпозиция стиля (Style Decomposition)

## Что делает

Скилл извлекает визуальный ДНК бренда из референсов клиента: доминирующую палитру — пиксельным анализом через colorthief + Pillow, шрифты — через DOM/CSS-инспекцию живых URL в Playwright, иконки — через семантическое сопоставление с библиотекой Iconify. Все артефакты складываются в папку `04_БРЕНД/extracted/` в виде пяти структурированных файлов. Является основным инструментом агента `style-extractor` на этапе 04.

## Когда вызывается

Вызывается агентом `style-extractor` в рамках команды `/landing-brand` (этап 04), когда папка с референсами клиента (`03_РЕФЕРЕНСЫ/`) уже заполнена и этап 03 закрыт.

## Вход → выход

**Вход:** Референсные изображения и URL из `03_РЕФЕРЕНСЫ/` (закрытый этап 03); материалы клиента из `02_МАТЕРИАЛЫ/` (логотип, брендбук если есть).

**Выход:** Пять файлов в `04_БРЕНД/extracted/`:
- `palette.yaml` — доминирующие цвета с hex-кодами и семантическими ролями
- `fonts.yaml` — выявленные шрифты, рекомендации к паре
- `icons.yaml` — подобранные иконки из Iconify
- `grid.md` — сеточная структура, выявленная из референсов
- `motion.md` — паттерны анимации и движения

## Failure modes

- **Playwright не может открыть URL** — если референс за paywall или CDN блокирует headless-браузер, шрифты не определяются; нужен ручной ввод.
- **Слишком тёмные/монохромные референсы** — colorthief выдаёт бедную палитру из 1–2 цветов; агент должен дополнить её из логотипа клиента.
- **Iconify не находит семантически близких иконок** — match-icons возвращает пустой список; нужна ручная корректировка перед этапом 05.
- **Отсутствие WOFF2-кэша** — download-fonts.py требует интернет во время выполнения; при оффлайн-сборке этап зависает.
- **Рассинхрон между extracted/ и design-system** — если style-decomposition перезапустить после закрытия этапа 05, артефакты перезапишутся и дизайн-токены устареют.
