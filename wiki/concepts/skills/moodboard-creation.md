# Moodboard Creation — создание мудборда из референсов

## Что делает
Читает утверждённые визуальные референсы из `03_РЕФЕРЕНСЫ/index.yaml` и рендерит интерактивный HTML-превью мудборда. Опционально вставляет текстовый нарратив из `moodboard.md` прямо в страницу.

## Когда вызывать / в каком этапе
Вызывается на этапе **03 (Референсы)** агентом `moodboard-composer` после того, как пользователь утвердил набор референсов через `/landing-references`. Скилл запускается автоматически оркестратором — вручную не требуется.

## Что на вход / на выход

**Вход:**
- `03_РЕФЕРЕНСЫ/index.yaml` — список референсов с полем approved/rejected для каждого
- `moodboard.md` (опционально) — текстовый нарратив/описание настроения бренда
- Шаблон `moodboard.html.j2` — Jinja2-шаблон для рендера

**Выход:**
- `03_РЕФЕРЕНСЫ/moodboard.html` — готовый HTML-превью мудборда с отфильтрованными референсами (только approved) и встроенным нарративом

## Связанные концепты
- [[moodboard-composer]] — агент-владелец этого скилла, вызывает его в рамках пайплайна
- [[landing-references]] — предыдущий этап: сбор и разметка референсов, формирует `index.yaml`
- [[landing-brand]] — следующий этап: использует мудборд как визуальную основу для бренд-кита
