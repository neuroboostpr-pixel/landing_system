# Стилизация фото

## Что делает

Скилл применяет identity-safe преобразования к клиентским фотографиям: вырезает фон, очищает края прозрачного слоя, кадрирует под нужный аспект и масштабирует до заданного размера. Используется агентом `photo-stylist` в рамках пайплайна обработки фото. Операции намеренно не затрагивают лица и идентичность людей на снимках — только геометрические и фоновые трансформации.

## Когда вызывается

Вызывается агентом `photo-stylist` на этапе обработки фото (по SKILL.md — stage 02; по CLAUDE.md пайплайн фото идёт на 07c). Точный момент вызова зависит от того, какой режим (`cutout`, `cleanup`, `crop`, `resize`) нужен для конкретного слота в photo-board.

## Вход → выход

**Вход:** исходный файл фотографии (JPG/PNG) и параметры трансформации — режим (`cutout`, `cleanup`, `crop`, `resize`), целевое соотношение сторон или максимальный размер.

**Выход:** обработанный файл (PNG с альфа-каналом для `cutout`/`cleanup`; обрезанный или масштабированный файл для `crop`/`resize`), готовый к вставке в слот `composed.html`.

## Failure modes

- `rembg` не установлен — скилл откатывается на Pillow-эвристику, качество вырезки хуже, артефакты на краях.
- `cleanup` применяется к фото без альфа-канала — операция не даёт эффекта, файл остаётся без изменений без явной ошибки.
- `crop` с нестандартным aspect ratio (например 3:7) — Pillow может обрезать не тот край, ключевой объект уходит за рамку.
- Входной файл повреждён или не поддерживаемого формата — исключение внутри `scripts/style.py` без fallback, пайплайн останавливается.
- Большие RAW-файлы (>20 МБ) — медленная обработка, превышение memory limit в рамках агент-сессии.
