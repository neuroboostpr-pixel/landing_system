# Сбор материалов клиента

## Что делает

Скилл обслуживает этап 02 (материалы клиента): создаёт структуру подпапок в `02_МАТЕРИАЛЫ_КЛИЕНТА/`, скрапит внешние отзывы клиента с Яндекс.Карт, 2GIS и Otzovik через локальный Playwright + trafilatura (без API-ключей), затем запускает сборщик манифеста и строит HTML-галерею всех собранных ассетов. Результат — единый каталог материалов с превью, готовый для работы следующих этапов.

## Когда вызывается

Вызывается агентом `client-assets-collector` в начале этапа 02 — после того как проект создан (onboarding завершён) и до начала сбора референсов (этап 03). Условие: папка проекта существует, `.landing-state.yaml` зафиксировал завершение этапа 01.

## Вход → выход

**Вход:** корневая папка проекта со структурой из шаблона; опционально — клиентские материалы, уже помещённые в `02_МАТЕРИАЛЫ_КЛИЕНТА/`; URL-адреса профилей клиента на площадках отзывов (Я.Карты, 2GIS, Otzovik).

**Выход:** заполненные подпапки `02_МАТЕРИАЛЫ_КЛИЕНТА/`; JSON-манифест всех ассетов; `gallery.html` — HTML-превью собранных материалов для проверки клиентом или менеджером.

## Failure modes

- Playwright не установлен или браузер не запускается — `parse-reviews.py` падает без отзывов; скилл не прерывает пайплайн, но манифест будет неполным.
- Площадка заблокировала IP или изменила разметку страницы — trafilatura возвращает пустой контент; отзывы пропускаются молча.
- `02_МАТЕРИАЛЫ_КЛИЕНТА/` уже существует с частично заполненными подпапками — повторный запуск может перезаписать пользовательские файлы, если не предусмотрена проверка существующих ассетов.
- Нет материалов клиента вообще — gallery.html генерируется пустой; нет явного предупреждения оркестратору.
- Скрипт `collect.py` не находит папку проекта — критическое падение с невнятным traceback, если slug передан неверно.
