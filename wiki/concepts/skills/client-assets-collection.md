# Сбор клиентских материалов

## Что делает

Скилл инициализирует структуру папки `02_МАТЕРИАЛЫ_КЛИЕНТА/`, парсит внешние отзывы клиента с площадок Яндекс.Карты, 2GIS и Otzovik через локальный Playwright + trafilatura (без API-ключей), а затем собирает манифест всех материалов и строит HTML-галерею для просмотра. Всё это выполняется на этапе 02 агентом client-assets-collector.

## Когда вызывается

Вызывается на этапе 02 («Материалы клиента»), когда оркестратор диспатчит агента `client-assets-collector`. Предполагается, что этап 01 (контекст/аналитика ниши) уже завершён и есть базовое понимание бизнеса клиента.

## Вход → выход

**Вход:** папка проекта с созданной структурой (или без `02_МАТЕРИАЛЫ_КЛИЕНТА/`), данные о клиенте из этапа 01 (ниша, ссылки на карточки на картах/отзовиках).

**Выход:** инициализированные подпапки `02_МАТЕРИАЛЫ_КЛИЕНТА/`; файл манифеста с перечнем всех собранных материалов; HTML-галерея для визуального просмотра; спаршенные отзывы с внешних площадок в структурированном виде.

## Failure modes

- **Парсер не достучался до площадок** — Playwright не смог загрузить страницу Яндекс.Карты или 2GIS (блокировка, captcha, изменение DOM). Отзывы остаются пустыми, галерея строится без них.
- **Ссылки на отзовики не переданы** — если в данных этапа 01 нет URL карточек клиента, `parse-reviews.py` не знает что парсить и завершается с пустым результатом.
- **Папка уже существует с частичным содержимым** — повторный запуск может пропустить инициализацию подпапок, если скрипт не проверяет идемпотентность.
- **Отсутствие зависимостей** — trafilatura или Playwright не установлены в окружении; скрипты падают на импорте.
- **HTML-галерея ссылается на несуществующие файлы** — если клиент не положил материалы до запуска `collect.py`, галерея генерируется с битыми путями.
