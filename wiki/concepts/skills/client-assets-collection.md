# Client Assets Collection — Сбор материалов клиента

## Что делает
Автоматически создаёт структуру папок для материалов клиента, парсит отзывы с Яндекс.Карт, 2GIS и Отзовика, и собирает HTML-галерею всех найденных ассетов.

## Когда вызывать / в каком этапе
Используется на **этапе 02** (материалы клиента). Вызывается агентом `client-assets-collector` после того, как проект создан и папка `02_МАТЕРИАЛЫ_КЛИЕНТА/` требует наполнения и разметки.

## Что на вход / на выход

**Вход:**
- Существующий проект лендинга с папкой `02_МАТЕРИАЛЫ_КЛИЕНТА/`
- URL или название компании для парсинга отзывов

**Выход:**
- Проинициализированные подпапки в `02_МАТЕРИАЛЫ_КЛИЕНТА/`
- Спарсенные отзывы с Яндекс.Карт / 2GIS / Otzovik (через Playwright + trafilatura, без API-ключей)
- `manifest.json` — список всех собранных ассетов
- `gallery.html` — HTML-превью всей галереи материалов
