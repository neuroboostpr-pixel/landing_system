# Client Assets Collection — Сбор материалов клиента

## Что делает
Инициализирует папку материалов клиента, парсит отзывы с Яндекс.Карт, 2GIS и Otzovik, а затем собирает HTML-галерею всех найденных ассетов для просмотра и согласования.

## Когда вызывать / в каком этапе
Вызывается на **этапе 02** (`02_МАТЕРИАЛЫ_КЛИЕНТА`) агентом `client-assets-collector`. Запускается после создания структуры проекта и до перехода к этапу 03 (референсы). Активируется когда нужно собрать, распарсить и визуализировать исходные материалы клиента — логотипы, фото, отзывы.

## Что на вход / на выход

**Вход:**
- Папка `02_МАТЕРИАЛЫ_КЛИЕНТА/` (создаётся скиллом если отсутствует)
- URL-ы страниц клиента на Яндекс.Картах, 2GIS, Otzovik (передаются в `parse-reviews.py`)

**Выход:**
- Инициализированные подпапки внутри `02_МАТЕРИАЛЫ_КЛИЕНТА/`
- Распарсенные отзывы (через Playwright + trafilatura, без API-ключей)
- `manifest` с перечнем всех ассетов
- HTML-галерея (`collect.py`) для визуального просмотра собранных материалов
