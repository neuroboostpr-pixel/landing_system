# Client Assets Collection — Сбор материалов клиента

## Что делает

Собирает все клиентские материалы на этапе 02: создаёт структуру папок в `02_МАТЕРИАЛЫ_КЛИЕНТА/`, парсит отзывы с внешних площадок (Яндекс.Карты, 2GIS, Отзовик) и формирует HTML-галерею с манифестом всех собранных ресурсов.

## Когда вызывать / в каком этапе

Вызывается на **этапе 02** (Материалы клиента) агентом `client-assets-collector`. Выполняется до этапа 03 (Референсы) и этапа 04 (Бренд). Активировать, когда нужно заполнить папку `02_МАТЕРИАЛЫ_КЛИЕНТА/` реальными данными клиента — отзывами, фото, видео с внешних источников.

## Что на вход / на выход

**Вход:**
- URL-адреса страниц клиента на Яндекс.Картах, 2GIS, Отзовике (передаются в скрипты)
- Существующий проект с папкой `02_МАТЕРИАЛЫ_КЛИЕНТА/` (или создаётся автоматически)

**Выход:**
- Подпапки внутри `02_МАТЕРИАЛЫ_КЛИЕНТА/` (scaffold)
- Файл `assets-manifest.yaml` — манифест всех найденных ресурсов
- HTML-галерея-превью собранных материалов
- Спарсенные отзывы из внешних источников

**Инструменты:**
- `scripts/collect.py` — сборка манифеста и HTML-галереи
- `scripts/parse-reviews.py` — парсинг отзывов через Playwright + trafilatura (без API-ключей, бесплатно)
