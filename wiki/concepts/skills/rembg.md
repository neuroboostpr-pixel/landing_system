# Удаление фона (rembg)

## Что делает

Скилл-обёртка над библиотекой rembg (U2-Net / isnet-general-use), которая отделяет объект от фона на клиентских фотографиях. Применяется в фото-пайплайне этапа 07c, когда машина, товар или портрет сняты в студии на светлом или градиентном фоне, а в карточке блока нужен объект «в воздухе» — без фона — чтобы карточка перекрашивалась под дизайн-систему. Обрабатывает один файл или всю папку за прогон, сохраняет PNG/webp с альфа-каналом, обрезает прозрачные поля по bbox и при необходимости кладёт рядом preview на тёмном фоне для ручной проверки краёв.

## Когда вызывается

Вызывается вручную в рамках этапа 07c (photo pipeline): после того, как клиентские фото разложены по подпапкам `07c_PHOTOS/inbox/` и утверждены этапы 05 (design-system) и 07a (prototype). Перед запуском массового прогона рекомендуется проверить один файл с флагом `--preview`, чтобы убедиться в качестве краёв.

## Вход → выход

**Вход:** файл изображения (PNG/JPG) или папка с фотографиями со студийным фоном; опционально — название модели rembg и выходная директория.

**Выход:** PNG или webp с прозрачным фоном (alpha-канал), автоматически обрезанный по bbox объекта. При флаге `--preview` — дополнительный файл `<name>-preview.png` с объектом на тёмном фоне для визуальной проверки краёв.

## Failure modes

- **Рваный или обрезанный край** — стекло, тени под колёсами, полупрозрачные элементы rembg может срезать; проверяй `--preview` перед массовым прогоном.
- **Первый запуск без интернета** — модель (`~/.u2net`, ≈170 МБ) скачивается при первом вызове; без сети упадёт с ошибкой загрузки весов.
- **Плохой результат на конкретном фото** — некоторые снимки (сложный фон, низкий контраст объекта) дают некачественный вырез; такое фото лучше оставить с фоном или переснять — плохой вырез в прод не тащить.
- **Неправильная модель** — для авто рекомендована `isnet-general-use`, а не `u2net`; использование дефолта u2net даёт более грубые края.
- **Отсутствие rembg в окружении** — если пакет не установлен (`pip install rembg`), скрипт не запустится.
