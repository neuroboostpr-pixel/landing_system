# GPT-5 Prompting Engine

## Что делает

Создаёт, мигрирует, отлаживает и валидирует промпты для GPT-5 по краткому брифу, старому промпту или описанию нужного поведения агента. Выдаёт готовый промпт с оценкой качества и рекомендациями по API-параметрам.

## Когда вызывать / в каком этапе

Активируется вручную — не привязан к конкретному этапу лендинг-пайплайна. Нужен, когда пользователь просит написать, переработать или проверить промпт для GPT-5, API, GPTs, Codex-агента или внутреннего ассистента.

## Что на вход / на выход

**Вход:**
- бриф с описанием задачи или существующий промпт для переработки
- тип задачи: `create` / `migrate` / `debug`
- целевая платформа (API, GPTs, Codex, внутренний ассистент)

**Выход (при создании):**
- готовый промпт с явной структурой (цель, роль, workflow, ограничения, формат вывода, критерии завершения)
- рекомендации по API-параметрам (`reasoning_effort`, `verbosity`)
- оценка качества по валидационному рубрику (0–10, порог 8)
- допущения и заметки по использованию

**Выход (при миграции/отладке):**
- диагноз проблем
- список изменённых инструкций
- финальный v2 промпт
- оценка + оставшиеся риски

## Workflow внутри скилла

1. Классифицировать задачу (`create` / `migrate` / `debug`).
2. Определить платформу использования.
3. Выбрать паттерн из `references/prompt-knowledge-base.txt`.
4. Прогнать проверки миграции из `references/gpt5-migration-base.txt`.
5. Применить рекомендации из `references/gpt5-prompting-base.txt`.
6. Собрать промпт с шестью обязательными секциями.
7. Оценить по `references/validation-rubric.md`.
8. Если оценка ниже 8/10 — одна итерация доработки.

**GPT-5 параметры по умолчанию:**
- простая задача: `reasoning_effort=minimal`
- стандартный агент: `reasoning_effort=medium`
- сложный multi-agent/coding: `reasoning_effort=high`
