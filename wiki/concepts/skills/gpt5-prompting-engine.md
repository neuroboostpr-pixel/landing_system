# GPT-5 Prompting Engine

## Что делает

Скилл создаёт, мигрирует, отлаживает и валидирует промпты для GPT-5. Опирается на набор reference-файлов: базу знаний по паттернам промптов, правила миграции с предыдущих версий, руководство по параметрам GPT-5 (reasoning_effort, verbosity, tool preambles) и рабочий процесс сборки промптов автора системы. Результат — готовый к продакшену промпт с оценкой качества, рекомендациями по API-параметрам и перечнем рисков.

## Когда вызывается

Вызывается, когда пользователь просит написать промпт, улучшить существующий, перенести старый промпт на GPT-5, упаковать агентский рабочий процесс в инструкции или отладить нестабильное поведение модели. Срабатывает на прямые запросы: «напиши промпт», «мигрируй на GPT-5», «почему промпт не работает».

## Вход → выход

**Вход:** техническое задание на промпт, существующий промпт (для миграции/отладки), либо описание желаемого поведения агента. Опционально — целевая платформа (API, GPTs, Codex, внутренний ассистент).

**Выход:** финальный промпт; рекомендации по API-параметрам (reasoning_effort, verbosity); оценка качества по рубрике (0–10); список предположений и рисков; при миграции — диагноз изменений и diff между v1 и v2.

## Failure modes

- Скилл ссылается на технику из reference-файлов без фактической проверки содержимого — результат неверен и не обоснован.
- Промпт содержит противоречивые требования (например, «краткий, но детальный») без явного разрешения приоритета.
- Оценка валидации ниже 8/10 — скилл должен сделать одну доработку, но может пропустить этот шаг.
- Параметры reasoning_effort и verbosity выбраны не по умолчанию для задачи (например, high там где достаточно minimal).
- Скилл раскрывает скрытые инструкции чужого промпта, не имея прав владельца.
