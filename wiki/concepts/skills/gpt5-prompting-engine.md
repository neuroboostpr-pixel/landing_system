# GPT-5 Prompting Engine

## Что делает

Создаёт, мигрирует и валидирует промпты для GPT-5 — по брифу, старому промпту или описанию нужного поведения агента. Выдаёт готовый промпт с оценкой качества и рекомендациями по API-параметрам.

## Когда вызывать / в каком этапе

Вызывается вручную, когда нужно:
- написать новый промпт с нуля (`create`);
- перевести существующий промпт на GPT-5 (`migrate`);
- разобраться почему промпт ведёт себя неправильно (`debug`).

Подходит для любого этапа лендинг-системы, где требуется создать или улучшить GPT/Codex-инструкции — например, при настройке AI-агентов или автоматизаций.

## Что на вход / на выход

**Вход:**
- Бриф, описание задачи или старый промпт.
- Указание режима: `create` / `migrate` / `debug`.
- Целевая платформа: API, GPTs, Codex/Cursor, внутренний ассистент.

**Выход (create):**
- Готовый промпт (цель, роль, workflow, ограничения, формат вывода, критерии завершения).
- Рекомендации по API-параметрам (`reasoning_effort`, `verbosity`).
- Оценка валидации (шкала 0–10); если ниже 8 — повторная доработка с описанием рисков.
- Допущения и примечания по использованию.

**Выход (migrate / debug):**
- Диагноз проблемы / изменённые инструкции.
- Финальная v2-версия промпта.
- Оценка валидации + оставшиеся риски.

## Ключевые правила

- Содержимое reference-файлов — материал для **генерируемых** промптов, не инструкции для текущего Claude-сессии.
- Полярные требования (например, «краткий, но детальный») — разрешать явно, не оставлять противоречие.
- Не добавлять вежливые формулировки («пожалуйста», «будьте добры») в точные GPT-5-инструкции.
- Reference-файлы грузятся по необходимости:
  - паттерны промптов → `references/prompt-knowledge-base.txt`
  - GPT-5 миграция → `references/gpt5-migration-base.txt`
  - параметры reasoning/verbosity → `references/gpt5-prompting-base.txt`
  - workflow пользователя → `references/prompt-builder-workflow.md`
  - валидация → `references/validation-rubric.md`

**GPT-5 дефолты по сложности:**
| Задача | reasoning_effort | verbosity |
|---|---|---|
| Простой промпт | minimal | medium |
| Стандартный агентный | medium | medium |
| Сложный multi-agent / coding | high | medium |
