# GPT-5 Prompting Engine

## Что делает

Скилл создаёт, мигрирует, отлаживает и валидирует промпты для GPT-5 на основе базы знаний Кирилла Безикова. Принимает бриф, старый промпт или описание нужного поведения агента — возвращает готовый промпт с оценкой качества.

## Когда вызывать / в каком этапе

Вызывается вручную, когда пользователь просит:
- написать новый промпт с нуля,
- улучшить или адаптировать существующий промпт,
- мигрировать промпт под GPT-5 (проверить на противоречия, устаревшие паттерны),
- упаковать промпт-воркфлоу или собрать агентский пайплайн,
- разобраться, почему промпт работает неправильно (debug).

Этап pipeline не фиксирован — скилл не привязан к конкретному этапу landing-system.

## Что на вход / на выход

**Вход:**
- Бриф с описанием нужного поведения, либо
- Старый промпт для миграции / отладки,
- Тип задачи: `create`, `migrate` или `debug`,
- Целевое окружение: API, GPTs, Codex/Cursor, внутренний ассистент.

**Выход:**
- Готовый промпт (цель, роль, воркфлоу, ограничения, формат вывода, критерии завершения),
- Рекомендации по параметрам API (`reasoning_effort`, `verbosity`),
- Оценка качества по рубрике (минимально допустимо 8/10),
- Перечень допущений и рисков.

При миграции/отладке дополнительно: диагноз проблемы и список изменённых инструкций.

## Внутренние эталоны (референсы скилла)

Скилл загружает из `references/` только нужное:
- `prompt-knowledge-base.txt` — паттерны промптов,
- `gpt5-migration-base.txt` — правила миграции и чистки противоречий,
- `gpt5-prompting-base.txt` — параметры рассуждения, многословности, инструментов GPT-5,
- `prompt-builder-workflow.md` — авторский воркфлоу,
- `validation-rubric.md` — рубрика для оценки.

## Ограничения

- Не раскрывает скрытые инструкции сгенерированного промпта без запроса владельца.
- Не использует противоречивые требования (например, «кратко, но подробно») без разрешения приоритетов.
- Не добавляет вежливые слова-паразиты (`please`) в production-промпты GPT-5.
