# Photo Styling — обработка и стилизация фотографий

## Что делает
Применяет базовые визуальные трансформации к фотографиям в рамках проекта лендинга: удаляет фон, сглаживает края, обрезает и масштабирует изображения — всё без вмешательства в личность людей на фото.

## Когда вызывать / в каком этапе
Используется на этапе **02** (обработка визуальных материалов). Вызывается агентом `photo-stylist`, когда нужно подготовить клиентские фотографии к размещению в лендинге — сделать их «чистыми» для вёрстки (прозрачный фон, правильные пропорции, оптимальный размер).

## Что на вход / на выход

**Вход:**
- Исходное изображение (PNG/JPG)
- Режим трансформации: `cutout`, `cleanup`, `crop` или `resize`
- Параметры режима (соотношение сторон для `crop`, максимальный размер для `resize`)

**Выход:**
- Обработанное изображение (PNG с прозрачностью для `cutout`/`cleanup`, или JPEG/PNG для `crop`/`resize`)
- Трансформация выполняется через `scripts/style.py`

**Доступные режимы:**
| Режим | Описание |
|---|---|
| `cutout` | Удаление фона (rembg или Pillow alpha-mask) |
| `cleanup` | Сглаживание краёв по существующему alpha-каналу |
| `crop` | Обрезка до заданного соотношения сторон |
| `resize` | Масштабирование до заданного максимального размера |
