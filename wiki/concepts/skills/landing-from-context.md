# landing-from-context — Создание лендинга из контекста агентства

## Что делает

Создаёт новый лендинг-проект внутри существующей папки агентства и автоматически переносит туда данные исследований, аудитории и прототипы — чтобы не начинать с чистого листа.

## Когда вызывать / в каком этапе

Вызывается командой `/landing-from-context <slug>`, когда текущая рабочая директория — корень родительского проекта агентства. Признаки подходящей ситуации: в папке есть подпапки `01_контекст`, `04_документы`, `05_исследования`. Подходит для создания лендинга по уже исследованному курсу, продукту или нише.

## Что на вход / на выход

**На вход:**
- `<slug>` — имя нового лендинга в kebab-case
- `--cinematic` — опциональный флаг
- Родительская папка агентства с данными: контекст, документы, исследования

**На выход:**
- Новый лендинг-проект в `~/Lendings/<slug>/` с полной структурой шаблона
- Снепшот данных родителя:
  - `01_контекст/` → `01_КОНТЕКСТ/`
  - `05_исследования/` → `01_КОНТЕКСТ/исследования/`
  - `04_документы/прототип-*.md` → `07_КОНТЕНТ/prototype.md`
- Файл `01_КОНТЕКСТ/source-references.yaml` — откуда скопированы данные
- Управление передаётся `landing-orchestrator`, начиная с этапа **02** (00–01 уже заполнены)

## Важные ограничения

- Создаётся только **снепшот** (копия), не симлинк — изменения в родителе не влияют на лендинг
- Родительский проект не модифицируется
- Если прототипных файлов нет — скилл спрашивает пользователя, не угадывает
