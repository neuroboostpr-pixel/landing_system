# References Collection — управление индексом референсов

## Что делает
Ведёт YAML-файл `03_РЕФЕРЕНСЫ/index.yaml`, в котором хранятся все визуальные референсы проекта (ссылки и файлы) с присвоенными статусами: кандидат, одобрен или отклонён. Позволяет добавлять, обновлять, просматривать и удалять записи через стандартные подкоманды.

## Когда вызывать / в каком этапе
Активируется на **этапе 03 — Референсы**. Агент `references-curator` использует этот скилл для работы с индексом: когда нужно добавить новый референс (URL или файл), изменить его статус, или сформировать финальный одобренный список для передачи в `moodboard-creation`.

## Что на вход / на выход

**Вход:**
- Путь к директории `03_РЕФЕРЕНСЫ/` (`refs-dir`)
- Команда и её аргументы: референс (URL или путь к файлу), опциональные флаги `--type` и `--status`

**Выход:**
- Обновлённый `03_РЕФЕРЕНСЫ/index.yaml` с актуальными записями и статусами
- При `list` / `show` — вывод записей для просмотра

**Доступные подкоманды:**
| Команда | Назначение |
|---|---|
| `add` | Добавить новый референс (url или file) |
| `update` | Изменить статус существующего референса |
| `list` | Показать список (с фильтром по статусу) |
| `show` | Показать одну запись по ID |
| `remove` | Удалить запись из индекса |

**Статусы референсов:** `candidate` → `approved` / `rejected`

## Связанные концепты
- [[references-curator]] — агент-владелец скилла: вызывает подкоманды, управляет сессией курирования
- [[moodboard-creation]] — принимает одобренные референсы (`status: approved`) на вход для синтеза мудборда
- [[landing-references]] — slash-команда, запускающая этап 03 через `references-curator`
