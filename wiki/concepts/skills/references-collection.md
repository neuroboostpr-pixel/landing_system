# References Collection — управление индексом референсов

## Что делает
Ведёт YAML-индекс визуальных референсов проекта: добавляет, обновляет статусы, удаляет и выводит список ссылок и файлов, собранных на этапе 03.

## Когда вызывать / в каком этапе
Используется на **этапе 03 (Референсы)** агентом `references-curator`. Вызывается автоматически при добавлении новой ссылки или файла в папку `03_РЕФЕРЕНСЫ/`, а также при смене статуса референса (кандидат → утверждён/отклонён).

## Что на вход / на выход

**Вход:**
- Путь к директории `03_РЕФЕРЕНСЫ/` (`<refs-dir>`)
- Подкоманда с аргументами: `add`, `update`, `list`, `show`, `remove`
- Для `add`: URL или путь к файлу, тип (`url` / `file`), начальный статус (`candidate` / `approved` / `rejected`)
- Для `update`: id референса и новый статус

**Выход:**
- Обновлённый `03_РЕФЕРЕНСЫ/index.yaml` с актуальным списком и статусами
- При `list` / `show` — вывод записей в терминал

## Связанные концепты
- [[references-curator]] — агент-владелец скилла, вызывает CRUD-операции
- [[landing-references]] — slash-команда этапа 03, запускает сбор референсов и использует этот скилл
