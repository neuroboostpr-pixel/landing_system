# References Collection — управление индексом референсов

## Что делает
Ведёт YAML-индекс визуальных референсов проекта в папке `03_РЕФЕРЕНСЫ/index.yaml`: добавляет, обновляет статус, выводит список и удаляет записи. Это «база данных» ссылок и файлов, которые маркетолог или агент собирает для вдохновения при создании лендинга.

## Когда вызывать / в каком этапе
Используется на **этапе 03** (сбор референсов) как внутренний инструмент агента `references-curator`. Вызывается автоматически, когда нужно сохранить найденный референс, поменять его статус (candidate → approved / rejected) или показать текущий список.

## Что на вход / на выход

**Вход:**
- Путь к папке `03_РЕФЕРЕНСЫ/` проекта (`refs-dir`)
- Подкоманда с аргументами: URL или путь к файлу, желаемый статус, ID записи

**Выход:**
- Обновлённый `index.yaml` с записями референсов
- При `list` / `show` — вывод содержимого индекса в консоль

**Подкоманды:**
| Команда | Действие |
|---|---|
| `add <refs-dir> <ref>` | Добавить URL или файл как кандидата |
| `update <refs-dir> <ref-id> --status <new>` | Сменить статус записи |
| `list <refs-dir> [--status <filter>]` | Показать все или отфильтрованные |
| `show <refs-dir> <ref-id>` | Детали одной записи |
| `remove <refs-dir> <ref-id>` | Удалить запись |

Реализация — Python-скрипт `scripts/index.py`.
