# /landing-moodboard — Генерация визуального мудборда

## Что делает

Собирает визуальный мудборд лендинга в виде HTML-страницы на основе одобренных референсов. Показывает клиенту и команде общее визуальное направление проекта перед тем, как переходить к извлечению стиля.

## Когда вызывать / в каком этапе

Этап **03 — Референсы**. Вызывать вручную командой `/landing-moodboard` после того, как:
- Пройден onboarding (`scripts/setup-flag.sh is_complete`).
- Этап 03 пройдён и статус референсов в `03_РЕФЕРЕНСЫ/index.yaml` выставлен в `approved` (через `/landing-references`).
- `scripts/gate-check.sh --stage 03_references` возвращает exit 0.

Команда НЕ вызывается автоматически оркестратором — только вручную.

## Что на вход / на выход

**Вход:**
- `03_РЕФЕРЕНСЫ/index.yaml` — список одобренных визуальных референсов со статусом `approved`.

**Выход:**
- `03_РЕФЕРЕНСЫ/moodboard.html` — готовый HTML-мудборд для просмотра в браузере.

После того как пользователь утверждает результат, запускается:
```bash
bash scripts/gate-check.sh --stage 03_references --project <project> --approve
```
— это закрывает этап и разрешает переход к следующему шагу (извлечение стиля / бренд-кит).

**HARD GATE:** агент показывает путь к `moodboard.html` и ждёт явного подтверждения пользователя — автоматически не двигается дальше.

## Связанные концепты

- [[moodboard-composer]] — агент, который непосредственно рендерит HTML из `index.yaml`
- [[landing-references]] — предшествующая команда, которая формирует и утверждает список референсов
- [[gate-check]] — скрипт проверки gate-условий этапа перед и после выполнения
- [[landing-brand]] — следующий этап (04), который использует мудборд как основу для бренд-кита
