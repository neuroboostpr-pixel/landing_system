# /landing-style — Стилизация блоков (Stage 08b)

## Что делает

Переводит wireframe-описания из `DESIGN.md §5` в реальный CSS и перезаписывает PHP-шаблоны каждого Lazy Blocks блока. После завершения регенерирует `main.css` и разблокирует `/landing-deploy`.

## Когда вызывать / в каком этапе

Этап **08b**. Вызывается вручную после того, как `/landing-build` получил статус `approved` в `.landing-state.yaml`. Если билд не утверждён — команда остановится с ошибкой на pre-flight.

Поддерживает точечный перезапуск для одного блока: `/landing-style --block hero`.

## Что на вход / на выход

**Вход (read-only для агента):**
- `05_ДИЗАЙН-СИСТЕМА/DESIGN.md` — §1–§9, в том числе wireframes §5 и токены §2–§3
- `08_КОД/block-spec.yaml` — список всех блоков, подлежащих стилизации
- `08_КОД/wp-theme/blocks/lazyblock-*/block.php` — исходные скелеты блоков
- `04_БРЕНД/brand-kit.md` — брендовые цвета и шрифты

**Выход (изменяемые файлы):**
- `DESIGN.md §5` — к каждому `### Block N` добавляется fenced ` ```css ` блок под строкой `**CSS rules:**`
- `wp-theme/blocks/lazyblock-<slug>/block.php` — перезаписывается с маркером `AUTO-GENERATED by frontend-builder` и layout-aware разметкой
- `08_КОД/wp-theme/assets/css/main.css` — полностью регенерируется из обновлённого DESIGN.md

## Шаги выполнения

1. **Pre-flight** — проверка onboarding и gate-check (`08_build` → approved).
2. **Dispatch `frontend-builder`** — агент последовательно проходит по каждому блоку из `block-spec.yaml`, создаёт CSS и обновляет `block.php`.
3. **Регенерация `main.css`** — запускается `extract-main-css.py`.
4. **HARD GATE (авто)** — `gate-check.sh --stage 08b_style`: проверяет маркеры в `block.php`, наличие CSS-блоков в §5 и существование `main.css`. При провале — точечный перезапуск через `--block <slug>`.
5. **HARD GATE (ручной визуал)** — открыть preview, проверить hero/pricing/FAQ/цвета/отсутствие PHP-ошибок. При успехе: `gate-check.sh --approve` → статус `08b_style: approved`.

## Связанные концепты

- [[frontend-builder]] — агент, который выполняет всю работу по генерации CSS и block.php
- [[landing-build]] — должен быть `approved` до запуска; создаёт scaffold и Lazy Blocks pipeline
- [[landing-deploy]] — разблокируется после утверждения stage 08b
- [[wp-gutenberg-block-builder]] — содержит скрипт `extract-main-css.py`, используемый на шаге 3
- [[design-tokens-generation]] — токены из §2–§3 DESIGN.md используются агентом при генерации CSS
