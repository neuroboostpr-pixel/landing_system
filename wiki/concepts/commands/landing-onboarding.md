# Landing Onboarding — мастер первичной настройки

## Что делает

Запускает интерактивный мастер настройки системы для нового пользователя: проверяет все зависимости, помогает ввести API-ключи и фиксирует завершение онбординга. После прохождения система готова к созданию лендингов.

## Когда вызывать / в каком этапе

Вызывается **один раз** перед первым проектом — командой `/landing-onboarding`. Если файл `~/.landing-system/setup_complete` уже существует, команда спрашивает, нужно ли пройти онбординг повторно (например, чтобы добавить новые ключи). Без пройденного онбординга все `/landing-*` команды заблокированы.

## Что на вход / на выход

**Вход:**
- Файл `docs/SETUP.md` — описание системы и требований
- Скрипт `scripts/wizard.sh` — интерактивные проверки
- Скрипт `scripts/setup-flag.sh` — маркировка завершения

**Выход:**
- Файл-флаг `~/.landing-system/setup_complete` — подтверждение, что все зависимости прошли валидацию
- Итоговый отчёт: «Onboarding complete» или список того, что ещё не настроено

## Шаги выполнения

1. Читает `docs/SETUP.md` и рассказывает пользователю, что умеет система.
2. Диспатчит агента `onboarding-guide`.
3. Агент запускает `bash scripts/wizard.sh` и интерактивно проводит через каждую секцию (зависимости, ключи, конфигурация).
4. После успешного прохождения всех валидаторов — запускает `bash scripts/setup-flag.sh mark_complete`.
5. Возвращает финальный статус: всё готово или список незакрытых пунктов.

## Связанные концепты

- [[onboarding-guide]] — специализированный агент, который исполняет мастер-шаги и валидирует ключи
- [[landing-setup]] — скилл, запускаемый командой `/landing-setup`; ближайший аналог для повторной проверки окружения
- [[landing-start]] — следующий шаг после онбординга: создание нового проекта через wizard
