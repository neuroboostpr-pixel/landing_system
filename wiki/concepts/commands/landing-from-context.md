# Создать лендинг из контекста агентства

## Что делает

Команда создаёт новый проект лендинга в `~/Lendings/<slug>/` и автоматически переносит в него контекст из родительской папки агентства — аудиторию, исследования, прототип и прочие наработки. В отличие от `/landing-new`, которая стартует с чистого листа, эта команда делает снимок (snapshot) доступных материалов из текущей директории и подставляет их на место этапов 00–01, пропуская их ручное заполнение. После создания проекта сразу запускается `landing-orchestrator`, начиная с этапа 02 (Материалы).

## Когда вызывается

Пользователь запускает `/landing-from-context <slug>` находясь внутри папки агентского проекта, например `~/Desktop/Агентство лидогенерации/04_документы/курс-копирайтинг/`. Подходит для ситуации, когда часть работы (бриф, исследование ниши, прототип) уже сделана в рамках агентского документооборота, и нужно быстро перенести её в landing-систему без повторного ввода.

## Вход → выход

**Вход:** текущая директория с контекстом агентства (папки типа `01_контекст/`, `05_исследования/`), строка-слаг нового проекта, опциональный флаг `--cinematic`.

**Выход:** папка `~/Lendings/<slug>/` со структурой из 18 подпапок, предзаполненными этапами 00–01 из снимка агентского контекста, запущенный `landing-orchestrator` на этапе 02.

## Failure modes

- Слаг не передан — команда завершается с подсказкой по использованию, проект не создаётся.
- Скрипт `from-context.sh` не найден (переменная `CLAUDE_PROJECT_DIR` не установлена) — bash упадёт с ошибкой `No such file or directory`; нужно убедиться что команда запускается из корня landing-system.
- Родительская папка не содержит ожидаемых подпапок (`01_контекст/` и пр.) — snapshot окажется пустым, этапы 00–01 не будут заполнены; придётся вводить материалы вручную в оркестраторе.
- Папка `~/Lendings/<slug>/` уже существует — возможно частичное перезаписывание файлов без предупреждения (поведение зависит от `from-context.sh`).
- `landing-orchestrator` не запустится, если не пройден онбординг (`~/.landing-system/setup_complete` отсутствует).
