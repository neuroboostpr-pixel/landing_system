# /landing-from-context — Новый лендинг с контекстом агентства

## Что делает

Создаёт новый проект лендинга и автоматически переносит в него исследования, аудиторию и прототип из текущей папки агентства — чтобы не начинать с нуля, если материалы уже есть.

## Когда вызывать / в каком этапе

Вызывается вручную, когда вы уже находитесь в папке агентского проекта (например, `~/Desktop/Агентство лидогенерации/04_документы/курс-копирайтинг/`), в которой есть готовые материалы: исследования (`05_исследования/`), контекст аудитории (`01_контекст/`), прототип и т.д.

Подходит опытным пользователям, которые не хотят проходить wizard `/landing-start`, а сразу хотят создать проект с заполненными начальными этапами.

## Что на вход / на выход

**Вход:**
- `<project-slug>` — обязательный аргумент, kebab-case имя проекта
- `--cinematic` — опциональный флаг (передаётся в скрипт)
- Текущая рабочая директория с файлами агентского проекта (контекст, исследования, прототип)

**Выход:**
- Новая папка `~/Lendings/<slug>/` со структурой из 13+ подпапок (шаблон проекта)
- Снимок (snapshot) контекста из родительской папки — этапы 00–01 частично заполнены автоматически
- Запускается `landing-orchestrator` начиная с этапа 02 (Материалы), минуя уже выполненные шаги

**Под капотом:**
```bash
bash skills/landing-from-context/scripts/from-context.sh ~/Lendings/<slug>
```

## Связанные концепты

- [[landing-orchestrator]] — запускается автоматически после создания проекта, начиная с этапа 02
