# landing-from-context — создание лендинга из папки агентства

## Что делает

Создаёт новый проект лендинга и автоматически импортирует в него уже готовые материалы из родительской папки агентства — аудиторию, исследования, прототип — чтобы не начинать с нуля.

## Когда вызывать / в каком этапе

Используй, когда ты уже находишься в папке клиентского или агентского проекта (например, `~/Desktop/Агентство/04_документы/курс-копирайтинг/`), где есть готовые папки `01_контекст/`, `05_исследования/` и т.п. Команда заменяет `/landing-new` в таких случаях — вместо чистого проекта сразу получаешь проект с предзаполненными данными.

Вызывается вручную пользователем. После создания проекта автоматически запускает `landing-orchestrator`, начиная с этапа 02 (Материалы), так как этапы 00–01 уже частично заполнены из снапшота.

## Что на вход / на выход

**Вход:**
- `<project-slug>` — обязательный аргумент, kebab-case имя нового лендинга
- `--cinematic` — опциональный флаг (передаётся дальше в скрипт)
- Текущая рабочая папка с контентом агентства (источник снапшота)

**Выход:**
- Новая папка `~/Lendings/<slug>/` со структурой из 13+ подпапок (стандартный template)
- Снапшот контекста из родительской папки — предзаполненные этапы 00 и 01
- Запущенный `landing-orchestrator` с этапа 02

**Внутренняя механика:**
Скрипт `skills/landing-from-context/scripts/from-context.sh` получает целевой путь (`$HOME/Lendings/$SLUG` по умолчанию, или абсолютный путь если slug начинается с `/` или `./`).

## Связанные концепты

- [[landing-orchestrator]] — запускается автоматически после создания проекта, ведёт через этапы 02–12
- [[landing-new]] — аналогичная команда для создания чистого проекта без наследования контекста
- [[landing-start]] — wizard для новичков, альтернативная точка входа без готового контекста
