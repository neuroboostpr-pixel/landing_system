# landing-setup — Одноразовая инициализация системы

## Что делает

Запускается один раз при установке landing-system: проверяет зависимости, собирает API-ключи и настраивает конфигурацию интеграций. После успешного завершения система готова к созданию проектов.

## Когда вызывать / в каком этапе

Вызывается вручную **до создания любого проекта-лендинга** — самый первый шаг после установки системы. Не является частью pipeline; это одноразовая операция уровня машины/окружения.

Команда: `/landing-setup`

## Что на вход / на выход

**На вход:**
- Ничего не требует, кроме установленной системы

**Шаги выполнения:**
1. Запускает `scripts/preflight.sh` — проверяет наличие Python, bats, wp-cli, `.env`
2. При неудачных проверках — показывает инструкции по исправлению, ждёт, перезапускает
3. Интерактивно собирает API-ключи (Firecrawl, CRM, деплой)
4. Настраивает выбор интеграций (CRM, аналитика, библиотеки)
5. Показывает итоговый отчёт готовности

**На выход:**
- `.env` — файл с API-ключами (в gitignore, не коммитится)
- `config/system.yaml` — настройки интеграций (коммитится)
- Отчёт о статусе подключённых интеграций в консоли
