# /landing-setup — Одноразовая инициализация системы

## Что делает

Настраивает всю инфраструктуру landing-system перед первым использованием: проверяет зависимости, собирает API-ключи, записывает конфигурацию интеграций и выводит итоговый отчёт о готовности системы.

## Когда вызывать / в каком этапе

Запускается **один раз** при первой установке системы — до создания любых проектов. Если preflight-проверки падают, команда показывает инструкции по исправлению, ждёт и перезапускает проверку. После успешного завершения доступна команда `/landing-new <slug>`.

## Что на вход / на выход

**На вход:**
- Нет обязательных аргументов — команда запускается без параметров
- Интерактивный ввод API-ключей: Firecrawl, CRM, deploy-credentials

**На выход:**
- `.env` — файл с заполненными API-ключами (добавлен в `.gitignore`, не коммитится)
- `config/system.yaml` — настройки выбранных интеграций (CRM, аналитика, JS-библиотеки; коммитится)
- Отчёт о готовности: какие интеграции подключены, какие нет

**Внутренние шаги:**
1. `scripts/preflight.sh` — проверка наличия Python, bats, wp-cli, `.env`
2. При ошибках — вывод инструкций по устранению, повторная проверка
3. Сбор API-ключей и запись в `.env`
4. Выбор интеграций и запись в `config/system.yaml`
5. Финальный отчёт готовности
