# /landing-content — Адаптация текстов под Gutenberg-блоки

## Что делает

Берёт исходный прототип лендинга и превращает его в готовые тексты, разложенные по блокам страницы. Параллельно формирует SEO-копирайтинг: заголовки, мета-описания и варианты H1.

## Когда вызывать / в каком этапе

Этап 07 (контент). Вызывается вручную командой `/landing-content` после того, как пользователь одобрил стек в `06_СТЕК/design-stack.yaml` (команда `/landing-stack`). Перед запуском система проверяет:

- что onboarding пройден (`scripts/setup-flag.sh is_complete`);
- что предыдущий этап закрыт (`scripts/gate-check.sh --stage 07_content`).

Если одна из проверок не пройдена — команда останавливается с поясняющим сообщением.

**HARD GATE:** после генерации агент показывает `final-copy.md` и ждёт явного одобрения пользователя. Без этого переход на этап 08 (сборка кода) невозможен.

## Что на вход / на выход

**Вход:**
- `07_ПРОТОТИП/prototype.md` — исходный текст прототипа
- `06_СТЕК/design-stack.yaml` — структура блоков (создаётся командой `/landing-stack`)
- `DESIGN.md` — общая структура лендинга
- `02_МАТЕРИАЛЫ_КЛИЕНТА/testimonials/` — реальные отзывы клиента

**Выход:**
- `07_КОНТЕНТ/final-copy.md` — финальные тексты, разложенные по каждому Gutenberg-блоку
- `07_КОНТЕНТ/seo-copy.md` — SEO-варианты: title, meta description, h1

После одобрения пользователем запускается:
```
bash scripts/gate-check.sh --stage 07_content --project <project> --approve
```
что фиксирует закрытие этапа в `.landing-state.yaml`.

## Связанные концепты

- [[content-writer]] — агент, которого вызывает команда для написания текстов
- [[landing-stack]] — предыдущий этап; должен быть завершён до запуска
- [[landing-build]] — следующий этап; активируется только после HARD GATE
- [[landing-prototype]] — поставляет `prototype.md`, который служит исходником текстов
