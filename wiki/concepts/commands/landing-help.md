# landing-help — Справка по командам системы

## Что делает

Выводит полный список доступных slash-команд landing-system с кратким описанием каждой. Это справочная страница для быстрой навигации по возможностям системы.

## Когда вызывать / в каком этапе

Вызывается в любой момент работы с системой — не привязан к конкретному этапу. Используй, когда нужно вспомнить название нужной команды или узнать, что уже реализовано, а что ещё в разработке.

## Что на вход / на выход

**Вход:** нет аргументов.

**Выход:** текстовый блок с четырьмя группами команд:

| Группа | Назначение |
|--------|-----------|
| **Entry points** | Создание нового проекта или клонирование |
| **Per-stage** | Команды для конкретных этапов производства (03–08) |
| **Operations** | Деплой, откат, QA |
| **Service** | Статус, справка, обновление системы |

Команды выводятся строго по шаблону, без лишнего текста.

## Список команд (краткий)

- `/landing-new <slug>` — новый проект с нуля
- `/landing-from-context <slug>` — проект из папки агентства
- `/landing-clone <src> --as <new>` — A/B-копия лендинга
- `/landing-references` — этап 03 (референсы)
- `/landing-moodboard` — этап 03 (мудборд)
- `/landing-brand` — этап 04 (бренд-кит)
- `/landing-design` — этап 05 (дизайн-система)
- `/landing-stack` — этап 06 (технический стек)
- `/landing-content` — этап 07 (контент)
- `/landing-build` — этап 08 (сборка темы)
- `/landing-deploy` — деплой на Бегет
- `/landing-rollback <version>` — откат версии
- `/landing-qa` — QA-аудит
- `/landing-status` — текущее состояние проекта

> **Статус реализации:** Phase 1 MVP в процессе. Большинство stage-команд возвращают «not yet implemented». Роадмап — в `docs/superpowers/plans/`.
