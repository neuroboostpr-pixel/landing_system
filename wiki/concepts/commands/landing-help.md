# /landing-help — Справка по командам системы

## Что делает

Выводит полный список слеш-команд landing-system с кратким описанием каждой. Служит быстрым справочником для пользователя — что запустить и на каком этапе.

## Когда вызывать / в каком этапе

Вызывается в любой момент работы с системой — когда нужно вспомнить название команды или понять, что доступно. Не привязана к конкретному этапу pipeline.

## Что на вход / на выход

**Вход:** нет параметров.

**Выход:** фиксированный текстовый блок в терминале со списком всех команд, сгруппированных по категориям:

- **ENTRY POINTS** — команды создания нового проекта (`/landing-new`, `/landing-from-context`, `/landing-clone`)
- **PER-STAGE** — команды для каждого этапа производства (03–08): references, moodboard, brand, design, stack, content, build
- **OPERATIONS** — деплой, передеплой, откат, QA
- **SERVICE** — статус, помощь, обновление системы

Команды, ещё не реализованные в текущей фазе MVP, явно помечены в выводе.

## Связанные концепты

Команда является чисто справочной и не имеет программных связей с другими концептами — она просто перечисляет их.
