# /landing-start — Главная точка входа в landing-system

## Что делает

Запускает интерактивный wizard, который объясняет систему, создаёт папку проекта с нужной структурой и пошагово проводит маркетолога через загрузку материалов (прототип, фото, логотип, референсы). В конце подсказывает следующий шаг — `/landing-go`.

## Когда вызывать / в каком этапе

Вызывается **один раз** в самом начале — перед созданием любого нового проекта. Особенно рекомендуется тем, кто впервые работает с landing-system. Команда не принимает аргументов: всё уточняется в диалоге.

## Что на вход / на выход

**Вход:** ничего. Wizard сам запрашивает имя проекта (kebab-case slug) в процессе диалога.

**Выход:**
- Папка `~/Lendings/<slug>/` с 18 подпапками и README-подсказками внутри каждой.
- Материалы, которые пользователь положил в нужные папки:
  - 🔴 `07_ПРОТОТИП/source/` — `prototype.pdf` или `.md` (обязательно).
  - 🟡 `07c_PHOTOS/inbox/` — фото клиента (рекомендуется).
  - 🟡 `04_БРЕНД/logos/` — логотип (рекомендуется).
  - ⚪ `03_РЕФЕРЕНСЫ/` — референсы (опционально).
- Верификация материалов скриптом `wizard-check-materials.py` после каждого шага.
- Финальная подсказка запустить `/landing-go`.

## Сценарий работы wizard

1. **Welcome** — три параграфа объяснения системы.
2. **Имя проекта** — спрашивает slug.
3. **Создание структуры** — 18 подпапок со встроенными README.
4. **Walkthrough по 4 материалам** — последовательная проверка загрузки каждого типа файлов.
5. **Финиш** — напоминание запустить `/landing-go`.

Прототип — единственный обязательный материал. Без него wizard завершается с ошибкой. Фото, логотип и референсы можно пропустить — система сгенерирует или подберёт их самостоятельно.

## Отличие от /landing-new

| Команда | Для кого | Онбординг |
|---|---|---|
| `/landing-start` | новичок | да, с walkthrough |
| `/landing-new <slug>` | опытный | нет, только создание папки |
