# /landing-start — Главная точка входа в систему

## Что делает

Запускает интерактивный wizard, который за один раз объясняет систему, создаёт папку проекта со всеми нужными подпапками и подсказками, проводит маркетолога через четыре шага материалов (прототип, фото, логотип, референсы) с проверкой каждого шага, и в финале подсказывает запустить `/landing-go`.

## Когда вызывать / в каком этапе

Вызывается **один раз**, в самом начале работы с новым проектом. Это нулевой этап — до любого контента, брендинга и кода. Предназначен для маркетологов, которые впервые знакомятся с системой. Опытные пользователи могут пропустить и сразу взять `/landing-new <slug>`.

## Что на вход / на выход

**Вход:**
- Никаких аргументов. Wizard сам спрашивает имя проекта (kebab-case slug).

**Выход:**
- Папка `~/Lendings/<slug>/` с 18 подпапками и README-подсказками в каждой
- Проверенные материалы в нужных местах:
  - 🔴 `07_ПРОТОТИП/source/` — `prototype.pdf` или `prototype.md` (обязательно, без него wizard выходит с ошибкой)
  - 🟡 `07c_PHOTOS/inbox/` — клиентские фото (рекомендуется, можно пропустить — AI сгенерирует)
  - 🟡 `04_БРЕНД/logos/` — логотип (рекомендуется, можно пропустить)
  - ⚪ `03_РЕФЕРЕНСЫ/` — референсы (опционально)
- Финальная подсказка: «запусти `/landing-go`»

**Важно:** wizard **не запускает** `/landing-go` автоматически — только подсказывает.

## Связанные концепты

- [[landing-onboarding-wizard]] — агент, который реализует всю логику wizard под капотом
- [[landing-new]] — быстрая альтернатива без онбординга, для опытных пользователей
- [[landing-go]] — следующий шаг после wizard; запускает полный pipeline через оркестратор
- [[landing-prototype]] — импорт прототипа (вызывается позже, после `/landing-go`)
