# /landing-start — Точка входа для нового лендинга

## Что делает

Запускает интерактивный wizard, который объясняет систему, создаёт папку проекта со всеми подпапками и проводит маркетолога через 4 шага загрузки материалов (прототип, фото, логотип, референсы) с проверкой каждого шага.

## Когда вызывать / в каком этапе

Вызывается один раз в самом начале работы над новым лендингом — до всех остальных команд. Рекомендуется всем, кто не знаком с системой. Опытные пользователи могут использовать `/landing-new <slug>` напрямую.

## Что на вход / на выход

**Вход:** никаких аргументов — wizard спрашивает всё сам.

**Выход:**
- Папка `~/Lendings/<slug>/` с 18 подпапками и README-подсказками внутри каждой
- Загруженные материалы в нужных директориях (прототип, фото, логотип, референсы)
- Проверка наличия обязательного прототипа через `wizard-check-materials.py`
- Финальная подсказка: запустить `/landing-go`

**Шаги wizard:**
1. Welcome (3 параграфа — объяснение системы)
2. Спрашивает kebab-case slug проекта
3. Создаёт структуру папок
4. Проводит по 4 материалам:
   - 🔴 Прототип (обязательно) → `07_ПРОТОТИП/source/`
   - 🟡 Фото клиента (рекомендуется) → `07c_PHOTOS/inbox/`
   - 🟡 Логотип (рекомендуется) → `04_БРЕНД/logos/`
   - ⚪ Референсы (опционально) → `03_РЕФЕРЕНСЫ/`
5. Проверяет наличие файлов после каждого шага
6. Завершает с подсказкой `/landing-go`

**Важно:** wizard не запускает `/landing-go` автоматически — только подсказывает.
