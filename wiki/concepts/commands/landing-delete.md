# Удаление проекта лендинга

## Что делает

Команда безопасно удаляет папку проекта `~/Lendings/<slug>/` с обязательным интерактивным подтверждением. Вся логика валидации и подтверждения инкапсулирована в скрипте `scripts/landing-delete.sh`. Команда не делает ничего без явного согласия пользователя — это защита от случайного уничтожения данных проекта.

## Когда вызывается

Вызывается вручную пользователем через `/landing-delete <project-slug>`, когда нужно полностью убрать проект из системы. Никаких автоматических триггеров нет — только ручной запуск.

## Вход → выход

**Вход:** slug проекта (аргумент команды), наличие папки `~/Lendings/<slug>/`.

**Выход:** папка проекта удалена (или операция отменена пользователем на шаге подтверждения). Других артефактов команда не создаёт.

## Failure modes

- Slug не передан — скрипт не знает, что удалять; завершится с ошибкой.
- Папка `~/Lendings/<slug>/` не существует — скрипт сообщит об ошибке и ничего не удалит.
- Пользователь не подтвердил удаление — операция отменяется без изменений.
- Скрипт `scripts/landing-delete.sh` отсутствует или недоступен — `bash` вернёт ошибку; команда упадёт до шага подтверждения.
- Недостаточно прав на удаление файлов — системная ошибка при `rm -rf`.
