# Landing Rollback — откат лендинга к предыдущей версии

## Что делает

Откатывает WordPress-тему лендинга к ранее сохранённой версии и сразу передеплоивает сайт на сервер. Позволяет быстро исправить ситуацию, если новый деплой сломал продакшн.

## Когда вызывать / в каком этапе

Вызывается вручную на этапе **09 (деплой / ops)**, когда после деплоя обнаружена проблема и нужно срочно вернуться к работающей версии. Команду запускают **внутри папки проекта-лендинга**.

Пример вызова:
```
/landing-rollback v1.0
```

## Что на вход / на выход

**Вход:**
- Аргумент: имя версии (например, `v1.0`)
- Папка проекта с каталогом `09_ВЕРСИИ/` внутри

**Шаги выполнения:**
1. Показывает список доступных версий (`ls 09_ВЕРСИИ/`)
2. Копирует тему из `09_ВЕРСИИ/<version>/wp-theme` обратно в `08_КОД/wp-theme`
3. Запускает `scripts/deploy.sh .` для повторного деплоя
4. Проверяет, что сайт живой после отката

**Выход:**
- Сайт работает на указанной версии темы
- Консольный отчёт о статусе сайта после отката

## Связанные концепты

- [[landing-deploy]] — команда прямого деплоя, которую rollback по сути повторяет с архивной версией
- [[landing-build]] — этап сборки темы, результаты которого сохраняются в `09_ВЕРСИИ/`
