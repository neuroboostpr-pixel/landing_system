# Landing Rollback — откат лендинга к предыдущей версии

## Что делает

Восстанавливает WordPress-тему лендинга из ранее сохранённой версии и повторно
деплоит сайт на Бегет. Позволяет быстро вернуться к рабочему состоянию после
неудачного обновления.

## Когда вызывать / в каком этапе

Команда относится к операционному этапу 09 (деплой и обслуживание). Вызывается
вручную, когда после деплоя или обновления сайт сломался и нужно откатиться назад.

Формат вызова:
```
/landing-rollback v1.0
```

Где `v1.0` — имя версии из папки `09_ВЕРСИИ/`.

## Что на вход / на выход

**Вход:**
- Имя целевой версии (`v1.0`, `v2.3` и т.п.)
- Наличие сохранённых версий в `09_ВЕРСИИ/<version>/wp-theme`

**Действия по шагам:**
1. Список доступных версий: `ls 09_ВЕРСИИ/`
2. Восстановление темы: `cp -r 09_ВЕРСИИ/<version>/wp-theme 08_КОД/wp-theme`
3. Повторный деплой: `scripts/deploy.sh .`
4. Проверка доступности сайта после отката

**Выход:**
- Сайт восстановлен и работает на выбранной версии темы
- Подтверждение, что сайт живой после rollback
