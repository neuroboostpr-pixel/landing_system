# /landing-wireframe — Интерактивный выбор блоков (этап 07a)

## Что делает

Генерирует интерактивный HTML-файл, в котором пользователь видит 2–3 варианта блоков из библиотеки для каждого раздела прототипа — и выбирает понравившиеся через радио-кнопки прямо в браузере.

## Когда вызывать / в каком этапе

Этап **07a_WIREFRAME**. Вызывать после успешного завершения `/landing-prototype` — когда файл `07_ПРОТОТИП/prototype.yaml` создан и валиден. Может запускаться автоматически через `/landing-go` или вручную этой командой.

## Что на вход / на выход

**Вход:**
- `07_ПРОТОТИП/prototype.yaml` — структурированное описание прототипа (обязательно, должно существовать)

**Выход:**
- `07a_WIREFRAME/wireframe.html` — интерактивный preview с вариантами блоков
- `07a_WIREFRAME/candidates.yaml` — список всех кандидатов на каждый блок

**После действий пользователя:**
- `07a_WIREFRAME/selections.yaml` — файл выбора (создаётся кнопкой «Confirm» в браузере; пользователь вручную кладёт его обратно в папку `07a_WIREFRAME/`)

## Как работает

1. Проверяет наличие `prototype.yaml`.
2. Передаёт задачу агенту `ux-composer`, который подбирает 2–3 блока из block-library под каждый раздел прототипа.
3. Рендерит `wireframe.html` — пользователь открывает его в браузере, выбирает варианты радио-кнопками, нажимает «Confirm» — скачивается `selections.yaml`.
4. Пользователь кладёт `selections.yaml` в `07a_WIREFRAME/`.
5. После одобрения — следующий шаг `/landing-compose`.

## Связанные концепты

- [[landing-prototype]] — предшествующий этап, создаёт `prototype.yaml` как входной артефакт
- [[landing-compose]] — следующий этап после выбора вариантов; собирает `composed.html`
- [[landing-go]] — рекомендуемый способ запуска через оркестратор
- [[ux-composer]] — агент, выполняющий подбор и рендер кандидатов блоков
