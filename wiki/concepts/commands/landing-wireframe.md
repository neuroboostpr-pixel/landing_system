# /landing-wireframe — Интерактивный вайрфрейм

## Что делает

Запускает этап **07a_WIREFRAME**: на основе согласованного прототипа генерирует интерактивный HTML-файл, где для каждого блока предлагается 2–3 варианта из библиотеки. Маркетолог выбирает нужный вариант радиокнопкой, нажимает «Confirm» — скачивается файл выбора.

## Когда вызывать / в каком этапе

Вызывается на этапе **07a**, после того как `07_ПРОТОТИП/prototype.yaml` создан и проверен командой `/landing-prototype`. Запускается автоматически через `/landing-go` (рекомендуется) или вручную этой командой. Этап зафиксирован в `.landing-state.yaml`.

**Условие запуска:** файл `07_ПРОТОТИП/prototype.yaml` существует и валиден.

## Что на вход / на выход

**Вход:**
- `07_ПРОТОТИП/prototype.yaml` — машиночитаемый прототип, созданный на этапе 07

**Выход:**
- `07a_WIREFRAME/wireframe.html` — интерактивный preview (desktop + mobile, CSS-only radio-переключатели между вариантами)
- `07a_WIREFRAME/candidates.yaml` — список кандидатов на каждый блок из библиотеки
- `07a_WIREFRAME/selections.yaml` — создаётся пользователем после нажатия кнопки «Confirm» в браузере; кладётся обратно в папку `07a_WIREFRAME/`

**После одобрения:** запускай `/landing-compose` для сборки `composed.html` с токенами дизайна.

## Связанные концепты

- [[ux-composer]] — агент, выполняющий рендер wireframe.html; выбирает блоки строго из библиотеки, не изобретает новые
- [[landing-compose]] — следующий шаг: инжектирует design-tokens и контент прототипа в выбранные блоки
- [[landing-go]] — рекомендуемый способ запуска; ведёт через все этапы автоматически
- [[prototype-importer]] — предшествующий агент, создающий prototype.yaml из PDF/MD
- [[landing-prototype]] — команда предыдущего этапа (07)
- [[wireframe-rendering]] — скилл, описывающий логику рендера интерактивного wireframe.html
