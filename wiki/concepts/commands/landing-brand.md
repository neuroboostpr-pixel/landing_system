# /landing-brand — Сборка бренд-кита (этап 04)

## Что делает

Запускает агента `brand-architect`, который собирает все извлечённые данные о стиле и создаёт единый файл бренд-кита с визуальным превью: палитра цветов, шрифтовые образцы, иконки.

## Когда вызывать / в каком этапе

**Этап 04 — Бренд.** Вызывать вручную после того, как `/landing-moodboard` завершён и агент `style-extractor` создал файлы `04_БРЕНД/extracted/*.yaml`. До этого команда не запустится — `gate-check` вернёт ошибку с указанием пропущенного шага.

Перед запуском система также проверяет, что онбординг пройден (`setup_complete`). Если нет — предлагает сначала запустить `/landing-onboarding`.

## Что на вход / на выход

**Вход:**
- `04_БРЕНД/extracted/*.yaml` — файлы с извлечёнными стилями (цвета, шрифты, иконки), созданные `style-extractor` после мудборда.

**Выход:**
- `04_БРЕНД/brand-kit.md` — канонический бренд-кит с провенансом (откуда взят каждый элемент стиля).
- `04_БРЕНД/brand-kit.html` — визуальный превью для согласования с заказчиком.

**HARD GATE:** команда не передаёт управление следующему этапу (05 — дизайн-система) без явного подтверждения пользователя после просмотра превью. После подтверждения запускается `gate-check --approve`.

## Связанные концепты

- [[brand-architect]] — агент, который непосредственно синтезирует бренд-кит из raw-данных
- [[landing-moodboard]] — предыдущий этап; его вывод — входные данные для этой команды
- [[landing-design]] — следующий этап; получает `brand-kit.md` как базис для дизайн-системы
- [[gate-check]] — скрипт проверки stage-gates; блокирует выполнение если предыдущий этап не закрыт
