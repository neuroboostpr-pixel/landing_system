# Landing References — сбор визуальных референсов (этап 03)

## Что делает

Собирает и каталогизирует визуальные референсы для лендинга: принимает ссылки или файлы, раскладывает их по статусам (кандидат / одобрен / отклонён), а затем собирает интерактивный HTML-мудборд для утверждения дизайн-направления.

## Когда вызывать / в каком этапе

Команда `/landing-references` запускается вручную на этапе **03_РЕФЕРЕНСЫ** — после завершения этапа 01 (бриф) и до начала этапа 04 (бренд-кит). Перед стартом автоматически проверяется: пройден ли onboarding и закрыт ли предыдущий этап через `gate-check.sh`.

## Что на вход / на выход

**Вход:**
- Аргумент `<project>` или текущий проект из конфига
- URL-ссылки или файлы с визуальными референсами, которые предоставляет пользователь

**Выход:**
- `03_РЕФЕРЕНСЫ/index.yaml` — реестр референсов с полями url, статус, теги
- `03_РЕФЕРЕНСЫ/moodboard.html` — визуальный мудборд-превью для утверждения

**HARD GATE:** команда показывает путь к `moodboard.html` и ждёт явного подтверждения пользователя перед переходом к этапу 04. Без approve дальше не идёт.

## Связанные концепты

- [[references-curator]] — агент, который собирает и тегирует референсы
- [[moodboard-composer]] — агент, рендерящий HTML-мудборд из одобренных референсов
- [[gate-check]] — скрипт проверки прохождения этапов
- [[landing-brand]] — следующий этап после утверждения референсов
- [[landing-moodboard]] — отдельная команда для работы с мудбордом
