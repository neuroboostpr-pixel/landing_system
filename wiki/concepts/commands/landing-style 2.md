# /landing-style — CSS и block.php для этапа 08b

## Что делает

Переводит вайрфреймы из DESIGN.md §5 в production-CSS и PHP-шаблоны блоков. Команда диспатчит агента `frontend-builder`, который для каждого блока из `block-spec.yaml` формирует CSS с медиа-запросами и вписывает его в DESIGN.md §5 фenced-блоком, а затем перезаписывает соответствующий `block.php` в директории темы с маркером автогенерации. После завершения агента запускается тонкий Python-скрипт, который перегенерирует `assets/css/main.css` из обновлённого DESIGN.md целиком.

## Когда вызывается

Вызывается вручную после того, как этап `08_build` утверждён (тема-scaffold и Lazy Blocks pipeline готовы). Также поддерживает режим одного блока: `/landing-style --block <slug>` для повторной обработки конкретного блока.

## Вход → выход

**Вход:** утверждённый `08_build`; DESIGN.md с секцией `## 5. Per-block layouts` и заголовками `### Block N — Name`; `block-spec.yaml` со списком блоков; скелеты `block.php` в папках `lazyblock-*`.

**Выход:** фenced ```css-блоки в DESIGN.md §5 под каждым заголовком блока; перезаписанные `block.php` с маркером `AUTO-GENERATED by frontend-builder`; обновлённый `assets/css/main.css`. Этап закрывается после прохождения четырёх автоматических gate-проверок и ручного визуального approve в браузере.

## Чем закрывается этап (gates)

- `design_md` — файл DESIGN.md присутствует в проекте
- `block_php_markers` — каждый `block.php` начинается с маркера frontend-builder
- `section5_has_css` — каждый `### Block N` в §5 содержит хотя бы один fenced ```css
- `main_css_regenerated` — файл `assets/css/main.css` существует и был пересоздан

## Failure modes

- **`08_build` не утверждён** — gate-check завершится с exit 1 на preflight; нужно сначала запустить `/landing-build`.
- **Отсутствует fenced CSS под `### Block N` после прогона** — агент пропустил блок или упал; запустить `/landing-style --block <slug>` для конкретного блока.
- **`block.php` без маркера** — баг агента; повторить `--block <slug>` и убедиться, что промпт содержит точные байты маркера.
- **Токен отсутствует (`/* TODO: missing token */` в CSS)** — токен не объявлен в DESIGN.md §2; добавить через `/landing-design` и перезапустить `/landing-style`.
- **Визуальный approve не пройден** — несоответствие вайрфрейму; доработать CSS вручную или пере-диспатчить агента, затем повторить approve.
