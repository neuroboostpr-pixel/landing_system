# photo-stylist — Безопасная обработка клиентских фотографий

## Что делает

Обрабатывает «сырые» фотографии клиента для использования в лендинге: вырезает фон, подчищает края, накладывает тени и текстуры. Главное ограничение — лица, возраст и пропорции тела **никогда не изменяются**.

## Когда вызывать / в каком этапе

Этап **02** (материалы клиента). Запускается после того, как клиент передал фотографии. Завершается до перехода к этапу 03 (референсы): перед закрытием этапа пользователь должен утвердить галерею `assets-gallery.html`.

## Что на вход / на выход

**Вход:**
- Оригинальные фото в папке `02_МАТЕРИАЛЫ_КЛИЕНТА/photos/original/`
- Назначение каждой фотографии (hero / about / proof) — уточняется у пользователя

**Выход:**
- Обработанные фото в `02_МАТЕРИАЛЫ_КЛИЕНТА/photos/processed/`
- `02_МАТЕРИАЛЫ_КЛИЕНТА/photos/stylesheet.md` — журнал применённых трансформаций
- `assets-gallery.html` — превью оригиналов и обработанных версий для финального утверждения

## Разрешённые трансформации

| Разрешено | Запрещено |
|---|---|
| Удаление фона (cutout) | Изменение лица, возраста, пропорций |
| Чистка краёв | AI-репейнт человека |
| Тени, бумажные текстуры | Бьюти-ретушь |
| Кадрирование под макет | Face swap / face age change |
| Изменение размера и формата | |

## Ключевое ограничение

Для обработки изображений разрешён **только** скрипт `python3 skills/photo-styling/scripts/style.py`. Нельзя использовать PIL напрямую, внешние редакторы, AI-сервисы или любые другие инструменты. Если нужная операция выходит за рамки `style.py` — агент останавливается и запрашивает решение у пользователя.

## HARD GATE

Этап 03 не начинается, пока пользователь не проверил `assets-gallery.html` и не одобрил обработанные фотографии.
