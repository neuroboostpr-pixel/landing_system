# Frontend Builder — CSS и блоки этапа 08b

## Что делает

Агент переводит визуальные wireframes из DESIGN.md §5 в production-код: для каждого блока формирует фenced-CSS-секцию с BEM-правилами и перезаписывает `block.php` шаблон Lazy Blocks. Работает строго последовательно по порядку из `block-spec.yaml`. Все цвета и размеры — только через CSS-токены из §2; жёстко закодированные значения запрещены. Итогом служит набор готовых к сборке блоков, совместимых с pipeline `extract-main-css.py`.

## Когда вызывается

Вызывается командой `/landing-style` после успешного завершения `/landing-build` (этап 08). Физический gate (`enforce_stage_gate.py`) блокирует запись, пока предшественники не закрыты. При передаче флага `--block <slug>` обрабатывает только один указанный блок.

## Вход → выход

**Вход:** `DESIGN.md` (wireframes §5, токены §2, брейкпоинты §3), `block-spec.yaml` (список блоков и BEM-классы), скелеты `block.php`, `brand-kit.md`, `landing-structure.md`. Все входные файлы — только для чтения, кроме §5 и `block.php`.

**Выход:** В каждый раздел `### Block N` в DESIGN.md §5 добавляется fenced ` ```css ` секция с заголовком `**CSS rules:**`. Каждый `lazyblock-<slug>/block.php` полностью перезаписывается с маркером `AUTO-GENERATED by frontend-builder` и разметкой, соответствующей wireframe.

## Чем закрывается этап (gates)

Этап 08b не имеет отдельного именованного gate в `stage-gates.yaml` — закрытие происходит через общий `gate-check --stage 08_build`. После обработки всех блоков pipeline запускает `extract-main-css.py` → `verify-08_build.sh` → `gate-state.sh approve`.

## Failure modes

- **Токен отсутствует в §2** — агент оставляет `/* TODO: missing token */` и продолжает; `main.css` собирается с CSS-fallback, но визуал может отличаться от дизайна.
- **Секции §5 не в числовом порядке** — CSS-каскад в `main.css` ломается; агент не перестанавливает разделы, только дописывает в конец блока.
- **Дочерние `block.php` repeater-блоков** — `check-block-php-markers.py` выдаёт false-positive exit-1 на sub-block файлах, которые генерирует `generate-lzb-templates.py`, а не этот агент.
- **Stage gate не пройден** — `enforce_stage_gate.py` физически блокирует Write/Edit; обойти нельзя, нужно закрыть предшественника.
- **Wireframe в §5 не описывает мобильную раскладку** — агент применяет single-column stack как fallback, не изобретая собственную адаптацию.
