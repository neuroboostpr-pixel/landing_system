# frontend-builder — Перевод вайрфреймов в CSS и PHP-шаблоны

## Что делает

Берёт вайрфреймы из DESIGN.md §5 и превращает их в настоящий CSS-код (per-block правила) и рабочие PHP-шаблоны блоков Lazy Blocks. После него лендинг визуально совпадает с дизайном.

## Когда вызывать / в каком этапе

Этап **08b**, после команды `/landing-build` (wp-builder уже создал скелет тем). Вызывается автоматически `landing-orchestrator` как часть stage 08, либо вручную с флагом `--block <slug>` для перегенерации одного блока.

## Что на вход / на выход

**Входные артефакты (только чтение):**
- `05_ДИЗАЙН-СИСТЕМА/DESIGN.md` — §5 вайрфреймы, §2 токены, §3 брейкпоинты, §7 motion, §8 a11y (единственный источник истины)
- `04_БРЕНД/brand-kit.md` — контекст бренда
- `01a_АНАЛИЗ_НИШИ/landing-structure.md` — контракт блоков
- `08_КОД/block-spec.yaml` — список блоков, контролы, BEM-классы
- `08_КОД/wp-theme/blocks/lazyblock-<slug>/block.php` — текущий скелет

**Выходные артефакты (агент пишет):**
- `05_ДИЗАЙН-СИСТЕМА/DESIGN.md §5` — в каждую секцию `### Block N` добавляет фenced-блок ` ```css ` с правилами, предварённый строкой `**CSS rules:**`
- `08_КОД/wp-theme/blocks/lazyblock-<slug>/block.php` — полная перезапись с маркером `// AUTO-GENERATED by frontend-builder.`

**Ключевые ограничения:**
- Только CSS-переменные `var(--*)` из §2 — никаких хардкоженных цветов или размеров
- Брейкпоинты в px из §3.2 (не токены `--bp-*`)
- Нулевой JavaScript — аккордеоны через `<details>`, бургер через checkbox-hack
- Не трогает §1–§4, §6–§9, `style.css`, `functions.php`, `assets/js/*`

**Алгоритм:** обрабатывает блоки последовательно по порядку из `block-spec.yaml`. Для каждого: читает спецификацию → читает вайрфрейм →  генерирует CSS → генерирует `block.php` → переходит к следующему. После всех блоков pipeline запускает `extract-main-css.py` для регенерации `main.css`.

**Известное ограничение:** дочерние `block.php` (repeater-паттерны Lazy Blocks, например `lazyblock-faq-item`) принадлежат pipeline и не получают маркер — скрипт `check-block-php-markers.py` даёт по ним false positive exit-1. Планируется фикс в follow-up задаче.
