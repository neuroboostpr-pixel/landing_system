# frontend-builder — Генератор CSS и PHP-шаблонов блоков

## Что делает

Берёт wireframe-схемы из DESIGN.md §5 и превращает их в настоящий CSS-код (на CSS-переменных) и готовые PHP-шаблоны для каждого блока Lazy Blocks. Это финальный шаг визуальной сборки лендинга — после него тема готова к деплою.

## Когда вызывать / в каком этапе

Этап **08b**, запускается автоматически из `/landing-style` после завершения `/landing-build` (этап 08). Агент не стартует, пока в `.landing-state.yaml` не стоит `current_stage == 08_build` и `gate-check.sh` не возвращает exit 0. Если предшественник не закрыт — harness-хук физически блокирует запись файлов.

## Что на вход / на выход

**Вход (только чтение):**
- `05_ДИЗАЙН-СИСТЕМА/DESIGN.md` — wireframes §5, токены §2, брейкпоинты §3, состояния §9
- `04_БРЕНД/brand-kit.md` — бренд-контекст
- `01a_АНАЛИЗ_НИШИ/landing-structure.md` — контракт блоков
- `08_КОД/block-spec.yaml` — перечень блоков, контролов, BEM-классов
- `08_КОД/wp-theme/blocks/lazyblock-<slug>/block.php` — скелеты блоков (только референс)

**Выход (запись):**
- **DESIGN.md §5** — в каждый раздел `### Block N — Name` добавляется именованный блок ` ```css ` (под строкой `**CSS rules:**`). Существующая строка `**CSS:**` с перечнем селекторов не трогается.
- **`08_КОД/wp-theme/blocks/lazyblock-<slug>/block.php`** — файл перезаписывается полностью с маркер-заголовком `// AUTO-GENERATED by frontend-builder.` и разметкой по wireframe.

## Ключевые правила генерации

- **Только токены.** Все цвета, отступы, шрифты — исключительно `var(--token)` из §2. Если токен отсутствует — оставляет `/* TODO: missing token */`, не добавляет токен в §2 сам.
- **Брейкпоинты — литералы px** (из таблицы §3.2): `@media (min-width: 768px) /* md */`. Переменных `var(--bp-*)` не создаёт.
- **Ноль JS.** Аккордеоны через `<details>/<summary>`, бургер через checkbox-hack. Если JS нужен — оставляет `// TODO: needs JS` в block.php.
- **Один helper-класс** на блок допускается (например, `.hero__cta-row`) с комментарием `/* layout-helper */`.
- **Идемпотентность.** Повторный запуск даёт тот же набор селекторов и правил.
- **Дочерние block.php** (repeater-паттерны Lazy Blocks) генерирует `generate-lzb-templates.py`, а не этот агент — они без маркера frontend-builder (известное ограничение).
