# Frontend Builder — CSS и PHP шаблоны блоков

## Что делает

Агент берёт wireframe-описания блоков из DESIGN.md §5 и превращает их в готовый визуальный код: вставляет CSS-правила прямо в §5 (фenced-блок после `**CSS rules:**`) и полностью перезаписывает каждый `block.php` для Lazy Blocks. Работает строго на этапе 08b — после того как `/landing-build` создал скелеты блоков. Обходит блоки по порядку из `block-spec.yaml`, использует только CSS-переменные (`var(--token)`) из §2, не изобретает токены и не трогает JS.

## Когда вызывается

Запускается командой `/landing-style` внутри папки проекта. Предварительное условие — `current_stage == 08_build` в `.landing-state.yaml` и успешный `gate-check.sh --stage 08_build`. Если gate не пройден — агент останавливается и сообщает о проблеме.

## Вход → выход

**Вход:** DESIGN.md (wireframes §5, токены §2, брейкпоинты §3.3), brand-kit.md, landing-structure.md, block-spec.yaml (контролы, BEM-классы), текущие скелеты `block.php` (только для чтения).

**Выход:** DESIGN.md §5 дополнен fenced CSS-блоками под каждым `### Block N`; все `lazyblock-<slug>/block.php` перезаписаны с маркером `// AUTO-GENERATED by frontend-builder` и полной разметкой, соответствующей wireframe. После завершения pipeline запускает `extract-main-css.py` для регенерации `main.css`.

## Failure modes

- **Отсутствует токен в §2** — агент не добавляет токен сам, оставляет комментарий `/* TODO: missing token */` и продолжает с CSS-fallback.
- **Wireframe не описывает адаптивность** — по умолчанию применяется одноколоночный stack; нет гарантии адекватного мобильного вида.
- **Sub-блоки (repeater child)** — `lazyblock-audience-card` и другие дочерние файлы не получают маркер; `check-block-php-markers.py` даёт ложный exit-1 на них (известный false positive).
- **Gate-check блокирует запись** — hook `enforce_stage_gate.py` физически запрещает Write/Edit, если предшественник 08_build не закрыт; агент не должен обходить блокировку.
- **Конфликт CSS-инвентаря** — существующая строка `**CSS:** .class1, .class2` в §5 (авторская) не должна изменяться; если агент её затрёт, каскад `main.css` сломается.
