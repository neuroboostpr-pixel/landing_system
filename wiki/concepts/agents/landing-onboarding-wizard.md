# Landing Onboarding Wizard — Мастер запуска нового проекта

## Что делает

Проводит маркетолога через первичную настройку нового лендинг-проекта: объясняет систему, создаёт папку с нужной структурой и помогает разложить исходные материалы по правильным местам. После завершения проект готов к запуску основного pipeline через `/landing-go`.

## Когда вызывать / в каком этапе

Запускается вручную командой `/landing-start` — всегда первым, до любого pipeline-этапа. Предназначен **только для новых проектов**; к уже существующим не применяется. Не является частью pipeline и не подчиняется Stage Execution Protocol.

## Что на вход / на выход

**Вход:**
- Имя проекта (kebab-case slug) — вводится пользователем интерактивно
- Исходные материалы, которые пользователь кладёт в папки вручную:
  - `07_ПРОТОТИП/source/` — `prototype.pdf` или `prototype.md` (обязательно)
  - `07c_PHOTOS/inbox/` — фото клиента (рекомендуется)
  - `04_БРЕНД/logos/` — логотип и фавикон (рекомендуется)
  - `03_РЕФЕРЕНСЫ/` — URL или скриншоты конкурентов (опционально)

**Выход:**
- Папка `~/Lendings/<slug>/` с 18 подпапками (копия `template/`)
- Материалы верифицированы скриптом `wizard-check-materials.py` по каждому шагу
- Финальная подсказка «Запускай: /landing-go»

## Алгоритм работы

1. **Pre-flight** — проверяет наличие codex CLI и что мы в корне landing-system (папка `template/`).
2. **Welcome** — печатает 3 параграфа приветствия с объяснением системы.
3. **Slug input** — ждёт имя проекта, валидирует kebab-case, проверяет уникальность.
4. **Создание проекта** — вызывает `bash skills/landing-project-init/scripts/init.sh <slug>`.
5. **4 шага материалов** — для каждого шага: объясняет путь, ждёт «готово» или «пропустить», запускает верификацию Python-скриптом. Шаг 1 (прототип) — **обязательный**, пропуск отклоняется.
6. **Итог** — сводка по шагам и подсказка `/landing-go`.

Верификация шагов: `pass` → следующий шаг; `warn` → предупреждение + вопрос; `fail` → повтор шага.

## Ограничения

Мастер **не** запускает `/landing-go` самостоятельно, **не** парсит прототип (это делает `prototype-importer` на этапе 07a), **не** модифицирует существующие проекты.
