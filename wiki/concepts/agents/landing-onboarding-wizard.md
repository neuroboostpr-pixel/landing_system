# landing-onboarding-wizard — Мастер создания нового проекта

## Что делает
Ведёт маркетолога за руку от нуля до готовой папки проекта со всеми материалами. Объясняет систему, создаёт структуру директорий, помогает разложить прототип, фото, логотип и референсы по нужным папкам — и всё это шаг за шагом с проверкой каждого шага.

## Когда вызывать / в каком этапе
Запускается командой `/landing-start` в самом начале работы — до всех остальных этапов workflow. Только для **новых** проектов. Существующие проекты не трогает.

## Что на вход / на выход

**Вход:**
- Имя проекта (kebab-case), которое вводит пользователь
- Файлы материалов, которые пользователь кладёт вручную:
  - `prototype.pdf` или `prototype.md` (обязательно)
  - фотографии клиента в `07c_PHOTOS/inbox/` (рекомендуется)
  - логотип в `04_БРЕНД/logos/` (рекомендуется)
  - референсы в `03_РЕФЕРЕНСЫ/` (опционально)

**Выход:**
- Папка `~/Lendings/<slug>/` с 18 подпапками (скопированными из `template/`)
- Разложенные материалы по соответствующим подпапкам
- Верифицированный результат каждого шага через `scripts/wizard-check-materials.py`
- Подсказка запустить `/landing-go` для продолжения

## Процесс (5 фаз)

1. **Pre-flight** — проверяет наличие `codex CLI` и что работаем внутри landing-system repo.
2. **Welcome** — печатает 3 абзаца объяснения системы, запрашивает slug.
3. **Создание проекта** — вызывает `skills/landing-project-init/scripts/init.sh <slug>`, копирует template.
4. **4 шага материалов** — интерактивно для каждого шага: показывает путь, объясняет что класть, ждёт «готово» / «пропустить», проверяет через `wizard-check-materials.py`. Шаг 1 (прототип) пропустить **нельзя**.
5. **Финальный итог** — показывает результаты всех шагов, советует `/landing-go`.

## Что НЕ делает
- Не запускает `/landing-go` самостоятельно — это явный шаг пользователя.
- Не парсит прототип — это задача [[prototype-importer]] на этапе 07a.
- Не модифицирует существующие проекты.

## Связанные концепты
- [[landing-project-init]] — скилл создания папки проекта, вызывается на фазе 3
- [[prototype-importer]] — следующий шаг после wizard, парсит `prototype.pdf`
- [[brand-architect]] — генерирует текстовый логотип, если логотип не предоставлен
- [[references-curator]] — подбирает референсы, если папка осталась пустой
- [[landing-go]] — команда, которую wizard рекомендует в финале
