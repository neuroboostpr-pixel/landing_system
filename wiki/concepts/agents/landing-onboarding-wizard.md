# Landing Onboarding Wizard — мастер запуска нового проекта

## Что делает

Проводит маркетолога за руку от нуля до готовой папки проекта с нужными материалами. Объясняет систему тремя абзацами, создаёт структуру папок и собирает все исходники (прототип, фото, логотип, референсы) прежде чем отпустить к полному пайплайну.

## Когда вызывать / в каком этапе

Вызывается командой `/landing-start` в самом начале — до любых этапов pipeline. Работает только при создании **нового** проекта: не трогает существующие папки и не запускает деплой. Это нулевой этап — bootstrap перед всей системой.

## Что на вход / на выход

**Вход:**
- Пользователь вводит slug проекта (kebab-case, например `stroyka-pro`)
- Файлы, которые маркетолог кладёт руками:
  - `prototype.pdf` / `prototype.md` — **обязательно** в `07_ПРОТОТИП/source/`
  - Фото клиента — рекомендуется, в `07c_PHOTOS/inbox/` (7 подпапок)
  - Логотип — рекомендуется, в `04_БРЕНД/logos/`
  - Референсы — опционально, в `03_РЕФЕРЕНСЫ/`

**Выход:**
- Папка `~/Lendings/<slug>/` с 18 подпапками и README-подсказками (копия `template/`)
- Материалы разложены по нужным местам
- Проверка каждого шага через `scripts/wizard-check-materials.py`
- Итоговый summary с подсказкой запустить `/landing-go`

## Процесс

1. **Pre-flight** — проверяет наличие `template/` и codex CLI (`scripts/install-codex.sh --check`)
2. **Welcome** — печатает 3 абзаца-объяснения дословно, запрашивает slug
3. **Создание проекта** — вызывает `skills/landing-project-init/scripts/init.sh <slug>`
4. **4 шага материалов** — для каждого: инструкция → «готово» / «пропустить» → проверка скриптом
   - Шаг 1 (прототип) обязателен, пропуск не принимается
   - Шаги 2–4 опциональны — wizard поясняет fallback (AI-генерация/references-curator)
5. **Финал** — итоговый summary + команда `/landing-go`

## Ограничения

Wizard **не запускает** `/landing-go` сам — пользователь начинает пайплайн явно. Не модифицирует уже существующие проекты. Не парсит прототип — это задача [[prototype-importer]] на этапе 07a.

## Связанные концепты

- [[landing-project-init]] — скилл, создающий папку проекта с 18 подпапками по шаблону
- [[landing-go]] — главная команда пайплайна, которую wizard рекомендует запустить в финале
- [[prototype-importer]] — агент, который обрабатывает `prototype.pdf` на этапе 07a (после wizard)
- [[references-curator]] — подбирает референсы самостоятельно, если маркетолог пропустил шаг 4
