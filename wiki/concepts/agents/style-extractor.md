# Style Extractor — агент извлечения визуального стиля

## Что делает

Анализирует утверждённые референсы (изображения и URL) и извлекает из них готовую к коду систему стилей: палитру цветов, шрифты, иконки, сетку и параметры анимации. Результат — 5 структурированных файлов, которые становятся основой для дальнейшей работы бренд-архитектора.

## Когда вызывать / в каком этапе

Запускается автоматически на **этапе 04 (brand)** после того, как мудборд утверждён пользователем. Предусловие: в `.landing-state.yaml` должно быть `current_stage == 04_brand`. Если предшественники не закрыты, hook `enforce_stage_gate.py` физически заблокирует запись файлов.

## Что на вход / на выход

**Вход:**
- `03_РЕФЕРЕНСЫ/index.yaml` — список референсов со статусом `approved`
- Изображения и URL из утверждённых референсов

**Выход** — 5 файлов в `04_БРЕНД/extracted/`:
- `palette.yaml` — цветовая палитра
- `fonts.yaml` — типографика
- `icons.yaml` — иконки (подобраны через match-icons.py)
- `grid.md` — параметры сетки
- `motion.md` — параметры анимации/движения

**HARD GATE:** все 5 файлов обязаны существовать до запуска `brand-architect`. Если хотя бы один отсутствует — переход к следующему этапу заблокирован.

## Как работает внутри

1. Читает `03_РЕФЕРЕНСЫ/index.yaml`, отбирает только `approved`-референсы.
2. Для изображений → `extract-palette.py` (палитра из пикселей).
3. Для URL → `identify-fonts.py` (определение шрифтов со страниц).
4. `match-icons.py` → подбор иконок под стандартный список нужд.
5. `orchestrate.py` → агрегирует все выходы в единую структуру.
6. Если `grid.md` / `motion.md` ещё не существуют — создаёт плейсхолдеры.
7. После успешного прогона: `verify-04_brand.sh` → `gate-state.sh approve`.
