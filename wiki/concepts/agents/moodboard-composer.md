# Moodboard Composer — сборка мудборда

## Что делает

Берёт одобренные референсы из `03_РЕФЕРЕНСЫ/index.yaml` и собирает два артефакта: текстовое описание визуального направления (`moodboard.md`) и наглядную HTML-доску с карточками референсов (`moodboard.html`). Результат — общий знаменатель по палитре, типографике и ощущению будущего лендинга.

## Когда вызывать / в каком этапе

Запускается на **этапе 03** после того, как `references-curator` пометил нужные референсы статусом `approved`. Агент не запускается раньше — необходим утверждённый набор референсов. После завершения мудборд передаётся на **HARD GATE**: пользователь открывает `moodboard.html` и подтверждает направление. Только после этого стартует `style-extractor`.

## Что на вход / на выход

**Вход:**
- `03_РЕФЕРЕНСЫ/index.yaml` — список референсов со статусом `approved`
- `01a_АНАЛИЗ_НИШИ/niche-analysis.md` — секция 6 «Что брать с собой» задаёт уместный визуальный язык
- `01a_АНАЛИЗ_НИШИ/visual-requirements.md` — секции 1, 2, 3, 5, 6 определяют требования к визуалу; референсы из red flag (секция 6) не включаются

**Выход:**
- `03_РЕФЕРЕНСЫ/moodboard.md` — нарратив: палитра, типографика, motion, что берём / что отвергаем
- `03_РЕФЕРЕНСЫ/moodboard.html` — визуальная доска с карточками референсов (генерируется скриптом `skills/moodboard-creation/scripts/render.py`)

**Инструменты:** Bash, Read, Write, Glob, вызов `render.py`.

## Процесс работы

1. Читает `index.yaml`, фильтрует только `approved`-референсы.
2. Для каждого референса запрашивает у пользователя теги (например: `split-screen`, `warm-palette`, `premium-typography`).
3. Пишет `moodboard.md` с описанием визуального направления.
4. Запускает `render.py` для генерации HTML-доски.
5. Ждёт явного одобрения пользователя перед передачей эстафеты.

## Связанные концепты

- [[references-curator]] — поставляет утверждённые референсы (index.yaml), без которых агент не запускается
- [[style-extractor]] — следующий этап: извлекает конкретные цвета, шрифты, иконки из одобренного мудборда
- [[niche-analyst]] — поставляет niche-analysis.md и visual-requirements.md, которые ограничивают выбор референсов
