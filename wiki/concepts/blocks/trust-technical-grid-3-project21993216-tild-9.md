# Блок гарантий и поддержки — сетка карточек с иконками

## Что делает

Отображает гарантии или преимущества компании в виде равномерной сетки из трёх карточек. Каждая карточка содержит иконку и короткое пояснение. Подходит для секций «Почему мы» и «Наши гарантии».

## Когда вызывать / в каком этапе

Используется на этапе **07a (UX Wireframe)** агентом [[ux-composer]], когда в прототипе есть секция доверия, гарантий или технической поддержки. Блок отбирается из библиотеки по категории `trust` и паттерну `grid-3`. Подходит для ниш tech, b2b-saas, services, ecommerce на российском рынке.

## Что на вход / на выход

**Вход:**
- `heading` (text, обязательный) — заголовок секции гарантий
- Иконки для каждой карточки (берутся из слотов блока или генерируются [[icon-generator]])
- Короткие тексты-пояснения под каждой иконкой (заполняются из `prototype.yaml` на этапе 07b)

**Выход:**
- HTML-фрагмент блока в составе `wireframe.html` (этап 07a)
- Затем инжектируется в `composed.html` (этап 07b) через [[block-composer]] с подставленными design-токенами и текстами из прототипа
