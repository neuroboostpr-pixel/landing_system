# Animation Fade-Out — плавное исчезновение элемента

## Что делает
CSS-паттерн анимации: элемент плавно исчезает с помощью keyframe-анимации `fade-out`. Используется для скрытия блоков, всплывающих подсказок, оверлеев и любых UI-элементов, которые должны уходить со страницы с визуальным эффектом затухания.

## Когда вызывать / в каком этапе
Подключается на этапе **07b (Compose)** или **08 (Build)** — когда блоки страницы требуют анимационной обратной связи при скрытии. Применяется дизайнером или block-composer'ом при добавлении интерактивных состояний в `composed.html` или в финальные PHP-шаблоны Lazy Blocks.

## Что на вход / на выход

**Вход:**
- CSS-класс или JS-триггер, назначающий анимацию целевому элементу.
- Опционально: переменные длительности и задержки через CSS custom properties.

**Выход:**
- Готовый CSS keyframe `@keyframes fade-out` с переходом `opacity: 1 → 0`.
- Утилитарный класс (`.lp-fade-out` или аналог) для подключения анимации к любому элементу.

Нет явных связей в исходнике.
