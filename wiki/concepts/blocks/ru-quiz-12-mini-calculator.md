# Квиз — мини-калькулятор стоимости

## Что делает

Встраивает в квиз ориентировочный расчёт цены прямо на странице: пользователь выбирает параметры услуги (радио-кнопки или range), видит диапазон стоимости — и только после этого соглашается оставить контакт. Никакого JavaScript: вся «калькуляция» реализована через CSS-селектор `:checked`.

## Когда вызывать / в каком этапе

Используется на этапе **07b (block-compose)**, когда [[block-composer]] собирает `composed.html` из блоков библиотеки. Подходит для лендингов сферы **услуг (b2c, local)**: ремонт, монтаж, клининг, юридические/медицинские услуги — любая ниша, где цена зависит от 1–2 ключевых параметров. Категория: `quiz`.

## Что на вход / на выход

**Входные слоты (текстовые):**

| Слот | Обязательный | Макс. символов |
|---|---|---|
| `headline` | да | 100 |
| `param-1-label` | да | 60 |
| `param-1-opt-1` / `param-1-opt-2` | да | 50 |
| `param-2-label` | нет | 60 |
| `param-2-opt-1` / `param-2-opt-2` | нет | 50 |
| `result-prefix` | да | 40 |
| `cta-button` | да | 50 |

**На выход:** готовый HTML-блок квиза, который вставляется в `composed.html`. Под вопросами отображается строка вида «Ваша стоимость: от X ₽» — значение статичное, определяется комбинацией выбранных radio через CSS `:checked`.

**Конверсионная механика:** показ ценового диапазона мотивирует пользователя оставить контакт, чтобы узнать точную цифру. Источники практики: Marquiz (блог), Skillbox (кейсы калькуляторных квизов).
