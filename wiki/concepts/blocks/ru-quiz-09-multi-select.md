# ☑️ Квиз — вопрос с мульти-выбором (чекбоксы)

## Что делает

Блок квиза с возможностью выбрать несколько вариантов ответа сразу — вместо radio-кнопок используются чекбоксы. Пользователь отмечает всё подходящее и жмёт «Далее». Блок работает на чистом CSS без JS.

## Когда вызывать / в каком этапе

Используется на этапах **07a (wireframe)** и **07b (compose)** при сборке квизовой воронки. Подходит для вопросов, где пользователь должен указать сразу несколько характеристик: например, «Какие услуги вас интересуют?» или «Что важно при выборе?». Актуален для ниш: услуги (services), b2c-продукты, локальный бизнес (local).

## Что на вход / на выход

**Входные слоты:**

| Слот | Обязателен | Макс. символов | Описание |
|---|---|---|---|
| `question-text` | ✅ | 120 | Текст вопроса |
| `option-1` | ✅ | 60 | Первый вариант |
| `option-2` | ✅ | 60 | Второй вариант |
| `option-3`…`option-6` | ❌ | 60 | Дополнительные варианты |
| `next-button` | ✅ | 30 | Подпись кнопки «Далее» |
| `progress-label` | ❌ | 60 | Текст прогресс-бара сверху |

**На выход:** HTML-блок с чекбоксами, прогресс-баром и кнопкой перехода. CSS-анимация состояний `:checked` без подключения JS.

**Конверсионная заметка:** множественный выбор собирает больше данных о потребностях клиента. Пользователь чувствует, что его лучше понимают — это повышает доверие и конверсию в заявку. Источники практики: Tilda Education, Marquiz.
