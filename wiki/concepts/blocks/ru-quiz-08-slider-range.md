# Квиз — вопрос со слайдером диапазона

## Что делает
Блок добавляет в квиз один шаг: пользователь тянет ползунок и задаёт числовой параметр — бюджет, площадь, срок или любой другой диапазон. Над ползунком показывается прогресс-бар, под ним — текущее значение и единица измерения. Никакого JavaScript не нужно: работает на нативном `input[type=range]`.

## Когда вызывать / в каком этапе
Используется на этапе **07b (Compose)** — когда `block-composer` собирает `composed.html` из выбранных блоков. Подходит для сайтов услуг, B2C и локального бизнеса (`services`, `b2c`, `local`). Выбирается на этапе **07a (Wireframe)** — `ux-composer` предлагает его как вариант слайдера вместо текстового поля, когда вопрос квиза требует числового ответа.

## Что на вход / на выход

**На вход (слоты):**

| Слот | Макс. символов | Обязательный |
|---|---|---|
| `question-text` — текст вопроса | 120 | да |
| `unit-label` — единица измерения (руб., м², дней) | 20 | да |
| `min-label` — подпись минимального значения | 30 | да |
| `max-label` — подпись максимального значения | 30 | да |
| `question-comment` — пояснение под вопросом | 100 | нет |
| `progress-label` — метка прогресс-бара | 60 | нет |

**На выход:**
Готовый HTML-фрагмент шага квиза, встраиваемый в `composed.html`. Значение ползунка передаётся в форму без JS — браузерный механизм `<input type=range>`.

## Почему снижает трение
По данным Tilda Education и Skillbox, ползунок сегментирует аудиторию по бюджету эффективнее, чем текстовое поле: пользователь не боится «назвать цифру», просто двигает слайдер. Подходит для первого или второго шага квиза, где важно быстро отсеять нецелевые лиды по бюджету или площади.
