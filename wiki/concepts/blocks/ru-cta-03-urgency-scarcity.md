# ⏰ Полоса срочности — осталось X мест

## Что делает

Акцентная полоса оранжевого цвета, которая создаёт ощущение дефицита: показывает оставшееся количество мест или дату окончания акции. Работает без JavaScript-таймера — только текст, без динамики.

## Когда вызывать / в каком этапе

Используется на этапе **07a (Wireframe)** при выборе CTA-блока с триггером срочности. Подходит для услуг, B2C-продуктов и локального бизнеса, когда нужно усилить конверсию через ограниченность предложения — по количеству мест или по дате.

## Что на вход / на выход

**На вход (слоты):**
| Слот | Тип | Обязательный | Макс. символов | Описание |
|---|---|---|---|---|
| `urgency-label` | text | да | 60 | Основная фраза дефицита («Осталось X мест», «Акция до...») |
| `seats-count` | text | нет | 5 | Конкретное число мест |
| `deadline-date` | text | нет | 30 | Дата окончания акции |
| `subhead` | text | нет | 120 | Поясняющий подзаголовок |
| `primary-cta` | cta | да | — | Кнопка, по умолчанию «Успеть получить» |

**На выход:** HTML-блок — оранжевая полоса с крупным текстом счётчика/даты, подзаголовком и одной CTA-кнопкой. Встраивается в `wireframe.html` и `composed.html`.

**Важное ограничение:** не обманывать пользователя — если указана дата окончания, акция должна действительно завершаться в этот срок. Источник: «Как создать сайт-шедевр», стр. 29.
