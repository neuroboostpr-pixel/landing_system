# ⏰ Полоса срочности — осталось X мест

## Что делает
Оранжевая акцентная полоса с текстом дефицита («Осталось X мест» или «До конца акции — N дней»), подзаголовком и одной кнопкой призыва к действию. Работает без JavaScript-таймера — только текст и визуальный акцент.

## Когда вызывать / в каком этапе
Используется на этапе 07b (compose) и 08 (build) при сборке CTA-блоков для услуг, B2C-предложений и локального бизнеса. Подходит, когда нужно создать ощущение дефицита по количеству мест или по дате окончания акции — без сложной JS-логики.

## Что на вход / на выход

**Вход (слоты):**
| Слот | Тип | Обязателен | Ограничение |
|---|---|---|---|
| `urgency-label` | text | ✅ да | до 60 символов |
| `seats-count` | text | нет | до 5 символов |
| `deadline-date` | text | нет | до 30 символов |
| `subhead` | text | нет | до 120 символов |
| `primary-cta` | cta | ✅ да | default: «Успеть получить» |

**Выход:** HTML-блок с оранжевым фоном, крупным текстом счётчика/даты и кнопкой CTA. Без таймеров и скриптов — только статический контент.

## Важные ограничения
Согласно источнику: если указана дата окончания акции — **держать слово**. Ложный дефицит разрушает доверие. Дефицит по количеству и по дате — один из сильнейших конверсионных триггеров (источник: «Как создать сайт-шедевр», стр. 29).
