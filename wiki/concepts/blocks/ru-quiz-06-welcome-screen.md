# Квиз — стартовый экран «Начать тест»

## Что делает

Показывает пользователю мотивирующий экран перед началом квиза: крупный заголовок с обещанием пользы, подзаголовок с выгодой, опциональный лид-магнит (подарок за прохождение) и большая кнопка «Начать тест». Никаких вопросов — только разогрев аудитории и снижение барьера входа.

## Когда вызывать / в каком этапе

Используется на этапе **07a (Wireframe)** при сборке квизовых лендингов. Блок ставится первым в последовательности quiz-блоков — до любых вопросов. Подходит для сервисных ниш (b2c, локальный бизнес), где нужно убедить пользователя начать опрос, а не уйти.

## Что на вход / на выход

**Вход (слоты meta.yaml):**

| Слот | Тип | Лимит | Обязателен |
|---|---|---|---|
| `headline` | text | 80 симв. | да |
| `subheadline` | text | 150 симв. | да |
| `lead-magnet` | text | 100 симв. | нет |
| `cta-button` | text | 40 симв. | да |
| `trust-note` | text | 80 симв. | нет |

**Выход:**
- Центрированный HTML-блок (wireframe-вариант на этапе 07a)
- Итоговый HTML с токенами и текстами (composed.html на этапе 07b)

## Конверсионная логика

Welcome-экран повышает конверсию квиза: пользователь видит выгоду ещё до начала опроса. Лид-магнит («получите результат + подарок») дополнительно снижает психологический барьер. Источники: Tilda Education, Skillbox.
