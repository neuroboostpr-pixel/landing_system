# Контактная секция — корпоративная сетка с двумя карточками адресов

## Что делает
Отображает контактную информацию компании на ярком фоне: две крупные карточки с адресами, дополненные декоративными объектами. Подходит для корпоративного стиля — строго, заметно, читаемо.

## Когда вызывать / в каком этапе
Используется на этапе **07a (UX Wireframe)** — агент [[ux-composer]] выбирает этот блок из библиотеки при формировании wireframe.html, если прототип предусматривает раздел «Контакты» с двумя точками присутствия (офис, склад, шоурум и т.п.). Также задействуется на этапе **07b** при сборке composed.html через [[block-composer]].

Подходит для ниш: **услуги** (services) и **электронная коммерция** (ecommerce). Ориентирован на **российский рынок** (`ru_market: true`).

## Что на вход / на выход

**Вход:**
- Обязательный слот `heading` (тип: text) — заголовок раздела контактов.
- Контент двух адресных карточек (адреса, телефоны, режим работы — передаются при наполнении блока).

**Выход:**
- HTML-блок с двумя карточками адресов на ярком фоне, встраиваемый в wireframe.html или composed.html.
- Без анимаций (`has_animation: false`) — блок статичный, без JS-зависимостей.
