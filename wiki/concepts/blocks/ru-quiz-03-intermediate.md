# 🎉 Квиз — промежуточный мотивационный экран

## Что делает

Промежуточный экран, который появляется между шагами квиза: большое эмодзи, поощрительный текст и кнопка «Продолжить». Удерживает пользователя в квизе — снижает abandon rate на 15–25%, создавая эмоциональный момент одобрения.

## Когда вызывать / в каком этапе

Используется на этапе **07b (Block Compose)** — `block-composer` вставляет блок в composed.html, когда в прототипе описан многошаговый квиз и нужны промежуточные экраны мотивации. Актуален для ниш: услуги, B2C, локальный бизнес (`ru_market: true`).

## Что на вход / на выход

**Входные слоты (все обязательные):**

| Слот | Тип | Ограничение |
|---|---|---|
| `emoji-icon` | text | одно эмодзи (напр. 🎉, 👍, 🔥) |
| `motivation-text` | text | до 100 символов поощрительного текста |
| `continue-cta` | cta | текст кнопки, по умолчанию «Продолжить» |

**Выход:**
- HTML-блок промежуточного экрана, встроенный в `07b_COMPOSED/composed.html` между шагами квиза.
- Placeholders для визуального контента отсутствуют — блок текстовый, генерации фото/иконок не требует.

## Связанные концепты

- [[block-composer]] — агент этапа 07b, вставляет блок в composed.html с токенами и контентом из прототипа
- [[ux-composer]] — агент этапа 07a, выбирает этот блок при рендере wireframe.html для квиз-флоу
- [[block-library-management]] — скилл управления библиотекой, хранит мета-описание блока
- [[block-composition]] — скилл, описывающий правила компоновки блоков на этапе 07b
- [[prototype-importer]] — парсит прототип, на основе которого ux-composer выбирает блоки квиза
