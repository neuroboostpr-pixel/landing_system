# Hover Effect 03 — Item 3

## Что делает
Готовый CSS-паттерн hover-эффекта, извлечённый с реального сайта. Применяется к элементам блоков для добавления визуальной реакции на наведение курсора без написания стилей с нуля.

## Когда вызывать / в каком этапе
Используется на этапе **07b (Compose)** и **08 (Build)** при сборке блоков, которым нужна интерактивная анимация при hover. Подключается дизайнером или block-composer'ом при выборе визуального стиля элементов карточек, кнопок или списков. Не требует отдельной команды — импортируется как CSS-паттерн из библиотеки блоков.

## Что на вход / на выход

**Вход:**
- Ссылка на паттерн из `block-library/_patterns/hover-effect-03-item-3/`
- HTML-элемент (карточка, пункт списка, кнопка), к которому нужно применить эффект

**Выход:**
- CSS-стили hover-эффекта, встроенные в тему или блок
- Визуальная реакция элемента на наведение (анимация/трансформация)
