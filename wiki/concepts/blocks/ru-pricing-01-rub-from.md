# 💰 3 тарифа с ценой «от X ₽»

## Что делает
Показывает три тарифных карточки в один ряд — Базовый, Стандарт, Премиум — с ценой в формате «от X ₽», списком из пяти пунктов с галочками и кнопкой «Выбрать». Средний тариф автоматически подсвечивается как «Популярный».

## Когда вызывать / в каком этапе
Используется на этапе **07a (Wireframe)** при выборе блока ценообразования для российского рынка. Подходит для услуг (b2c, локальный бизнес), где цена нефиксирована и начинается «от» определённой суммы. UX-composer выбирает этот блок, если прототип содержит тарифную секцию с тремя уровнями.

## Что на вход / на выход

**Вход (слоты):**
| Слот | Тип | Обязательный | Макс. символов |
|---|---|---|---|
| `headline` | text | да | 60 |
| `tier-1-name` / `tier-2-name` / `tier-3-name` | text | да | 20 |
| `tier-1-price` / `tier-2-price` / `tier-3-price` | text | да | 20 |
| `tier-1-features` / `tier-2-features` / `tier-3-features` | text | да | — |
| `tier-1-cta` / `tier-2-cta` / `tier-3-cta` | cta | да | default: «Выбрать» |

**Выход:**
- HTML-фрагмент с тремя карточками, готовый к вставке в `wireframe.html` (этап 07a) и `composed.html` (этап 07b)
- Средняя карточка получает визуальный акцент «Популярный» без дополнительного слота

## Примечания по конверсии
Формат «от X ₽» снижает ценовой барьер — пользователь видит минимальный порог входа, а не пугающую итоговую цену. Выделение среднего тарифа создаёт **якорный эффект**: крайние варианты воспринимаются как «слишком дёшево» и «слишком дорого», а средний — как оптимальный выбор.
