# Animation: checkIconScale

## Что делает
CSS-паттерн, который добавляет анимацию масштабирования иконки галочки (check icon) через keyframe-анимацию. Используется для визуального акцента при появлении элементов подтверждения — например, при успешной отправке формы или в списках преимуществ.

## Когда вызывать / в каком этапе
Подключается на этапе 07b (Compose) или 08 (Build) при вёрстке блоков, где нужна анимированная иконка галочки. Не является самостоятельным блоком — это CSS-примитив, который встраивается в другие блоки через класс или keyframe-правило.

## Что на вход / на выход
- **Вход:** нет специфических параметров; паттерн применяется через CSS-класс к любому элементу с иконкой галочки.
- **Выход:** CSS keyframe-анимация `checkIconScale`, которая масштабирует иконку (обычно `scale(0) → scale(1)`) с эффектом появления.
