# 📊 Сравнительная таблица тарифов

## Что делает
Отображает три тарифных плана в виде таблицы сравнения 3×6: три колонки-тарифа и шесть строк с характеристиками. Средний тариф автоматически подсвечивается акцентным фоном для усиления якорного эффекта. В нижней строке — кнопки CTA для каждого тарифа.

## Когда вызывать / в каком этапе
Используется на этапе **07b (Block Compose)** при сборке `composed.html`. Подходит для лендингов услуг, B2C-продуктов и локального бизнеса, где нужно сравнить 2–3 ценовых пакета. Вставляется агентом `block-composer` по результатам `prototype.yaml` или выбору пользователя в wireframe.

## Что на вход / на выход

**На вход (слоты):**
- `headline` — заголовок секции, до 60 символов (обязательный)
- `tier-1-name`, `tier-2-name`, `tier-3-name` — названия тарифов, до 20 символов каждый
- `tier-1-price`, `tier-2-price`, `tier-3-price` — цена каждого тарифа, до 20 символов
- `tier-1-cta`, `tier-2-cta`, `tier-3-cta` — тексты кнопок (дефолт: «Выбрать»)
- `feature-row-1` … `feature-row-6` — строки с описанием характеристик, до 60 символов каждая

**Все 16 слотов обязательные.**

**На выход:**
- HTML-блок таблицы сравнения, интегрированный в `07b_COMPOSED/composed.html`
- Матрица ✓/✗ захардкожена в шаблоне, кастомизируется под проект вручную

**Адаптив:** мобильная версия — горизонтальный скролл (`overflow-x: auto`), JavaScript не требуется.

**Конверсия:** средний тариф (`tier-2`) подсвечен акцентным цветом из `tokens.json` — классический якорный эффект, склоняющий пользователя к среднему чеку.
