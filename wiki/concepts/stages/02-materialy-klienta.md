# 02_МАТЕРИАЛЫ_КЛИЕНТА — Материалы клиента (устаревшее)

## Что делает

Папка-заглушка для клиентских материалов из старых проектов. В современном prototype-first flow этот этап помечен как `n/a` — используется только для обратной совместимости со старыми проектами, где фотографии и документы клиента складывались сюда вручную.

## Когда вызывать / в каком этапе

Этап **02** в шаблоне проекта. В новых проектах, созданных через `/landing-start` или `/landing-go`, этот этап **пропускается** (`n/a`). Актуален только если проект был создан до внедрения PR-B и PR-E workflow.

## Что на вход / на выход

**Вход:**
- Фотографии клиента (ранее складывались в `02_МАТЕРИАЛЫ_КЛИЕНТА/photos/original/`)
- Прочие документы клиента

**Выход:**
- Ничего не генерируется. Папка служит лишь резервным источником для `photo-curator`, который сканирует её наряду с актуальным путём `07c_PHOTOS/inbox/` для поддержки старых проектов.

**Куда переехало:**
| Тип материала | Новый путь |
|---|---|
| Фото клиента | `07c_PHOTOS/inbox/` |
| Логотипы | `04_БРЕНД/logos/` |

## Связанные концепты

- [[photo-curator]] — сканирует оба пути (`02_МАТЕРИАЛЫ_КЛИЕНТА/photos/original/` и `07c_PHOTOS/inbox/`) для backward-совместимости
- [[07c-photos]] — актуальная папка для фото в PR-B pipeline
- [[04-brend]] — актуальная папка для логотипов (PR-E wizard)
- [[landing-photos]] — команда PR-B, обрабатывает фото из `07c_PHOTOS/inbox/`
- [[landing-start]] — wizard PR-E, направляет пользователя сразу в правильные папки
