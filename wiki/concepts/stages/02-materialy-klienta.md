# 02_МАТЕРИАЛЫ_КЛИЕНТА — Материалы клиента (legacy)

## Что делает
Папка-хранилище для исходных материалов клиента — фотографий и документов. В новых проектах не используется: заменена более специализированными папками.

## Когда вызывать / в каком этапе
Этап помечен как `n/a` в prototype-first flow — то есть в стандартном новом проекте эта папка не задействуется. Актуальна только для **старых проектов**, созданных до введения PR-B pipeline.

## Что на вход / на выход
**Вход:** фотографии и документы клиента, загруженные вручную.

**Выход:** нет — папка является хранилищем, а не обрабатывающим этапом. Агент `photo-curator` (PR-B) сканирует путь `02_МАТЕРИАЛЫ_КЛИЕНТА/photos/original/` для обратной совместимости.

## Связанные концепты
- [[07c-photos]] — актуальная папка для фото клиента в новых проектах (`07c_PHOTOS/inbox/`)
- [[04-brend]] — актуальная папка для логотипов клиента (`04_БРЕНД/logos/`)
- [[photo-curator]] — PR-B агент, сканирует оба пути (старый и новый) для backward compat
