# Stage 03 — Референсы

## Что делает
Собирает список лендингов-образцов, на которые будет ориентироваться дизайн. Маркетолог или агент кладут сюда ссылки и скриншоты сайтов, которые нравятся по стилю, нише или отдельным блокам.

## Когда вызывать / в каком этапе
Этап 03. Заполняется на стадии сбора материалов — сразу после создания проекта через `/landing-start` (шаг «Референсы» в wizard) или автоматически агентом [[references-curator]]. Является необязательным шагом (опциональные материалы).

## Что на вход / на выход

**Вход:**
- Список URL лендингов-образцов с пометками (ниша, что нравится)
- Опциональные скриншоты

**Выход:**
- `index.yaml` — структурированный список референсов со статусами (`candidate` / `approved` / `rejected`)
- `screenshots/` — папка со скриншотами (опционально)

Формат `index.yaml`:
```yaml
references:
  - url: https://example.com/landing-1
    note: "Похожая ниша, нравится hero"
    status: candidate
```

## Связанные концепты
- [[landing-start]] — wizard на шаге «Референсы» предлагает добавить URL в эту папку
- [[references-curator]] — агент, который может автоматически наполнить `index.yaml`
