# Project Memory Folder — память сессий по проекту

## Что делает
Хранит автоматические записи всех разговоров с Claude Code в рамках одного лендинг-проекта. Папка ведётся машиной — вручную не редактируется.

## Когда вызывать / в каком этапе
Папка `memory/` создаётся при инициализации проекта командой `/landing-new` или `/landing-start` как часть структуры шаблона. Файлы внутри появляются автоматически через хуки `SessionEnd` и `PreCompact` после каждой рабочей сессии.

## Что на вход / на выход

**Вход:**
- Транскрипты сессий Claude Code (хуки пишут автоматически)

**Выход:**
- `daily/YYYY-MM-DD.md` — сырые логи сессий за каждый день
- `compiled/index.md` — скомпилированные уроки и решения по проекту
- `compiled/concepts/` — концепты по конкретным архитектурным решениям
- `compiled/qa/` — ответы из `query.py --file-back`

## Правила использования

1. **Не редактировать вручную** — папка управляется хуками, ручные правки будут перезаписаны.
2. **Конфиденциальность** — папка добавлена в `.gitignore`, поскольку транскрипты могут содержать детали клиента. Для передачи знаний команде нужно вручную экспортировать нужные файлы.
3. **Один проект — одна папка** — `memory/` живёт внутри конкретного лендинга (`~/Lendings/<slug>/memory/`), а не в системной папке `~/.landing-system/`.

## Связанные концепты
- [[lifecycle-keeper]] — агент управления версиями; логи из `memory/` могут содержать историю этапов для rollback-сценариев
- [[landing-orchestrator]] — главный дирижёр; хуки записи памяти срабатывают в рамках его workflow
- [[landing-project-init]] — скилл создания проекта; он же разворачивает шаблон с папкой `memory/`
