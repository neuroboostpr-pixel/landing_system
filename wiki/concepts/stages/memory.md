# template/memory — Память сессий проекта

## Что делает
Хранит историю разговоров Claude Code с проектом лендинга: сырые логи по дням, скомпилированные уроки и концепты. Это долгосрочная память конкретного лендинга — что решали, к чему пришли, какие ошибки уже разбирали.

## Когда вызывать / в каком этапе
Папка создаётся автоматически при инициализации проекта из шаблона. Файлы внутри появляются автоматически — через хуки `SessionEnd` и `PreCompact` без участия пользователя. Вручную редактировать содержимое не нужно и не рекомендуется.

## Что на вход / на выход

**На вход:**
- Автоматические записи хуков после каждой сессии Claude Code
- Сырые транскрипты и логи разговоров

**На выход:**
- `daily/YYYY-MM-DD.md` — сырые логи сессий за конкретный день
- `compiled/index.md` — скомпилированные уроки и ключевые решения
- `compiled/concepts/` — концепты по отдельным архитектурным или продуктовым решениям
- `compiled/qa/` — ответы из `query.py --file-back`

## Особенности

**Конфиденциальность:** папка добавлена в `.gitignore` — транскрипты могут содержать клиентские детали. Если нужно поделиться знаниями с командой, нужно вручную экспортировать нужные файлы.

**Изоляция по проекту:** каждый лендинг имеет свою `memory/` — история одного проекта не смешивается с другими.
