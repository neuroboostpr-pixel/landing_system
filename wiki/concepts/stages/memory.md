# template-memory — Папка памяти сессий проекта

## Что делает
Хранит автоматические логи разговоров с Claude Code по конкретному лендинг-проекту: сырые записи сессий, скомпилированные уроки и принятые решения. Позволяет агентам и пользователю восстанавливать контекст между сессиями без повторного объяснения истории проекта.

## Когда вызывать / в каком этапе
Папка создаётся автоматически при инициализации проекта и наполняется на протяжении всего жизненного цикла лендинга. Файлы не редактируются вручную — они генерируются хуками `SessionEnd` и `PreCompact` после каждой завершённой сессии.

## Что на вход / на выход

**Вход:**
- Автоматические события хуков `SessionEnd` / `PreCompact` после сессий Claude Code.

**Выход:**
- `daily/YYYY-MM-DD.md` — сырые логи сессий за конкретный день.
- `compiled/index.md` — скомпилированный индекс уроков и ключевых решений.
- `compiled/concepts/` — отдельные концепт-файлы по конкретным техническим решениям.
- `compiled/qa/` — ответы из `query.py --file-back` (поиск по истории).

## Конфиденциальность
Папка добавлена в `.gitignore` — транскрипты могут содержать клиентские детали. Для совместного использования знаний с командой нужно вручную экспортировать нужные файлы.
