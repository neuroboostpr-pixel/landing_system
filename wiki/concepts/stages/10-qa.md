# 10_QA — Этап контроля качества

## Что делает
Автоматически проверяет задеплоенный лендинг по трём направлениям: скорость страницы (PageSpeed), доступность (accessibility) и SEO. Формирует отчёт с результатами аудита.

## Когда вызывать / в каком этапе
Этап запускается **автоматически после деплоя** (этап 09). Инициирует агент `qa-auditor` без участия пользователя. Находится в цепочке: 09_DEPLOY → 10_QA → 11_SEO.

## Что на вход / на выход

**Вход:**
- Задеплоенный сайт на Бегете (результат этапа 09)

**Выход:**
- `qa-report.md` — сводный отчёт по проверкам (PageSpeed, accessibility, SEO)
- `lighthouse.json` — сырые данные Lighthouse audit

## Связанные концепты
- [[qa-auditor]] — агент, который создаёт артефакты этого этапа
- [[landing-qa]] — slash-команда для ручного запуска QA-проверки
- [[landing-audit]] — slash-команда для SEO/tech аудита (этап 11)
- [[landing-deploy]] — предшествующий этап (09), после которого запускается QA
