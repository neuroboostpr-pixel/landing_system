# 11_АНАЛИТИКА — Настройка аналитики и событий

## Что делает
Хранит конфигурацию счётчиков аналитики (Яндекс.Метрика / Google Analytics) и список событий для отслеживания пользовательских действий на лендинге.

## Когда вызывать / в каком этапе
Этап 11 — запускается автоматически оркестратором после деплоя лендинга (этап 09). Не требует ручного вмешательства.

## Что на вход / на выход

**Вход:**
- Утверждённый задеплоенный лендинг (этапы 08–09 закрыты)
- Параметры проекта (домен, тип бизнеса, целевые действия)

**Выход:**
- `analytics-config.md` — настройки счётчиков Яндекс.Метрики и/или GA4
- `events.yaml` — перечень событий для отслеживания (клики по CTA, отправка форм, прокрутка и т.д.)

## Связанные концепты
- [[analytics-engineer]] — агент, который генерирует конфиг и список событий для этого этапа
