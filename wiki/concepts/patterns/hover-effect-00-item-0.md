# Hover Effect 00 — Item 0

## Что делает
CSS-паттерн hover-эффекта, извлечённый с реального сайта методом css-pattern-extraction. Добавляет интерактивную реакцию элемента при наведении курсора — используется для оживления блоков лендинга без JavaScript.

## Когда вызывать / в каком этапе
Применяется на этапе **07b (Block Compose)**, когда `block-composer` собирает `composed.html` из выбранных блоков и внедряет дизайн-токены. Паттерн подключается как CSS-утилита к элементам блока — карточкам, кнопкам, иконкам — там, где нужна визуальная реакция на hover.

Не вызывается напрямую пользователем; используется агентом или скиллом автоматически при сборке блока, которому назначен данный паттерн.

## Что на вход / на выход

**Вход:**
- `meta.yaml` — метаданные паттерна (id, тип, название, дата импорта, метод импорта)
- CSS-правила паттерна из папки `hover-effect-00-item-0/`

**Выход:**
- CSS-стили hover-эффекта, встроенные в `composed.html` или в таблицу стилей блока
- Визуально интерактивный элемент лендинга без дополнительного JS

## Связанные концепты
- [[block-composer]] — агент этапа 07b, который применяет паттерн при сборке composed.html
- [[block-composition]] — скилл, управляющий процессом подбора и внедрения паттернов в блоки
- [[block-library-management]] — скилл, отвечающий за каталог блоков и паттернов, включая импорт из реальных сайтов
