# Stage Agent Preamble (канонический блок)

## Что делает

Определяет обязательный блок предусловий, который каждый агент-владелец этапа (stage-owner agent) обязан включать сразу после YAML-frontmatter и заголовка. Блок заставляет агента перед любым Write/Edit действием прочитать `.landing-state.yaml`, отрисовать Mermaid-карту пайплайна, создать TodoWrite-список оставшихся этапов, запустить `gate-check.sh` и дождаться exit 0. Это закрывает архитектурную брешь: без единого канонического шаблона каждый агент, вызванный напрямую (минуя оркестратор), мог обходить пайплайн-лок.

## Когда вызывается

Применяется при создании нового агента-владельца этапа или при аудите существующих. Если агент не содержит этого блока — он считается несоответствующим стандарту и подлежит правке. `PreToolUse` хук `scripts/hooks/enforce_stage_gate.py` физически блокирует Write/Edit к файлам этапа, если предшественники не закрыты.

## Вход → выход

**Вход:** markdown-файл нового агента с YAML-frontmatter; известен ID этапа (`<STAGE>`).
**Выход:** агент с вставленным 7-шаговым блоком «ОБЯЗАТЕЛЬНЫЕ предусловия», где `<STAGE>` заменён на реальный ID (например, `04_brand`). Агент теперь умеет самостоятельно читать state, рисовать карту, создавать todo, проверять гейты и закрывать этап через `gate-state.sh approve`.

## Failure modes

- Агент скопирован без замены `<STAGE>` — gate-check бежит с буквальной строкой вместо реального ID, этап не найден, пайплайн падает.
- Блок вставлен в `landing-orchestrator.md` вместо его расширенного варианта — оркестратор теряет soft-warning/hard-lock различие и специфичные ссылки.
- Хук `enforce_stage_gate.py` не установлен — блок присутствует в тексте, но физической блокировки нет; агент может пропустить шаги под давлением пользователя.
- Агент не вызывает `verify-<STAGE>.sh` по завершении — этап технически «done», но `approved` не выставлен, следующий агент застревает на gate-check.
- Разработчик дрейфует формулировки блока между агентами — функциональный смысл сохраняется, но ссылки на `stage-execution-protocol.md` устаревают при переименовании файла.
