# refresh-catalog — регенерация каталога блоков

## Что делает
Пересобирает файл `block-library/catalog.yaml`, сканируя все существующие папки блоков в библиотеке — как старые (`ru-*`), так и новые импортированные. Результат — актуальный реестр всех доступных блоков для системы.

## Когда вызывать / в каком этапе
Запускается вручную после добавления или удаления блоков из `block-library/`. Также может вызываться скриптами импорта блоков (команда `/landing-import-blocks`) для поддержания каталога в актуальном состоянии. Не привязан к конкретному этапу pipeline — это служебная утилита уровня системы.

## Что на вход / на выход

**Вход:**
- Папки блоков в `block-library/` — все поддиректории с метаданными (`meta.yaml`)

**Выход:**
- Обновлённый `block-library/catalog.yaml` — единый реестр блоков со всеми полями из `meta.yaml`

## Связанные концепты
- [[block-library-management]] — скилл управления библиотекой блоков, в рамках которого используется этот скрипт
- [[landing-import-blocks]] — команда импорта новых блоков, после которой нужно обновить каталог
