# Session Start Hook — инъекция wiki-индекса при старте сессии

## Что делает
Автоматически печатает wiki-индекс системы и индекс памяти проекта в stdout при каждом старте сессии Claude Code — так агент сразу «знает», где он находится и что делал в прошлый раз, без лишних вопросов.

## Когда вызывать / в каком этапе
Запускается автоматически через механизм `SessionStart` в Claude Code. Пользователь ничего не вызывает вручную — хук отрабатывает сам при открытии сессии в любой папке landing-system.

## Что на вход / на выход

**Вход:**
- `stdin` — JSON с текущей рабочей директорией (`cwd`) сессии.

**Выход (в stdout — инжектится как system context):**
- Если `cwd` внутри `landing-system/` → содержимое `landing-system/wiki/index.md`.
- Если `cwd` похож на `~/Lendings/<slug>/` → содержимое `<slug>/wiki/index.md` + последний daily log проекта.
- Если оба пути актуальны (например, работаем в landing-system над конкретным проектом) → **оба** индекса одновременно.

**Важно:** скрипт быстрый (< 1 сек), без сетевых вызовов, без побочных эффектов.

## Логика определения контекста

| Условие | Что инжектируется |
|---|---|
| `cwd` ⊆ `landing-system/` | Системный wiki-индекс |
| `cwd` ⊆ `~/Lendings/<slug>/` | Проектный wiki + daily log |
| Оба условия верны | Системный + проектный |

## Связанные концепты
- [[wiki]] — системная wiki, индекс которой читает хук
- [[memory]] — папка памяти проекта, откуда берётся `MEMORY.md`
- [[landing-orchestrator]] — главный агент, которому хук предоставляет контекст о текущем проекте
