# wiki-query — CLI-запросы к системной wiki

## Что делает

Позволяет задать вопрос на естественном языке и получить ответ из wiki landing-system прямо в терминале. Работает как со всей системой, так и с конкретным проектом.

## Когда вызывать / в каком этапе

Используется в любой момент — не привязан к конкретному этапу пайплайна. Полезен, когда нужно быстро найти информацию об агенте, команде или концепте системы без ручного листания файлов wiki. Вызывается вручную из CLI разработчиком или маркетологом.

## Что на вход / на выход

**Вход:**
- Вопрос на естественном языке (строка)
- Опциональный флаг `--project=<slug>` — ограничивает поиск wiki конкретного проекта
- Опциональный флаг `--file-back` — включает сохранение ответа в файл

**Выход:**
- Ответ из wiki, выведенный в stdout
- При флаге `--file-back`: файл ответа сохраняется в `memory/qa/`

**Примеры вызова:**
```bash
python -m scripts.wiki.query "что делает landing-orchestrator"
python -m scripts.wiki.query "как работает photo-curator" --project=dubai-avto-liza
python -m scripts.wiki.query "какие этапы у пайплайна" --file-back
```

## Связанные концепты

- [[memory]] — при флаге `--file-back` ответы сохраняются в папку памяти проекта (`memory/qa/`)
- [[landing-orchestrator]] — типичный объект запроса; query.py часто используется чтобы разобраться, что делает оркестратор
