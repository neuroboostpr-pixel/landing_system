# sdk_client.py — обёртка Claude Agent SDK для wiki-компилятора

## Что делает
Предоставляет единую точку доступа к Claude Agent SDK внутри wiki-компилятора. Принимает текст исходника концепта, отправляет запрос модели `sonnet` и возвращает готовую wiki-страницу в markdown. В юнит-тестах функция `_sdk_query()` подменяется моком — реальный API не вызывается.

## Когда вызывать / в каком этапе
Вызывается автоматически изнутри `compile.py` при сборке wiki (`python -m scripts.wiki.compile --source-mode=system`). Напрямую пользователем не вызывается. Срабатывает на каждый концепт, чей хэш изменился с прошлого прогона.

## Что на вход / на выход

**Вход:**
- Текст исходника концепта (markdown или yaml) — передаётся как строка в `_sdk_query()`
- Конфигурация модели (по умолчанию `sonnet`)
- Авторизация через `~/.claude/auth.json` — ключ `ANTHROPIC_API_KEY` **не** нужен, используется подписка Claude Code

**Выход:**
- Строка — готовая wiki-страница в markdown с frontmatter, соответствующая шаблону компилятора
- В тестах: фиктивная строка, возвращённая моком `_sdk_query`

## Ключевые детали реализации
- Использует **async API версии 0.2.x** (`claude_agent_sdk.query`)
- Модель `sonnet` выбрана как баланс скорости и стоимости — для задачи компиляции wiki-концептов `opus` избыточен
- Авторизация через локальный auth.json делает модуль независимым от CI-секретов при локальной сборке
- Мок-слой в тестах изолирует логику компилятора от сетевых вызовов: юнит-тесты проходят без интернета и без ключей
