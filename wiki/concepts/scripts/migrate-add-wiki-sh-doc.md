# migrate-add-wiki — добавление wiki и memory к проекту

## Что делает
Миграционный bash-скрипт, который дополняет существующий проект-лендинг двумя папками: `wiki/` (локальная wiki проекта) и `memory/` (персистентная память). Запускается один раз для «старых» проектов, созданных до введения wiki-инфраструктуры.

## Когда вызывать / в каком этапе
Вызывается вручную, вне основного pipeline. Нужен в двух случаях:
- Проект был создан командой `/landing-new` или `/landing-from-context` до появления wiki-системы (до 2026-05-15).
- После `git pull` нового кода системы старый проект не имеет папок `wiki/` и `memory/`, и агенты сообщают об их отсутствии.

Скрипт **не трогает** уже существующие данные проекта — он только дополняет недостающее.

## Что на вход / на выход

**Вход:**
- Путь до папки существующего проекта: `~/Lendings/<slug>` (передаётся аргументом).

**Команда запуска:**
```bash
bash scripts/migrate-add-wiki.sh ~/Lendings/<slug>
```

**Выход:**
- Папка `<project>/wiki/` — создаётся с базовой структурой.
- Папка `<project>/memory/` — создаётся с базовой структурой.
- Скрипт идемпотентен: повторный запуск не ломает уже существующее.

## Связанные концепты
- [[memory]] — папка `memory/` проекта, которую скрипт инициализирует; хранит MEMORY.md и контекст агентов.
- [[wiki]] — папка `wiki/` проекта, которую скрипт инициализирует; хранит локальные wiki-страницы конкретного лендинга.
