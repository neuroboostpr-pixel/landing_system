# migrate-niche-to-v2 — Миграция анализа ниши до v2

## Что делает

Переводит устаревшую структуру папки `01a_АНАЛИЗ_НИШИ/` в формат niche-analysis v2. Скрипт идемпотентный — запускать повторно безопасно: он никогда не затирает уже существующие файлы, только создаёт недостающие.

## Когда вызывать / в каком этапе

Нужен при работе со старыми проектами, где нише-анализ был сделан до обновления системы до v2. Перед запуском `niche-analyst` в таком проекте следует прогнать этот скрипт, чтобы структура папки соответствовала тому, что агент ожидает на входе.

Типичный сценарий: открываешь существующий проект, видишь в `01a_АНАЛИЗ_НИШИ/` только старые файлы без `market-profile.md` или `landing-structure.md` — запускаешь миграцию.

## Что на вход / на выход

**Вход:**
- Один аргумент: `<project-dir>` — путь к папке проекта-лендинга (например, `~/Lendings/my-project`).

**Что делает скрипт (по порядку, только если файл/заголовок отсутствует):**
1. Добавляет строку `Mode: legacy_v1` в заголовок `01a_АНАЛИЗ_НИШИ/positioning.md`.
2. Создаёт заглушку `01a_АНАЛИЗ_НИШИ/market-profile.md` (не перезаписывает, если уже есть).
3. Создаёт заглушку `01a_АНАЛИЗ_НИШИ/landing-structure.md` (не перезаписывает, если уже есть).

**Выход:**
- Изменённые/созданные файлы внутри `<project-dir>/01a_АНАЛИЗ_НИШИ/`.
- Скрипт не трогает ничего вне этой папки.

**Запуск:**
```bash
bash scripts/migrate-niche-to-v2.sh ~/Lendings/my-project
```
