# landing-go-next-stage — определение следующего этапа

## Что делает
Читает файл `.landing-state.yaml` текущего проекта и выводит идентификатор следующего этапа, который нужно выполнить. Если все этапы завершены — выводит `DONE`.

## Когда вызывать / в каком этапе
Используется внутри команды `/landing-go` и агентом `landing-orchestrator` как вспомогательный инструмент для определения, куда двигаться дальше по pipeline. Вызывается автоматически — вручную запускать не нужно.

## Что на вход / на выход

**Вход:**
- `.landing-state.yaml` — файл состояния проекта с отметками о завершённых и незавершённых этапах (должен существовать в корне проекта).

**Выход:**
- `stdout` — идентификатор следующего actionable этапа (например, `03`, `07b`, `08`).
- Если все этапы помечены как `approved` — выводит строку `DONE`.

Скрипт не изменяет файл состояния — только читает.

## Связанные концепты
- [[landing-go]] — главная команда, которая использует этот скрипт для определения следующего шага
- [[landing-orchestrator]] — оркестратор pipeline, диспатчит этапы на основе вывода скрипта
- [[stage-gates]] — правила, по которым этап считается завершённым и может быть пропущен
