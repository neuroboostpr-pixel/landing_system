# state_yaml.py — парсер файла состояния проекта

## Что делает
Читает файл `.landing-state.yaml` из папки лендинг-проекта и превращает его в Python-словарь с двумя ключевыми полями: текущий активный этап (`current_stage`) и список одобренных этапов (`approved`). Это базовый строительный блок, на котором держится вся логика отслеживания прогресса проекта.

## Когда вызывать / в каком этапе
Парсер вызывается автоматически при каждом обращении к состоянию проекта — не вручную. Используется внутри wiki-компилятора (`scripts/wiki/`) при построении графа проекта в режиме `--source-mode=project-graph`, а также любым компонентом системы, которому нужно узнать, на каком этапе находится проект прямо сейчас.

## Что на вход / на выход

**Вход:**
- Путь к файлу `.landing-state.yaml` конкретного проекта (например, `~/Lendings/my-project/.landing-state.yaml`).

**Выход:**
- Python `dict` с полями:
  - `current_stage` — идентификатор текущего активного этапа (например, `"07b"`)
  - `approved` — список этапов, уже прошедших HARD GATE и подтверждённых пользователем

## Связанные концепты
- [[landing-orchestrator]] — главный агент, который читает состояние проекта для принятия решений о следующем шаге
- [[stage-gates]] — правила HARD GATE, которые определяют, что именно записывается в `approved`
- [[landing-go]] — команда, запускающая оркестратор; читает `.landing-state.yaml` как первый шаг
- [[landing-status]] — команда отображения прогресса; использует тот же файл состояния
