# wiki-utils — утилиты для сборки wiki

## Что делает
Набор вспомогательных функций на Python, которые используются всеми скриптами wiki-компилятора: генерация slug из произвольного текста (включая кириллицу), разбор и запись YAML frontmatter в markdown-файлы, атомарная запись файлов на диск.

## Когда вызывать / в каком этапе
Не вызывается напрямую пользователем — это внутренняя библиотека, которую импортируют `compile.py` и другие скрипты из `scripts/wiki/`. Задействована каждый раз при сборке или обновлении wiki (хук `post-commit`, команда `python -m scripts.wiki.compile`).

## Что на вход / на выход

**Функция `slugify(text)`**
- Вход: произвольная строка (русская или латинская)
- Выход: kebab-case slug (например `"Анализ ниши"` → `"analiz-nishi"`)

**Функция `parse_frontmatter(text)`**
- Вход: полный текст markdown-файла
- Выход: кортеж `(metadata: dict, body: str)` — разобранный YAML-заголовок и тело

**Функция `write_with_frontmatter(path, metadata, body)`**
- Вход: путь к файлу, словарь метаданных, текст тела
- Выход: записывает готовый markdown с frontmatter на диск атомарно

**Функция `atomic_write(path, content)`**
- Вход: путь и строка контента
- Выход: файл создаётся через временный `.tmp-*` файл + `os.replace`, что гарантирует отсутствие «полуфайлов» при сбое

## Детали реализации

- Транслитерация кириллицы выполняется по встроенной таблице `CYRILLIC_MAP` (32 символа), без внешних зависимостей.
- `atomic_write` создаёт родительские папки автоматически (`mkdir -p`), временный файл хранится в той же директории что и целевой — это необходимо для корректной работы `os.replace` на одной файловой системе.
- При исключении в процессе записи временный файл удаляется — нет «мусора» на диске.
