# migrate-template-readmes.sh — миграция README в существующий проект

## Что делает

Копирует недостающие README-файлы из канонического шаблона `template/` в папку уже существующего проекта. Если в проекте не хватает каких-то подпапок (например `04_БРЕНД/logos/`), скрипт создаёт их. Существующие файлы **не перезаписываются** — операция идемпотентна.

## Когда вызывать / в каком этапе

Используется при **миграции старых проектов** на новую структуру PR-E (Onboarding Wizard). Вызывать вручную один раз, если проект был создан до введения системы `/landing-start` и в его папках отсутствуют README с подсказками по материалам.

```bash
bash scripts/migrate-template-readmes.sh ~/Lendings/<existing-project>
```

Также упоминается в CLAUDE.md как рекомендованный шаг после обновления системы.

## Что на вход / на выход

**Вход:**
- Путь к папке существующего проекта (`<project_dir>`) — единственный аргумент.
- Наличие `template/` в корне `landing-system/` с актуальной структурой 18 подпапок.

**Выход:**
- Добавленные README-файлы в те подпапки проекта, где их не было.
- Созданные недостающие подпапки (например `04_БРЕНД/logos/`).
- Существующие файлы остаются без изменений — повторный запуск безопасен.

## Связанные концепты

- [[landing-start]] — основная команда PR-E, которая создаёт новые проекты с правильной структурой сразу; данный скрипт — эквивалент для старых проектов
- [[landing-project-init]] — скилл инициализации проекта, формирует ту же структуру папок изнутри системы
- [[04-brend]] — этап бренда; скрипт в том числе создаёт `04_БРЕНД/logos/` если её нет
