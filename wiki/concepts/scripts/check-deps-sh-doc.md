# check-deps.sh — проверка зависимостей системы

## Что делает
Скрипт проверяет наличие всех инструментов, необходимых для работы landing-system, и сообщает, что установлено, а что отсутствует. При нехватке хотя бы одной зависимости — завершается с ошибкой и подсказывает команды установки.

## Когда вызывать / в каком этапе
Запускать **перед началом работы** с системой — особенно на новой машине или после клонирования репозитория. Рекомендован как первый шаг перед `/landing-setup` и `/landing-start`. CLAUDE.md явно указывает: «Перед работой проверь: `scripts/check-deps.sh`».

```bash
bash scripts/check-deps.sh
```

## Что на вход / на выход

**Вход:** ничего (не требует аргументов).

**Выход:**
- `stdout` — список зависимостей с отметками `✅` / `❌` и версией найденного инструмента
- `exit 0` — все зависимости найдены, можно работать
- `exit 1` — одна или несколько зависимостей отсутствуют; выводится список команд установки для macOS и Linux

**Проверяемые зависимости:**

| Инструмент | Команда | Зачем |
|---|---|---|
| `bats-core` | `bats` | тесты bash-скриптов (TDD) |
| `git` | `git` | версионирование проектов |
| `node` | `node` | JS-зависимости, сборка |
| `bash` | `bash` | интерпретатор самой системы |

**Подсказки по установке:**
- macOS: `brew install bats-core node git`
- Linux: `apt-get install bats node git`
