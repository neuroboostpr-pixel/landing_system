# Session End Hook — хук завершения сессии

## Что делает
Запускает фоновый процесс `flush.py` в момент завершения Claude-сессии. Это нужно для того, чтобы данные сессии (транскрипт разговора) были обработаны и сохранены без задержки закрытия интерфейса.

## Когда вызывать / в каком этапе
Вызывается автоматически системой Claude Code при каждом завершении сессии через механизм `SessionEnd`-хуков. Пользователю не нужно запускать его вручную. Хук срабатывает в фоне — пользователь не видит и не ждёт его выполнения.

## Что на вход / на выход

**Вход:**
- Контекст завершаемой сессии (транскрипт, метаданные) — передаётся неявно через окружение хука.

**Выход:**
- Запущенный detached-процесс `flush.py`.
- Сам хук не возвращает ничего — он немедленно завершается, не блокируя закрытие сессии.

**Побочный эффект:**
- `flush.py` в фоне читает транскрипт текущей сессии и сохраняет/обрабатывает данные (например, для wiki-компилятора или памяти проекта).

## Связанные концепты
- [[wiki]] — вероятно, flush.py обрабатывает транскрипты для нужд wiki-системы
