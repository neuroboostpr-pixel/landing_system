# scrape-css.sh — скачивание HTML и CSS живого сайта

## Что делает
Загружает исходный HTML и все CSS-стили с указанного URL в локальную папку. Разбирает inline-стили и внешние подключённые таблицы стилей по отдельным файлам — чтобы дальнейший анализ мог работать с сырым кодом без браузера.

## Когда вызывать / в каком этапе
Используется на этапе **04 (Бренд / Стиль)** — когда агент `style-extractor` или аналитик начинает извлекать визуальные эффекты с сайта-референса. Вызывается вручную или из скриптов-обёрток в `scripts/extract-effects/`.

Типичный сценарий: маркетолог нашёл сайт-референс → `scrape-css.sh <url> ./out` → файлы готовы для парсинга токенов и анимаций.

## Что на вход / на выход

**Вход:**
- `<url>` — адрес живого сайта (например `https://example.com`)
- `<out-dir>` — папка для сохранения результатов

**Выход (в `<out-dir>`):**
- `page.html` — исходный HTML страницы
- `inline.css` — все inline `<style>...</style>` блоки, объединённые в один файл
- `link-N.css` — каждый внешний stylesheet отдельным файлом (link-1.css, link-2.css, …)

## Связанные концепты
- [[style-extractor]] — агент этапа 04, который запускает этот скрипт для получения сырых стилей референсов
- [[style-decomposition]] — скилл, обрабатывающий вывод скрипта: извлекает палитру, шрифты, анимации
