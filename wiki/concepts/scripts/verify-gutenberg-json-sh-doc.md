# verify-gutenberg-json — валидатор block.json для Gutenberg-блоков

## Что делает
Проходит по всем файлам `block.json` в указанной директории и проверяет, что каждый из них является корректным JSON. Если хотя бы один файл сломан — скрипт возвращает ошибку, что позволяет поймать проблему до деплоя.

## Когда вызывать / в каком этапе
Используется на этапе **08 (Код)** — после того как `wp-builder` или `frontend-builder` сгенерировали Lazy Blocks с файлами `block.json`. Запускается как часть gate-check перед переходом к этапу 09 (Deploy). Можно вызывать вручную в любой момент при подозрении на битый JSON.

## Что на вход / на выход

**Вход:**
- `<dir>` — путь к директории, в которой рекурсивно ищутся файлы `block.json` (обычно папка темы или `blocks/`)

**Выход:**
- Сообщения в stdout о каждом проверенном файле
- **Exit 0** — все `block.json` валидны (или директория пуста)
- **Exit 1** — хотя бы один файл содержит невалидный JSON
- **Exit 2** — указанная директория не существует

**Артефакты:** скрипт ничего не создаёт и не изменяет — только читает и проверяет.

## Связанные концепты
- [[wp-gutenberg-block-builder]] — генерирует `block.json` файлы, которые этот скрипт проверяет
- [[wp-builder]] — оркестрирует сборку блоков на этапе 08, вызывает валидацию
- [[stage-gates]] — HARD GATE 08→09 требует exit 0 от скриптов валидации
- [[frontend-builder]] — также может генерировать `block.json` при правке шаблонов блоков
