# snapshot-palettes-to-project — копирование палитр в проект

## Что делает

Скрипт копирует выбранные цветовые палитры из глобальной библиотеки (`presets/palettes.yaml`) в папку `04_БРЕНД/palettes.yaml` конкретного проекта. Перед копированием запускает валидацию исходной библиотеки через `validate-palettes.py`, чтобы гарантировать корректность данных.

## Когда вызывать / в каком этапе

Используется на этапе **04 (Бренд)** — до или во время работы `brand-architect`. Запускают вручную из терминала, когда нужно «заморозить» конкретные палитры в проекте (снэпшот), чтобы бренд не зависел от изменений в глобальной библиотеке.

Типовые ситуации:
- Быстрый старт бренда без полного цикла `style-extractor`.
- Пресет-палитра одобрена маркетологом, нужно зафиксировать её в проекте.
- Тестовый прогон `design-system-generator` с заранее известной палитрой.

## Что на вход / на выход

**Аргументы командной строки:**
| Флаг | Обязателен | Описание |
|---|---|---|
| `--project <path>` | да | Путь к папке проекта |
| `--library <path>` | да | Путь к YAML-файлу глобальной библиотеки палитр |
| `--id <id>` | нет* | ID палитры для включения (можно повторять) |
| `--all` | нет* | Скопировать все палитры из библиотеки |

\* Нужен хотя бы один из `--id` или `--all`.

**Вход:**
- `presets/palettes.yaml` (или любой YAML-файл с ключом `palettes: [...]`)

**Выход:**
- `<project>/04_БРЕНД/palettes.yaml` — снэпшот выбранных палитр
- Создаёт папку `04_БРЕНД/` если её нет

**Сообщения:**
- `snapshotted N palette(s) to <dest>` — при успехе
- `ERROR: unknown palette id(s): [...]` — если `--id` не найден в библиотеке
- `ERROR: pass --all or one or more --id` — если не передано ни одного выбора
