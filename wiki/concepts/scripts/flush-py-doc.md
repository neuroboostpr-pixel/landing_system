# flush.py — Извлечение уроков из сессии

## Что делает
Автоматически читает транскрипт завершённой Claude Code сессии, извлекает ключевые уроки через Anthropic SDK и сохраняет их в дневной файл памяти проекта. Работает незаметно в фоне — маркетолог его не вызывает вручную.

## Когда вызывать / в каком этапе
Скрипт запускается **автоматически** из хуков `SessionEnd` и `PreCompact`. Не относится к конкретному этапу pipeline — работает на протяжении всего жизненного цикла любого проекта. Вручную вызывается только при отладке:

```bash
python3 flush.py --transcript <path> --cwd <cwd> [--mode session-end|pre-compact]
```

## Что на вход / на выход

**Вход:**
- `--transcript <path>` — путь к JSONL-файлу транскрипта сессии
- `--cwd <cwd>` — рабочая папка, по которой определяется целевой проект
- `--mode` — режим запуска (`session-end` или `pre-compact`)

**Выход:**
- Дополненный файл `memory/daily/YYYY-MM-DD.md` — уроки сессии добавляются (append) к дневному журналу памяти текущего проекта

**Логика определения проекта:**
- Если `cwd` указывает на `landing-system` → пишет в системную память
- Если `cwd` указывает на `~/Lendings/<slug>/` → пишет в память конкретного лендинга

## Связанные концепты
- [[memory]] — целевая папка, куда записываются результаты
- [[landing-orchestrator]] — основной агент-оркестратор, сессии которого чаще всего попадают в flush
