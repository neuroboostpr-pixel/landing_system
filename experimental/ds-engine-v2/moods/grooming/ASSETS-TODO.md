## ✅ Уже готово системой (CSS/токены — генерить не нужно)

- **page-bg** — фон страницы — тёплый беж база  (`var(--lp-bg)`)
- **section-bg-rhythm** — смена фона секций: светлый ↔ ПОЛНОШИРИННАЯ ОРАНЖ-ЗОНА ↔ светлый (01/10,01/15)  (`класс .gr-bg-* / .gr-accent-band`)
- **photo-mask** — маски фото: squircle (hero 01/08), круг (аватары 01/11), оранж-круг-подложка (01/02)  (`класс .gr-photo / .gr-circle`)
- **glow-shadow** — мягкие тёплые тени карточек/фигуры (по всем экранам)  (`box-shadow токены`)

---
**Как генерировать:**
- 🔸 batch-sheet — один запрос на лист (иконки/глифы), потом нарезать на файлы по слотам.
- 🔹 batch-series — один стиль-бриф на серию (фигуры/фото/росчерки), кадры по отдельности.
- 🔹 single — уникальный ассет (фон-сцена, лого, фавикон), свой бриф.
- Готовые файлы класть в `assets/{decor,bg,figures,icons,brand}/`, статус в манифесте → `готов`.
