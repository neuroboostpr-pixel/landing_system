# gen-design-system

## Pre-flight

```bash
python -m scripts.wiki.log --type skill_call --skill gen-design-system --stage 05
```

Дизайн-система = **ВИД и ПРИЁМЫ** (цвета, шрифты, размеры, объекты-роли, движение), снятые с РЕФЕРЕНСА
клиента. Структуру/контент даёт прототип (`gen-prototype`), НЕ референс.

## Вход

- Референс(ы) клиента — `03_РЕФЕРЕНСЫ/*.png` (скриншоты сайтов-образцов). Один референс = один МОД.
  Референс часто = НЕСКОЛЬКО экранов (hero + секции + спека шрифтов/цветов).
- `03_РЕФЕРЕНСЫ/references-index.md` — какой референс какому моду соответствует.

## Инструменты (в этом скиле: `scripts/`)

| Скрипт | Когда | Что делает |
|---|---|---|
| `scripts/extract-palette.py <ref.png> [...] [--n 8]` | шаг 2 (цвета) | палитра по ПИКСЕЛЯМ: доминантные (фоны) + vivid-акценты (кнопки) с hex. Подсказка для `palette.css`, не замена глаза. Требует Pillow. |
| `scripts/verify_tokens.py <dir|file> [--skip-token-files]` | финал | гейт токенизации §4.3. Легальные зоны hex: `:root{}`, `html[data-mood="…"]{}`, комментарии, `/* token-exempt */`. `--skip-token-files` пропускает palette.css/motion.css (файлы-определения). В компонентном CSS/HTML hex = FAIL. (живёт в `scripts/` корня системы.) |

## Выход (yaml/css проекта) — на КАЖДЫЙ мод `05_ДИЗАЙН-СИСТЕМА/moods/{mood}/`

- `palette.css` — цвета `--lp-*` (ЕДИНСТВЕННЫЙ источник цвета).
- `typography.css` — шрифты `--lp-fh/fb`, кегли `--fs-*`, `--lh-*`, `--ls-*`.
- `metrics.css` — размеры-ТОКЕНЫ (`--cta-size`, `--figure-h`, `--header-h`, …) — ЕДИНСТВЕННЫЙ источник размеров.
- `motion.css` — `--ease/dur-*/reveal-*/parallax-*/float-*/glow/shadow-*/radius-*`.
- `objects.yaml` — роли (вид через ТОКЕНЫ + поле `motion`). Формат `moods/_OBJECT-SPEC-FORMAT.md`.
- `compositions/*.yaml` — расположение (ref:роль + зона/наезд/порядок), БЕЗ дублей параметров.

## Флоу

0. **Прочитать ВСЕ экраны референса ГЛАЗАМИ** (не только hero!). Референс = N скриншотов;
   роли (карточки/формы/состояния/декор/футер) живут на ВНУТРЕННИХ экранах, не только на первом.
   ⛔ Собрать мод с одного hero = неполный objects.yaml = дефект. Если экран большой — нарезать
   на полосы и читать зумом (как флоу A в `gen-prototype`).
1. Снять с референса **ГЛАЗАМИ** объекты-роли — пройти весь **21-уровневый чек-лист**
   (`moods/_OBJECT-SPEC-FORMAT.md`) ПО ВСЕМ экранам: базовые-визуальные → размеры → типографика →
   медиа → декор → иконки → интерактив(9 состояний) → формы → микро → навигация → карточки → … →
   анимация → дизайн-система. Уровень не применим → пометить «н/п», не пропускать молча.
2. Цвета → `palette.css` (по ПИКСЕЛЯМ: `scripts/extract-palette.py` как подсказка + сверка зумом).
   Шрифты/кегли → `typography.css`.
3. Размеры объектов → ТОКЕНЫ в `metrics.css` (`--cta-size` и т.п.). Движение → `motion.css`.
4. Каждый объект → РОЛЬ в `objects.yaml`: вид ССЫЛКАМИ на токены (`size: --cta-size`, `color: --lp-accent`),
   состояния (default/hover/focus…), поле `motion` (on_load/hover/idle со ссылками на motion-токены).
5. Раскладку первого экрана → `compositions/hero.yaml` (ref:роль + расположение). Параметры НЕ дублировать.
6. Каждый мод **самодостаточен** — не ссылается на другие муды; активируется `html[data-mood="{mood}"]`.

## ПРАВИЛА (⛔ нарушение = дефект)

- ⛔ **objects.yaml = ЕДИНСТВЕННЫЙ источник вида.** Параметры — ССЫЛКАМИ на токены, НЕ голые px/hex.
- ⛔ **Различие параметра по модам = НОВЫЙ ТОКЕН** (cta 140/118 = один `--cta-size`, разный по модам).
- ⛔ **Цвета только в palette.css** (`--lp-*`); **размеры только в metrics.css**. 0 hex/px вне токенов (иначе мод «протекает»).
- ⛔ **БЕЗ проектных отсылок в ДС** — никаких имён проекта/клиента, «левая зона», «cta-combo». ДС универсальна.
- ⛔ **БЕЗ `adaptation` в ДС** — как роль ложится на конкретный прототип → в ТЗ (`gen-spec`), не тут.
- ⛔ **Placement в роли = ПО РЕФЕРЕНСУ** (приём «круг на границе зон + наезд»), НЕ по верстке/проекту.
   Конкретные координаты под проект — в composition.
- ⛔ **Каждый заголовок/цитата — ОТДЕЛЬНАЯ роль** (h1/h2/h3/quote/subhead/caption…), не одна `heading`.
- ⛔ **Кегль H1 — под ДЛИНУ реального заголовка, не «крупно=премиум».** Гигант-дисплей (`clamp(…, …, 7rem)`)
  годится ТОЛЬКО для расколотого КОРОТКОГО слова (типа «PRO»/«ДЕНЬГИ» — 1-2 слова). Для полного headline-предложения
  кегль должен давать **2-4 строки, помещаться в первый экран** (ориентир desktop `--fs-h1` ≤ ~3rem, не 7rem).
  Проверка: уложить фактический headline прототипа в кегль — если «стена текста» / не помещается → уменьшить токен.
- ⛔ **Эффекты ОБЯЗАТЕЛЬНЫ** (в статичном скрине не видны): у каждой роли `motion`; reveal/parallax/float токенами.
- ⛔ **Снимать со ВСЕХ экранов референса, не только с hero.** Внутренние секции дают роли
  (карточки/формы/таймлайн/FAQ/футер), которых нет на первом экране. Один hero = неполный мод.
- Снимать ГЛАЗАМИ, не выдумывать. Невидимое (hover/focus) → «предпол.». Цвета — по пикселям.
