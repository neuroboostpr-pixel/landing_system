# rembg

## Pre-flight

```bash
python -m scripts.wiki.log --type skill_call --skill rembg --stage 07c
```

Скилл-обёртка над [rembg](https://github.com/danielgatis/rembg) (Daniel Gatis,
U2-Net / isnet-general-use) для удаления фона. Заменяет грубый chroma-key:
держит края машины/объекта на неоднородном студийном фоне (градиент + тень)
заметно чище.

**Установка пакета** (один раз на машине):
```bash
pip install rembg
# первая обработка скачает веса модели (~170 МБ) в ~/.u2net — нужен интернет 1 раз
```

## Использование

```bash
# один файл -> webp с прозрачностью + preview (оценить края на тёмной карточке)
python skills/rembg/scripts/cutout.py <photo.png> --out <out_dir> --webp --preview

# вся папка цветов модели за раз
python skills/rembg/scripts/cutout.py <inbox_dir> --out <out_dir> --webp
```

**Флаги:**
- `--out <dir>` — куда класть результат (обязательно)
- `--model <name>` — модель rembg; по умолчанию `isnet-general-use` (точнее краёв
  для авто, чем `u2net`)
- `--webp` — сохранять webp с alpha (легче png; для дальнейшей вставки в тему)
- `--preview` — рядом класть `<name>-preview.png` (объект на тёмном фоне) для
  визуальной проверки краёв перед массовым прогоном
- `--no-crop` — не обрезать по bbox (по умолчанию обрезает прозрачные поля)

## Где применяется

Этап **07c (photo pipeline)**: когда клиентское фото авто снято в студии на
светлом фоне, а в карточке марки/модели нужна машина «в воздухе» на фоне самой
карточки (который перекрашивается под дизайн-систему). Флоу:

1. `rembg/cutout.py` — вырезать объект (прозрачный фон) → webp.
2. Положить в `wp-theme/assets/img/<brand>/` и сослаться в карточке.
3. Адаптация под mood — НЕ репейнт объекта, а **полупрозрачный оверлей
   `var(--c-accent)`** поверх (см. T41 в
   [block-system-consolidated-spec](../../docs/superpowers/specs/2026-06-03-block-system-consolidated-spec.md)).

**Identity-safe:** объект не репейнтится; rembg только отделяет от фона. Для
лиц/людей удаление фона допустимо, но генерация/замена лиц — отдельное правило
(PR-B, ai_approved_by_user).

## Рекомендации по краям

- Для машин на студийном фоне `isnet-general-use` обычно лучше `u2net`.
- Полупрозрачные элементы (стекло, тени под колёсами) rembg может срезать —
  проверяй `--preview` на тёмном фоне перед массовым прогоном.
- Если край «рваный» на конкретном фото — это фото лучше оставить с фоном или
  доснять; не тащить плохой вырез в прод.
