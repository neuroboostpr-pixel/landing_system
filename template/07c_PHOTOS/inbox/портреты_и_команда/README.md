# портреты_и_команда

Фото людей для лендинга:
- **Эксперт / директор / основатель** — для блока «о нас», для testimonials
- **Команда** — групповое фото или индивидуальные портреты сотрудников
- **Клиенты** — для testimonials (с их разрешением!)

## Рекомендации по технике

- **Пропорции:** 1:1 (квадрат) или 3:4 (портретная). Автоматически подходит под слоты `testimonial-avatar` (1:1) и `expert-photo`.
- **Свет:** мягкий, ровный. Без контрового, без сильных теней на лице.
- **Фон:** светлый, не пёстрый. Лучше офисный интерьер или нейтральный.
- **Кадрирование:** грудной портрет (medium-shot) — лицо не слишком крупно, видны плечи.

## Чего избегать

- Селфи с фронталки (низкое качество)
- Групповые фото где половина закрыта другими
- Старые ч/б фотографии (если только это не стилизованный сайт)

После `/landing-photos` AI пометит эти фотки тегами `portrait` и/или `team`.
