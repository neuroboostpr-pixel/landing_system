# Mood Recipes Design

Date: 2026-06-22
Status: experimental contract, used by DS-Engine v2

## Goal

`recipes.yaml` describes the transferable visual character of a reference: zone
roles, typography behavior, accent rhythm, decor, masks, motion, and component
treatment. It must not contain client text or copied reference text.

## Rules

1. Reference gives visual roles and techniques, not layout to copy pixel-by-pixel.
2. Prototype gives structure and real text. Do not invent blocks or content.
3. Each recipe technique must be visible beyond hero when relevant.
4. Text must be tested with real prototype copy on desktop and mobile.
5. Real client people, products, machines, places, and objects are preserved; only
   processing and layout adaptation are allowed.

## Required Files

For each mood:

- `recipes.yaml`
- `assets-manifest.yaml`
- `ASSETS-TODO.md`
- `asset-pack.yaml`

See `docs/standards/ds-asset-pack.md`.
