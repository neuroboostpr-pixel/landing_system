## Что такое Style Moods?

Style Mood — это **полный набор стилевых правил** (цвета, шрифты, анимации, паттерны), который меняет визуальное впечатление от лендинга **без изменения структуры блоков**.

Одна и та же структура макета может выглядеть очень по-разному в разных mood'ах:
- **Одна цветовая палитра** для каждого mood
- **Одна типографика** (шрифты, размеры, интерлиньяж)
- **Одни паттерны** (фон, анимации, декор)

Система включает **6 готовых mood'ов** — выбирай нужный в зависимости от нише и целевой аудитории.

## 6 Style Moods

### 1. **Brutalist** — геометричный, контрастный, минималистичный
**Когда использовать:** tech/fintech, software, IT-услуги, startup'ы, B2B  
**Палитра:** монохром (чёрный/белый) + один яркий accent (обычно красный)  
**Типография:** sans-serif, чёткие линии, высокий контраст  
**Паттерны:** clean lines, no gradients, sharp borders  
**Впечатление:** modern, serious, trustworthy, no-nonsense

**Пример ниш:**
- DevOps платформы
- AI/ML инструменты
- Финтех-приложения
- Code editors

---

### 2. **Editorial Warm** — тёплые цвета, serif, мягкие градиенты
**Когда использовать:** lifestyle, блоги, контент-платформы, медиа, beauty/wellness  
**Палитра:** тёплые тона (бежевый, терракота, золото) + приглушённые accent'ы  
**Типография:** serif для заголовков, sans-serif для текста, увеличенный line-height  
**Паттерны:** soft gradients, paper texture, gentle animations  
**Впечатление:** warm, approachable, editorial, human-centered

**Пример ниш:**
- Fashion/lifestyle блоги
- Wellness/spa услуги
- Контент-курсы
- Издательства

---

### 3. **Swiss Modernist** — минимализм, сетка, точность
**Когда использовать:** дизайн, архитектура, премиальные услуги, corporate  
**Палитра:** neutral greys, один accent colour, максимум 3 цвета total  
**Типография:** clean sans-serif, идеальная сетка, mono-weight  
**Паттерны:** grid-based layouts, no decoration, whitespace is key  
**Впечатление:** professional, premium, organized, timeless

**Пример ниш:**
- Architecture firms
- Design agencies
- Corporate presentations
- Premium SaaS

---

### 4. **Retro Windows** — ностальгия, пастель, playful
**Когда использовать:** ретро-тематика, творчество, молодая аудитория, игры, indie-проекты  
**Палитра:** пастельные цвета (мягкие голубой, розовый, жёлтый, зелёный)  
**Типография:** чуть bold, playful spacing  
**Паттерны:** nostalgic shapes, bouncy animations, rounded corners  
**Впечатление:** fun, retro, friendly, creative

**Пример ниш:**
- Indie games
- Creative portfolios
- Toy/collectible brands
- Retro-inspired products

---

### 5. **Coral Soft** — мягкие тона, wellness, красота
**Когда использовать:** beauty, health, wellness, female-focused, lifestyle, е-commerce  
**Палитра:** коралл, розовый, персиковый, мягкие pastels  
**Типография:** rounded sans-serif, мягкие transitions  
**Паттерны:** soft shapes, gradient overlays, smooth animations  
**Впечатление:** caring, beautiful, welcoming, accessible

**Пример ниш:**
- Beauty/cosmetics
- Health coaching
- Female wellness
- Lifestyle e-commerce

---

### 6. **Monochrome Precision** — люкс, чёрнобелое, симметричная композиция
**Когда использовать:** люкс-товары, премиум-услуги, high-end fashion, недвижимость  
**Палитра:** чёрный, белый, один gold/silver accent, максимум contrast  
**Типография:** elegant serif, tight letter-spacing  
**Паттерны:** symmetrical, gold accents, minimal animation  
**Впечатление:** luxury, exclusive, timeless, sophisticated

**Пример ниш:**
- Luxury fashion
- Premium real estate
- High-end jewelry
- Exclusive memberships

## Как выбрать Mood для твоего проекта?

### Матрица выбора

| Ниша | Рекомендуемый mood | Альтернатива |
|---|---|---|
| Tech/SaaS/AI | **Brutalist** | Swiss Modernist |
| Финтех | **Brutalist** | Monochrome Precision |
| Lifestyle/Beauty | **Coral Soft** | Editorial Warm |
| Wellness/Health | **Coral Soft** | Editorial Warm |
| Блог/Контент | **Editorial Warm** | Swiss Modernist |
| Design agency | **Swiss Modernist** | Monochrome Precision |
| Недвижимость | **Monochrome Precision** | Swiss Modernist |
| Fashion | **Coral Soft** или **Monochrome Precision** | Editorial Warm |
| Gaming/Creative | **Retro Windows** | Coral Soft |
| Corporate B2B | **Swiss Modernist** | Brutalist |

### Questions to Ask

Ответь на вопросы — они помогут выбрать правильный mood:

1. **Какой уровень энергии нужен?**
   - Высокий (динамичный) → **Retro Windows** или **Coral Soft**
   - Средний (профессиональный) → **Swiss Modernist** или **Editorial Warm**
   - Низкий (люкс/серьёзный) → **Monochrome Precision** или **Brutalist**

2. **Кто целевая аудитория по возрасту?**
   - 16-25 → **Retro Windows**
   - 25-40 → **Swiss Modernist**, **Coral Soft**, **Editorial Warm**
   - 40+ → **Monochrome Precision**, **Brutalist**

3. **Какой уровень экспертизы?**
   - Высокий (B2B, enterprise) → **Brutalist**, **Monochrome Precision**
   - Средний → **Swiss Modernist**, **Editorial Warm**
   - Accessible (consumer) → **Coral Soft**, **Retro Windows**

4. **Контрастность?**
   - Максимум (stand out) → **Brutalist**, **Monochrome Precision**, **Retro Windows**
   - Средняя → **Editorial Warm**, **Coral Soft**
   - Минимум (subtle) → **Swiss Modernist**

## Workflow: Как использовать Moods в Wireframe

### Stage 07a (Wireframe selection)

1. **Откой `wireframe.html`** в браузере
2. **Для каждого блока:**
   - Выбери layout variant (например, "Hero variant 2")
   - **НОВОЕ (PR-S):** Выбери mood tab ниже layout tabs (например, "Editorial Warm")
   - Посмотри preview — блок переклеится в выбранный mood
3. **После выбора всех:** нажми "Confirm selections" → скачается `selections.yaml` с mood'ами

### selections.yaml формат (с mood'ами)

```yaml
project: my-project
timestamp: "2026-06-02T14:30:00Z"

selections:
  - block_position: 1
    chosen_variant: hero-variant-2
    style_mood: editorial-warm          # ← НОВОЕ
  
  - block_position: 2
    chosen_variant: features-grid-4col
    style_mood: editorial-warm
  
  - block_position: 3
    chosen_variant: pricing-table-3
    style_mood: coral-soft              # Другой mood для этого блока!
```

### Stage 07b (Compose)

После выбора mood'ов:

```bash
/landing-compose my-project
```

Pipeline автоматически:
1. Читает `selections.yaml` (включая `style_mood` поля)
2. Для каждого блока загружает mood CSS:
   - `block-library/_styles/{mood}/palette.css` (цвета)
   - `block-library/_styles/{mood}/typography.css` (шрифты)
   - `block-library/_styles/{mood}/motion.css` (анимации)
3. Инъектирует mood CSS в `composed.html`

**Результат:** composed.html имеет правильные цвета, шрифты, паттерны для каждого блока в зависимости от выбранного mood!

## Best Practices

### ✅ Делай

- **Консистентность:** Используй один mood для весь лендинга (все блоки в одном mood), или максимум 2 дополняющих mood'а
- **Тест разных mood'ов:** Перед финалом посмотри блок в 2-3 mood'ах — выбери тот что лучше подходит бренду
- **Mood = целевая аудитория:** Brutalist для developers, Coral Soft для beauty, Monochrome для luxury
- **Простота >> красивость:** Минималистичный mood (Swiss Modernist) почти всегда лучше чем перегруженный

### ❌ Не делай

- **Микс mood'ов:** Не меняй mood для каждого блока (confusing, incoherent)
- **mood для маскировки слабого контента:** Хороший контент в простом mood лучше, чем слабый контент в красивом mood
- **Mood = цвет:** Mood это не просто палитра — это система цветов + шрифты + анимации (все вместе)
- **Переусложнение:** Если не уверен, выбери **Swiss Modernist** — работает для большинства ниш

## Troubleshooting

### Проблема: Mood выбран, но цвета не поменялись в compose

**Причина:** mood CSS не инъектировался правильно.

**Решение:**
1. Проверь что `selections.yaml` содержит `style_mood` поле
2. Проверь что path к mood CSS правильный: `block-library/_styles/{mood}/palette.css`
3. Перезапусти `/landing-compose my-project`

### Проблема: Все блоки выглядят одинаково

**Причина:** Mood не отличается от дефолтного.

**Решение:**
- Mood'ы отличаются в основном **цветами** и **шрифтами**
- Если контент идентичный, то да, они будут похожи
- Сравни 2 совсем разных mood'а (например, Brutalist vs Coral Soft) чтобы увидеть разницу

### Проблема: Mood CSS конфликтует с другими CSS

**Причина:** CSS specificity, неправильный порядок инъекции.

**Решение:**
- Mood CSS инъектируется ДО блока HTML (правильный порядок)
- Если конфликт остался, скажи фиксить — это баг в mood CSS

## FAQ

**Q: Можно ли создать свой Custom Mood?**  
A: Пока нет (out of scope PR-S.1). Это планируется в PR-S.2. Сейчас доступны только 6 готовых.

**Q: Можно ли менять Mood после Compose?**  
A: Да! Отредактируй `selections.yaml`, измени `style_mood`, перезапусти `/landing-compose`.

**Q: Влияет ли Mood на SEO?**  
A: Нет. Mood = чисто визуальный слой. Структура HTML, content, meta-tags не меняются.

**Q: Какой Mood самый "безопасный" (work for everything)?**  
A: **Swiss Modernist** — скучновато, но работает для всех ниш и аудиторий.

**Q: Сколько Mood'ов можно использовать в одном лендинге?**  
A: Максимум 2 (например, Editorial Warm для hero, Coral Soft для pricing). Больше = confusing.
