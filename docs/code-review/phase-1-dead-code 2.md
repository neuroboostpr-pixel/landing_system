## Глоссарий

- *reference-map* — карта «кто кого вызывает» по проекту.
- *usage_class* — классификация файла по тому, откуда на него ссылаются.
- *orphan-файл* — файл без входящих ссылок откуда-либо.
- *doc-only* — упоминается только в документации, не вызывается из исполняемого кода.
- *false-positive* — файл, который ошибочно помечен как «неиспользуемый», хотя реально используется (через скрытую ссылку, не обнаруженную карта-стрителем).
- *dynamic include* — подключение файла через переменную (`include $variable` в PHP, `glob()` в Python) — не отслеживается простым поиском по basename.
- *Python import* — подключение модуля через `import X` или `from X import Y` — не отслеживается поиском «bash X.py».
- *one-shot migration* — скрипт миграции, который запускается один раз и больше не нужен.
- *stage-agent* — агент, отвечающий за один этап pipeline'а (например, `wp-builder` для stage-08).
