# Стандарт точности парсинга прототипа (B37)

Каноничное правило этапа 07a (импорт прототипа): **ничего не терять, ничего не
выдумывать**. Переопределяет «по умолчанию» поведение агентов.

## Правило

Из исходника клиента (`07_ПРОТОТИП/source/prototype.docx|pdf|md`) в
`prototype.yaml` должно дойти **≥90% значимого текста**, и в yaml **не должно
быть структуры, которой нет в источнике**.

| ✅ Можно | ❌ Нельзя |
|---|---|
| Текст-подстрока из источника | Перефразировать / дописывать маркетинг |
| Реальные цены из таблиц docx | `price: standard/premium/vip` вместо цифр |
| Пустой `cta: ""` если нет данных | Выдумать «Get Started», меню, бейджи |
| `client_notes:` для комментариев клиента | Комментарии разработчику в визуал-блоки |

Частые галлюцинации, которые гейт ловит: меню `[Home, About, Services,
Contact]` на одностраничнике; абстрактные тарифы; Lorem ipsum.

## Инструменты

| Скрипт | Что делает |
|---|---|
| `extract-docx-text.py --source <docx> --out <pref>` | python-docx → `<pref>.txt` (весь текст, **включая таблицы**) + `.json` (структура). Эталон полноты. |
| `verify-prototype-fidelity.py --source-text <txt> --prototype <yaml> --min-coverage 0.9` | покрытие источника + анти-галлюцинация → `fidelity-report.md`, exit 1 при потере/выдумке. |
| `gate-prototype-fidelity.py <project>` | обёртка для гейта 07a: извлечь docx + проверить. |

## Гейт 07a

`config/stage-gates.yaml::07a_prototype` содержит hard-check
`prototype_fidelity` → этап не закрывается при потере >10% текста или
выдуманной структуре. Отчёт: `07_ПРОТОТИП/fidelity-report.md`.

## client_notes / source_meta

Комментарии клиента разработчику и техно-метаданные источника выносятся в
top-level секции `prototype.yaml`:

```yaml
client_notes:
  - text: "Ник, перепроверь — ты знаешь, что мы реально даём :)"
    relates_to: curriculum
source_meta:
  project_url: "https://..."
  deadline: "05 июня"
```

Они **не в `sections`**, поэтому render-wireframe их не рендерит как блоки —
но они сохранены и показываются как рекомендации.

## Ограничения текущей версии

- Извлечение полноты реализовано для **.docx** (python-docx). Для .pdf/.md
  гейт `prototype_fidelity` возвращает N/A (полнота не проверяется).
- Порог 90% настраивается `--min-coverage`. Мета-строки (URL, дедлайны,
  служебные ремарки) учитываются как покрытые, если попали в client_notes/
  source_meta.
