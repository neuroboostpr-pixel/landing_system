# Image Pipeline — генерация и подгонка картинок под дизайн (D1)

**Статус:** обязательный стандарт этапов 07d/07e (фото и визуалы).
**Источник:** спека [2026-06-12-reference-driven-flow-spec.md](../superpowers/specs/2026-06-12-reference-driven-flow-spec.md), раздел 5 (пилот пройден).
**Применяют:** photo-curator, visual-curator, icon-generator, infographic-builder.

Не «подобрать сток-фото», а для **каждого визуального места** на странице:

## Шаги (обязательная последовательность)

1. **Анализ места** — что вокруг: заголовок, тексты, кнопка, цвет фона секции.
2. **Цель картинки** — выводится из контекста. Пример: карточка бренда +
   кнопка «смотреть модели» = показать **весь модельный ряд**, не одну машину.
3. **Спецификация** — размер, пропорции, формат, текст запроса на генерацию.
   Запрашивать **нативные размеры** в промпте (не центр-кроп потом).
4. **Референсы для генерации** — **число референсов = составу композиции**:
   нужно 5 разных машин — даём 5 фото-референсов (с одним получаются клоны).
5. **Генерация** — на фоне, который **легко вырезать**: чистый студийный
   градиент или сплошной хромакей `#FF00FF`; объект не касается краёв;
   мягкая тень не до края.
6. **Вырезание фона** — `rembg` → PNG с прозрачностью. Если у клиентского
   файла фон уже прозрачный — использовать как есть (часто чище авто-вырезки).
7. **Вставка** — PNG поверх CSS-фона дизайн-системы (подходит под любую палитру).

## Адаптация под палитру (одно фото на все дизайн-системы)

НЕ делать отдельную картинку под каждый цвет. Накладывать **полупрозрачный
оверлей акцентного цвета** через CSS — он сам перекрашивается при смене палитры:

```css
.lp-photo-tinted::after {
  content: ""; position: absolute; inset: 0;
  background: var(--lp-accent);
  opacity: 0.18; mix-blend-mode: multiply;
  pointer-events: none;
}
```

## Ограничения (identity-safe + бренд)

- **Лица людей НЕ генерировать** — только реальные фото клиента (rembg-вырезка).
  AI-генерация лиц для testimonial/expert/team — только с явной галочкой
  `ai_approved_by_user`.
- **Логотипы НЕ генерировать** — см. [logo-icon-favicon.md](logo-icon-favicon.md).
- Генерация — только для абстрактного: маскоты, инфографика, предметы без
  бренд-знаков ([design-elements-rules.md](design-elements-rules.md), дерево решений).

> **Культурный анализ региона** (числа/цвета/символы/табу) — отложен,
> в текущем флоу этого шага нет (спека §5).
